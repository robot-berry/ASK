# 基于 PP-OCR 文字行扇出的单消失点透视矫正（独立实验）

## 结论

本实验不使用干净参考图、题目模板或 OCR 识别文本，只使用 PP-OCR 检测网络的文字概率图。它能识别并消除“同一组水平文字行的角度随 y 稳定变化”的水平透视扇出，再旋正文字，并通过扩画布保存整个源图。

hard20 回归中仅 `photo_169_0524.jpg`、`photo_201_0773.jpg` 触发，二者均通过变换后的独立重检测；其余 18 张不触发。`photo_169_0524` 本身也有真实文字扇出，因此本小样本中未观察到普通旋转/无透视样本误触。

这只是单消失点（水平行）校正，不是完整页面度量校正：它使文字行互相平行并接近水平，但没有估计竖直消失点、纸张真实宽高比，也不会强行把外边界变成矩形。`photo_201` 的题目完整保留，但页面外形仍可呈梯形；若目标是“扫描件矩形”，还需要可靠的纸张/题卡边界或第二组正交线。

## 检测和触发

1. 输入长边限制到 1800，沿用正式流程的文档粗校正和四向方向。
2. PP-OCR 检测输入长边 1216，边长独立取 32 的倍数；输出概率阈值 0.30，2x2 开运算，5x3 膨胀。
3. 轮廓最小外接矩形作为候选文字行。保留：长边 >= 图宽 7.5%，长短比 >= 3，短边 <= 图高 11%，绝对方向 <= 18°。把检测尺寸缩放回源尺寸后重新计算角度，避免 32 倍数取整带来的各向异性偏差。
4. 为排除 PP-OCR 对示意图长轮廓的响应，只使用一个纵向重复、x 区间相交或左右边对齐的连通文字栈；至少保留 5 行。
5. 对角度 `theta_i` 与归一化高度 `y_i / H` 做以 `sqrt(line_length)` 加权的线性拟合。
6. 强触发门槛（必须全部满足）：
   - 行数 >= 5；y 覆盖 >= 0.15H；10%-90% 角度范围 >= 2.4°；
   - `|corr(theta,y)| >= 0.72`，加权 `R² >= 0.48`，拟合中位绝对残差 <= 1.35°；
   - 行对 y 间隔 >= 0.06H、角差 >= 0.7°，至少得到 4 个合理交点；
   - 消失点距图中心为 1.2 至 150 个最大边长，交点到稳健消失点的中位离散 <= 2.5 个最大边长。
7. 消失点由有效行对交点的坐标加权中位数估计，权重为 `sqrt(length_i*length_j) * delta_y/H`。

## 单应矩阵推导

令图像中心为 `C=(cx,cy)`，水平文字行的消失点在中心坐标中为 `V=(Vx,Vy,1)`。选择最小范数的纯射影矩阵

```text
P = [ 1  0  0 ]
    [ 0  1  0 ]
    [ a  b  1 ]
```

若要把 `V` 映到无穷远，必须有 `a*Vx + b*Vy + 1 = 0`。使 `||(a,b)||` 最小的解为：

```text
(a,b) = -(Vx,Vy)/(Vx²+Vy²)
```

源图坐标中的矩阵为：

```text
H_projective = T(+C) * P * T(-C)
```

应用射影变换后，以变换后文字行角度的加权中位数做一次 `rotate_bound`，得到最终 `H_final = R_bound * T_canvas * H_projective`。

## 保完整与拒绝条件

- 对源图四条边各采样 300 点，共 1200 点；变换全部有限后，以变换后边界加 12 px 安全边扩画布，而不是在原尺寸内裁切。
- 输出长边上限 3600；缩小比例必须 >= 0.70；输出最大边不得超过源图最大边的 2.2 倍。
- 单应分母在四角必须同号且最小绝对值 >= 0.20，排除变换极线穿过源页或接近无限拉伸；最终旋转后的真实画布也必须满足 2.2 倍上限。
- 变换后四角必须保持凸，最短边不得小于源图短边的 35%。
- 将全白有效区 mask 同矩阵变换，保存其非零包围框供完整性检查。
- 变换后必须二次验收：原行扇出改善 >= 2 倍、理论 10%-90% 角度范围 <= 1.5°、中位绝对角 <= 0.75°；并在实际成图上重新运行 PP-OCR，重检文字栈 >= 5 行、范围 <= 1.8°、中位绝对角 <= 0.9°。任一失败就回退原图。

## 局限与建议

1. 只有 5 行且 y 覆盖刚过门槛时，消失点仍对单行误检敏感；正式接入前应扩大到更多真实手机图进行 ROC 调参。
2. 不应把此方案当作完整题卡矩形化。若题目区域含可靠页面四边，优先四角单应；若只有文字，可再估竖直线族/字符竖边以求第二消失点，否则保留当前的保守单消失点校正。
3. 正式实现必须保留“实际成图重新检测”的后验闸门，并在失败时无条件回退，不能只检查变换前端点的理论角度。
