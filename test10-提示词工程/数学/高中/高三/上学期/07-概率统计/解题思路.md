## 六、概率统计

### 14. 概率与分布

**核心思路**
- 古典概型：枚举/树状图；
- 条件概率、全概率、贝叶斯：先划分完备事件组；
- 分布列：取值 → 概率 → 检验和为 1 → 期望方差；
- 二项分布与超几何分布的判定（放回/不放回）；
- 正态分布：对称性 + $3\sigma$ 原则；
- 概率递推：马尔可夫链/状态转移（原文大招），建立 $P_n$ 与 $P_{n-1}$ 的递推式。

**易错点**：事件组不互斥；分布类型误判；递推初始状态遗漏。

### 14.1 古典、条件、全概率与贝叶斯（题型26）

**核心思路**

- 古典概型：先定样本空间（有序 / 无序、放回 / 不放回），再用计数或枚举；
- 条件概率：$P(B\mid A)=\dfrac{P(AB)}{P(A)}$，缩小样本空间；
- 全概率：按「来源 / 阶段」划分互斥完备事件组 $A_1,\dots,A_n$，$P(B)=\sum P(A_i)P(B\mid A_i)$；
- 贝叶斯：$P(A_k\mid B)=\dfrac{P(A_k)P(B\mid A_k)}{P(B)}$，分母用全概率算，结论写成「来自哪一类」；
- 独立重复试验：$P=C_n^k p^k(1-p)^{n-k}$。

**易错点**：划分不互斥 / 不完备；条件概率方向写反；「至少」用对立事件 $\ge1$ 个。

### 14.2 分布列模板与数字特征（题型27）

**核心思路**

1. 写出随机变量全部取值（先按题意穷举，再核对不重不漏）；
2. 逐值求概率（古典计数或条件概率）；
3. 列分布列并验证 $\sum p_i=1$（这一步常能发现前面算错）；
4. 求 $E(X)=\sum x_ip_i$、$D(X)=E(X^2)-E(X)^2$；
5. 线性变换用 $E(aX+b)=aE(X)+b$、$D(aX+b)=a^2D(X)$。

**易错点**：取值遗漏；方差忘记减 $E(X)^2$；期望写成分数后未化简。

### 14.3 二项、超几何、正态的判定

**核心思路**

- 二项 $B(n,p)$：$n$ 次独立重复、每次成功概率相同、有放回；
- 超几何：有限总体、分两类、不放回抽取；
- 正态 $N(\mu,\sigma^2)$：对称性 $P(X\le\mu)=P(X\ge\mu)=0.5$，$P(\mu-a<X<\mu+a)$ 型用对称区间，$3\sigma$ 原则估概率；
- 判定关键：先问「是否独立 / 是否放回」，再选分布。

**易错点**：不放回误判为二项；正态概率区间端点写反；$\sigma$ 与 $\sigma^2$ 混用。

### 14.4 统计案例：回归与独立性检验

**核心思路**

- 相关系数 $r$：$|r|\to1$ 相关性强，符号定正负；
- 回归直线过样本中心 $(\bar x,\bar y)$，用一点即可求参数或验证选项；
- 残差图带状均匀说明拟合好，出现喇叭形 / 弯曲说明模型不当；
- 独立性检验：算 $\chi^2$ 与临界值比较，结论写「有 …% 的把握认为 A 与 B 有关」。

**易错点**：相关不等于因果；结论不能写「证明有关」；$\chi^2$ 公式分子忘平方。

### 第83讲 统计
**核心思路**
- 不论采用哪种抽样方法，总体中每一个个体入样的概率都相同（题型一总结的唯一结论）。
- 分层抽样就是按比例抽样：样本容量/总体容量 = 各层样本数量/各层个体数量，据此求某层应抽数量，或由某层数量反求总体容量（列比例式）。
- 频率分布直方图：纵坐标是「频率/组距」，故面积=频率，各小矩形面积和为 1；频率×样本容量=频数。
- 由直方图估数字特征：众数取最高矩形底边中点的横坐标；中位数令左右两侧面积各为 0.5；平均数等于各矩形面积乘其底边中点横坐标之和（直方图的「重心」）。
- 百分位数三步：原始数据从小到大排序 → 计算 i=n×p% → i 非整数时取大于 i 的最小整数项，i 为整数时取第 i 项与第 i+1 项的平均。
- 数字特征分工：平均数、中位数、众数刻画集中趋势，方差、标准差刻画波动大小；数据经 ax+b 变换后平均数为 ax̄+b、方差为 a²s²。

**易错点**
- 直方图的纵坐标是频率/组距而不是频率（题型三总结专门点出）。
- 随机数表法必须在查看随机数表之前就指出开始数字的横、纵位置，才能保证所选数字的随机性。
- 方差可用「原数据平方的平均数减去平均数的平方」简化计算，直接套定义易算错。

### 第84讲 成对数据的统计分析
**核心思路**
- 相关关系不同于函数关系：它是非确定关系，且不一定是因果关系，也可能只是伴随关系。
- 判定相关性的三条路径：散点图走向（左下到右上为正相关，左上到右下为负相关）；样本相关系数 r 的符号与绝对值（越接近 ±1 相关性越强）；经验回归方程斜率 b 的符号。
- 求经验回归方程：先用数据算样本中心点，再按最小二乘公式算 b、a，写出 ŷ=bx+a；回归直线必过样本点的中心。
- 拟合效果三指标：残差图落点是否均匀分布在水平带状区域（带越窄越精确）；残差平方和越小越好；相关指数 R² 越接近 1 越好。
- 非线性回归统一套路：由散点图选函数类型 → 换元化为线性（指数型两边取自然对数、对数型令 x′=lnx、幂函数型取常用对数、二次型与反比例型换元）→ 按线性回归求系数 → 消去新元还原。

**易错点**
- 回归直线可能不经过散点图中任何一个样本点，但一定经过样本中心 (x̄,ȳ)；「经过点最多」的说法是错的。
- 相关性越强是指 r 越接近 1 或 −1（负相关时应接近 −1），只说「接近 1」会漏掉负相关情形。
- 相关关系不一定是因果关系，不能由统计相关直接下因果结论。

**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第84讲成对数据的统计分析.pdf`（OCR 第1—28页，原文标注停在第28/51页）

### 第88讲 随机事件、频率与概率
**核心思路**
- 写样本空间必须明确事件发生的条件，按一定次序列出结果，保证机会均等、不重不漏。
- 事件的关系与运算类比集合：包含、相等、并（和事件）、交（积事件），可借 Venn 图分析。
- 互斥：不能同时发生（AB=∅）；对立：有且只有一个发生（A∪B=Ω 且 AB=∅）。对立事件一定是互斥事件，互斥事件未必是对立事件。
- 频率是随机的，概率是确定的常数；大量重复试验中频率稳定于概率，因此可用频率估计概率。
- 进行事件运算时一要扣定义，二要全面考虑同一条件下试验可能出现的全部结果，必要时列举全部结果分析。

**易错点**
- 互斥事件可以同时不发生，对立事件必须有一个发生——判断「互斥而不对立」正是看能否同时不发生。
- 频率不等于概率，只能用足够多次试验的频率近似估计概率。
- 「至少」「至多」型问题直接用互斥加法易漏算，应结合对立事件考虑。

**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第88讲随机事件频率与概率.pdf`（OCR 第1—21页）

### 第89讲 古典概型与概率的基本性质
**核心思路**
- 古典概型两个特征缺一不可：样本点有限、每个样本点等可能。
- P(A)=事件 A 包含的样本点数 / 样本空间样本点总数，解题关键是数清总数 n 与事件内个数 m。
- 四步流程：读题理解背景 → 判断是否等可能并设出事件 A → 分别求 n 与 m → 代入古典概型公式。
- 计数手段：列举法、列表法、树状图法；复杂事件用互斥事件加法公式或对立事件（正难则反），「至少/至多」型优先用间接法。
- 交汇题（与向量、几何、函数、数列、统计交汇）四步：把条件翻译为事件 → 判断是否古典概型 → 选合适方法确定样本点个数 → 代公式求解。
- 有放回与无放回要分清：不放回依次抽取时，某一次抽到某类球的概率可借全概率或对称性直接得出（不必逐一列举）。

**易错点**
- 必须先验证「等可能性」，非等可能的试验不能套用古典概型公式。
- 基本事件要按规律列举，做到既不重复也不遗漏。
- 「至少」型若正面分类太多，应改用对立事件计算。

**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第89讲古典概型与概率的基本性质.pdf`（OCR 第1—29页，原文标注停在第29/37页）

### 第90讲 事件的相互独立性、条件概率与全概率公式
**核心思路**
- 条件概率 P(B|A)=P(AB)/P(A)，竖线后面就是条件，且必须 P(A)>0；定义法三步：分析题意弄清模型 → 算 P(A) 与 P(AB) → 代入公式。
- 相互独立 ⟺ P(AB)=P(A)P(B)；当 P(A)>0 时也等价于 P(B|A)=P(B)。判断独立有三种方法：定义法、由事件本身性质直接判定、条件概率法。
- 独立事件同时发生的概率等于各事件概率之积，可推广到 n 个事件；独立事件的对立事件之间仍相互独立。
- 全概率公式：先把样本空间做「互斥完备划分」A₁…Aₙ（两两互斥、并为 Ω、各概率为正），再对每种情形求 P(Aᵢ)P(B|Aᵢ) 并求和，体现「化整为零、各个击破」。
- 贝叶斯公式由果溯因：已知结果 B 反推原因 Aᵢ，三步走——用全概率公式算 P(B)、用乘法公式算 P(AB)、代入 P(Aᵢ|B)=P(AᵢB)/P(B)，结果是后验概率。
- 综合应用先列事件并用符号表示，再理清事件间关系，用「并」「交」表示所求事件后套公式。

**易错点**
- P(A)=0 表示条件 A 不可能发生，此时条件概率无意义，计算必须在 P(A)>0 下进行。
- 若 A 发生会影响 B，则 P(B)≠P(B|A)，不能把条件概率当成无条件概率使用。
- 全概率公式使用前必须验证划分的三个条件（两两互斥、并为全集、每个概率为正），否则不能套用。
- 全概率是「由因求果」，贝叶斯是「由果溯因」，两者不能混用。

**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第90讲事件的相互独立性条件概率与全概率公式.pdf`（OCR 第1—29页，原文标注停在第29/38页）

### 第91讲 离散型随机变量的分布列与数字特征
**核心思路**
- 分布列四步：审题 → 计算随机变量取每个值的概率 → 列表并检验概率之和是否为 1 → 按均值、方差公式求解。
- 分布列性质的三种用法：用「概率和为 1」求参数值或取值范围；用「某范围内概率等于该范围各取值概率之和」求特定事件概率；用 pᵢ≥0 与 Σpᵢ=1 检验写出的分布列是否正确。
- 均值 E(X)=Σxᵢpᵢ 刻画取值的「中心位置」；性质 E(aX+b)=aE(X)+b、E(X₁+X₂)=E(X₁)+E(X₂)、X₁、X₂ 独立时 E(X₁X₂)=E(X₁)E(X₂)。
- 方差 D(X)=Σ(xᵢ−E(X))²pᵢ，也常用变形 D(X)=E(X²)−[E(X)]²；D(aX+b)=a²D(X)。
- 遇到「有几类盈利」这类由若干独立小事件合成的随机变量，可借期望的线性性把它拆成简单变量之和再求期望。
- 随机变量所取的各值对应的事件两两互斥，可借此求相关事件的概率。

**易错点**
- 均值只刻画「中心位置」：分布完全确定均值，但不同分布可以有相同均值，均值不能完全决定随机变量。
- 分布列写出后必须检验概率之和为 1，这一步也是发现错误的主要手段。
- 方差的单位是随机变量单位的平方，标准差才与随机变量同单位。

**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第91讲离散型随机变量的分布列与数字特征.pdf`（OCR 第1—30页，原文标注停在第30/45页）

### 第92讲 两点分布、二项分布、超几何分布与正态分布
**核心思路**
- 两点分布只有两个结果且概率和为 1，P(X=1)=p 为成功概率，E(X)=p，D(X)=p(1−p)；它正是 n=1 时的二项分布。
- n 次独立重复试验三条件：每次同条件进行、各次相互独立、每次只有两种结果；此时「事件发生次数」服从二项分布 B(n,p)，P(X=k)=C(n,k)p^k q^{n−k}，E(X)=np，D(X)=np(1−p)。
- 两种分布的分水岭在抽样方式：二项分布本质是「有放回」，每次概率相同；超几何分布本质是「不放回」，需知道总体容量与各类个数，每次概率不同。
- 二项分布五步：设随机变量 → 判断服从二项分布 → 定参数 n、p → 写出分布列 → 代入 k 求概率；求「某范围概率」时转化为几个互斥事件之和或用对立事件。
- 正态分布：曲线关于 x=μ 对称、与 x 轴围成面积 1，σ 越小曲线越「高瘦」越集中；求概率时先定 μ、σ，再把所求区间向 (μ−σ,μ+σ]、(μ−2σ,μ+2σ]、(μ−3σ,μ+3σ] 转化，用对称性与总面积 1 求解。
- 3σ 原则：取值落在 (μ−3σ,μ+3σ) 内概率为 0.9974，落在外面的 0.0026 属小概率事件，可作为「出现意外情况」的判断依据。

**易错点**
- 使用独立重复试验的概率公式前必须先确认满足三条件，不符合时不能套用公式。
- 二项分布（有放回）与超几何分布（不放回）不可混用；超几何需要总体容量，二项分布不需要。
- 求「恰好发生 k 次」时先定准 n 与 k 的值，再代公式，n、k 弄错是最常见失误。
- 正态概率题要先由条件定 μ、σ，再向三个标准区间转化；超出 (μ−3σ,μ+3σ) 应说明出现意外情况。

### 第93讲 概率与统计的综合应用
**核心思路**
- 本讲无「知识梳理」也无「解题方法总结」板块，开篇即进入题型归纳，方法全部体现在各例解析中。

### 第83讲 统计 · 续
**补充思路**
- 直方图题求参数：由「各组频率之和为 1」列方程求纵坐标或未知频率；再由「某组频数 = 组距 × 纵坐标（频率/组距）× 样本容量」或频率 = 面积求部分条形的频数（例中为「(85−80)×纵坐标×样本容量」求某段人数）。
- 由直方图求百分位数与中位数：按累计频率找到所在组后在该组内作线性插值，即「累计到下界前的频率 + (该频率缺口/该组频率)×组距」；源文另给两种求百分位数的做法——从下往上累加与从上往下用剩余频率逼近。
- 直方图估平均数与方差：平均数取各组区间中点值与对应频率之积之和；方差取各组「(中点 − 平均数)² × 频率」之和。
- 已知分组数据的各组人数与方差求合并方差（题型八「分层方差问题」，源文【解题方法总结】）：先按各组人数加权求总平均数，再按「合并方差 = 各组人数 × [组内方差 + (组均值 − 总均值)²] 之和 ÷ 总人数」计算；用频率代替人数时把人数换成各组频率，分母为 1。
- 用平均数与方差表判断成绩：均值相同（或相近）时判断平均水平相当，再由方差（或标准差）小的一方数据更集中判断发挥更稳定；方差可按「平方的平均数减平均数的平方」计算；剔除个别数据后由保留的数据平方和重算均值与标准差再比较稳定性。
- 茎叶图比较：茎叶图能直观看出数据分布形状，均值相近时比较两组数据的离散程度，叶子更集中的一组方差更小。

- 百分位数落在某组内时要在组内插值，不能直接取下界或组中点。

### 第84讲 成对数据的统计分析 · 续
**补充思路**
- 指数型回归的具体流程：对 y = a·b^x 两边取自然对数，令新变量为 y 的自然对数，则化为「新变量 = 截距 + 斜率 × x」的一元线性方程，按最小二乘公式求斜率与截距，再由「底数等于斜率的指数、系数等于截距的指数」回代得 a、b，预测时代入年份代码。（源文【解题方法总结】概括为「换元法变成一元线性回归模型」。）
- 由换元后的两变量「落在直线附近」的题型：先对新变量作线性回归再还原为原函数形式，接着用还原后的函数解不等式（如函数值不小于某数）选对应取值，再在该取值对应的四类中算概率（如选中某款套餐的人数服从超几何分布，按组合数写分布列）。
- 列联表与独立性检验的标准步骤（源文【解题方法总结】）：一是整理出 2×2 列联表；二是按卡方公式计算观测值（公式为「样本量 × (ad − bc)² ÷ 四个合计之积」）；三是与临界值表比较，按选定的显著性水平作出推断；推断时先设零假设「两分类变量无关联」，计算值小于临界值则「没有充分证据推断零假设不成立，可认为二者无关」。
- 由卡方结论反求样本量或列联表中的未知数：令卡方观测值不小于（或不大于）临界值建立不等式，解出样本容量或某单元格数值的最小值（或范围），再夹出总人数。
- 等高（堆积）条形图读比例比较两类中某事件发生人数的多少；比较两种关系强弱的题依据卡方值大小判断（卡方越大关系越强）。
- 列联表与概率交汇：由列联表人数比例求两事件概率（如点球大战第二阶段甲胜概率，事件「双方进入第二阶段」与「第二阶段第一轮甲进球乙未进」独立，所求概率为二者之积）；进入第二阶段的概率按「第一阶段五轮比分可为 3:3、4:4、5:5」列举求和。
- 列联表后求超几何分布：从某类中抽出若干人，抽到特定类别的人数服从超几何分布，用组合数写分布列。
- 直方图＋扇形图填列联表：先由两图比例推出各分组人数再填表；上四分位数由累计频率在对应组内插值；分层抽样后求条件概率，再以「某条件下抽出类别的人数」为随机变量列分布列。
- 「关系系数」型问题：把两种分类下某条件的概率作比值定为关系系数，用全概率与条件概率（逆条件）把比值表示为已知概率与待求量的式子，列方程求解后比较两组系数说明哪类更显著。
- 误差分析（题型五）：由样本中心与均值求出回归方程的截距（斜率给定），再计算各样本点实际值与预测值之差的绝对值（残差绝对值），绝对值最小者拟合最好。
**补充易错点**
- 独立性检验的推断表述不能写成「证明有关」；卡方值小于临界值时只能说「没有充分证据推断零假设不成立」，即认为无关。
- 比较两类关系强弱看卡方值大小，不看单一比例的高低。

### 第89讲 古典概型与概率的基本性质 · 续
**补充思路**
- 有放回／不放回序列的「第 k 次取得某色」：按前几次的颜色分情况写路径概率再求和（如第 3 次取红，分前两次的颜色组合分别求积后相加）；也可用样本点计数法，以「某事件包含的样本点数 ÷ 条件事件的样本点数」直接求条件概率。
- 不放回但后摸者不知先摸结果：后者的概率按「前一人取红」「前一人取白」两种情形分别求积后相加（即全概率思想），结果与前者相同。
- 「直到两种颜色都出现」的取球次数：按取球次数分情况计数（注意最后一球颜色与前几球都不同），写分布列再求期望。
- 轮流抽签「先抽者不中」：用列举情形表写出后抽者中签的情形数，再在剩余签数中计算概率。
- 「直到某色全部取出」：按取球次数分情况，用组合数表示「前若干次中含该色全部球、最后一球为该色」等情形计数后求和。
- 分层抽样后借概率反求各类件数：先按比例求各层件数，再用「已知概率」列关于某等级件数的方程；含参数概率的式子整理成最简分式后对分母配方，用基本不等式求概率最大值，参数取整数时比较相邻整数值。
- 二项分布型的「至少」概率：如「至少三株成活」按组合数求和后乘样本总数得「约多少」；条件概率型「已知通过求优秀」把条件事件分成互斥的「答对 6 题」「答对 5 题」「答对 4 题」三部分，用各部分概率除以条件概率。
- 「各类至少取 1 个」：按组合数计算「各类数量之和」的取法。
- 独立选择的相遇／同车厢问题：如三人随机选车厢「恰有两人同车厢」，把「选定一对同车厢、第三人不同车厢」的各种情形概率相加。
- 求复杂互斥事件的概率两种方法（源文【解题方法总结】）：一是直接法——把所求事件分解为几个互斥事件之和，分别求各事件概率，再用互斥事件加法公式求和；二是间接法——正难则反，尤其「至多」「至少」类问题，间接法较少分类、更简单。
**补充易错点**
- 「恰有 2 人同车厢」等问题容易漏算或重算「哪两人同」的分类，须按「选哪一对」分别列举再相加。
- 不放回序列求第 k 次某色概率时须按前几色分情况，不能直接套「颜色占比」当每次概率。

### 第90讲 事件的相互独立性、条件概率与全概率公式 · 续
**补充思路**
- 多工厂产品合格率问题：以「产品来自哪个厂」为划分用全概率公式得总不合格率；已知抽到次品求来自某厂用贝叶斯公式（后验概率）；若一次抽取多件、「抽到的次品中来自某厂的件数」服从二项分布，可先求该厂次品率，再用二项分布得分布列与期望。
- 多台车床加工问题：以「由第 i 台车床加工」为划分用全概率公式求次品率，再由后验概率得「由第 i 台车床加工」的条件概率，据此构造耗时等随机变量的分布列与期望。

- 由 P(A|B)、P(B|A)、P(B) 反求 P(A)：用条件概率定义展开得到关于 P(A) 的方程解出，并说明所得值在实际背景中的意义（如某事件发生的概率）；扩大样本容量 k 倍时卡方值近似放大 k 倍，据此解出 k。
- 多局多胜制中「关键人物上场」为随机事件：全概率公式按「该人物上场」「未上场」两类求最终获胜概率；已知获胜反求上场概率用贝叶斯公式。
- 多选题正确选项个数取 2 个或 3 个的概率递推：设第 n 题「有 3 个正确选项」的概率，按「上一题有 3 个选项」「有 2 个选项」两类用全概率递推，得到一阶递推式后构造等比数列求通项。
- 比较「猜选 1 个选项」与「猜选 2 个选项」的得分期望作决策。
- 分层样本的合并均值与方差后接概率题：先求合并均值、合并方差，再接「从甲箱抽两件放入乙箱后乙箱某条件」求甲箱所抽两件的条件概率（贝叶斯）。
- 两阶段试验选用公式（源文【解题方法总结】）：第一阶段结果未知、求第二阶段某结果概率，用全概率公式；第二阶段结果已知、求它由第一阶段某结果引起，用贝叶斯公式。

- 由条件概率反求 P(A) 时方程可能有两解，须按概率落在 0 到 1 之间及实际背景取舍。
- 后验概率题（贝叶斯）中分母是「全概率公式所得结果」，不能误用条件事件的概率。

### 第91讲 离散型随机变量的分布列与数字特征 · 续
**补充思路**
- 均值方差性质的应用（源文【解题方法总结】）：新变量是原变量的函数时一般仍为随机变量，可借期望的性质与线性变换的期望方差公式直接求，避免重新求其分布列。
- 用马尔科夫不等式估计概率：对非负随机变量，随机变量不小于某正数的概率不超过「期望 ÷ 该数」；源文例题给出其证明。
- 用切比雪夫不等式估计偏离：随机变量与均值之差的绝对值不小于某数的概率不超过「方差 ÷ 该数的平方」；可对「原变量减均值的平方」用马尔科夫不等式推得。用于检验「治愈率达到某宣传值」等说法的可信性。
- 决策问题（题型六）：把各方案的晋级概率或收益写成参数的函数，比较二者大小选方案——比赛局数可变（如每轮赛制）时需构造关于局数的函数并用单调性判断哪个方案更大。
- 多选题按猜选选项数分别算得分期望，取期望最大者。
- 按已知的频率分布（表或直方图）算单件利润（净收益）的期望，比较不同进货量方案取期望最大者；易损零件的采购量按「总费用期望」比较，选期望更小者。
- 先验概率经观察数据用贝叶斯公式调整后，再比较方案（如先按先验算方案优劣，观测到结果后更新概率再决策）。

### 第92讲 两点分布、二项分布、超几何分布与正态分布 · 续
**补充思路**
- 超几何分布判断题：直方图求未知参数与中位数后分层抽样，再从不放回抽出的样本中求某类件数的分布列与期望；已知抽出球的颜色数反求白球数后求期望；从若干箱子中抽若干箱、从若干村中抽若干村等「不放回抽取」都为超几何分布。
- 超几何分布的判断与步骤（源文【解题方法总结】）：一是「不放回抽取 n 次」；二是随机变量表示抽到的次品（或类似指定类别）件数。求分布列三步：验证并确定总体容量、指定类别总数、抽取次数 → 计算各取值的概率 → 列分布列。
- 二项分布与超几何分布的综合应用（题型五）：同一摸球问题分别按「不放回抽三次」与「有放回抽三次」列两种分布，算付款（收益）期望后比较取较大者。
- 直方图分层后求超几何分布；再由「服从二项分布且某概率最大」求 k——当参数使分布对称（成功概率为二分之一）时最大概率在 k 为次数一半处。
- 「某事件发生 k 次概率最大」：令相邻两概率之比不小于 1（即 P(k+1)/P(k) ≥ 1），解出 k 的范围并取整数；超几何分布中该比值可用组合数之比的单调性求解。
- 「体育迷」等身份二项分布：把「恰有若干人为体育迷」的概率按二项分布求，再接分层抽样后的超几何分布。
- 超几何分布与二项分布的区别（源文【解题方法总结】）：一是超几何分布需已知总体容量（各类总数），二项分布不需要；二是超几何分布为不放回抽取、每次概率不同，二项分布为有放回（或独立重复）、每次概率相同。
- 正态密度函数（题型六）：若某变量服从标准正态，由线性关系得另一变量的分布函数，利用标准正态分布的对称性（分布函数满足关于某点对称的关系）判断其图像形状。
**补充易错点**

### 第92讲 两点分布、二项分布、超几何分布与正态分布 · 续
**补充思路**
- 正态密度函数的参数：由正态密度函数表达式对照标准形式直接读出均值 μ 与标准差 σ。
- 正态曲线形状比较：均值相同则由曲线峰值位置与宽度判断，峰更尖陡的 σ 更小，曲线越扁平 σ 越大；不同曲线在均值对称轴两侧对应区间围成的面积比较概率大小。
- 正态变量关于均值对称的等价概率：利用 P(X≥μ)=0.5、P(X≤μ−t)=P(X≥μ+t)，将所求区间拆成两段对称区间再作差。
- 正态分布与函数、二项分布结合：先由函数单调（如分段函数在 R 上递增）求出参数概率，从而得 μ；再按对称性与 3σ 区间把所求概率化成两段标准区间概率之差。
- 正态对称性求参数：由 P(X≤a)=P(X≥b) 得 a、b 关于均值对称，即 a+b=2μ；随后用均值不等式求 a²+b² 的最小值，或求分式型表达式的最小值。
- 正态分布的实际应用：由频率分布直方图先估样本平均数，令 μ 取该估计值，σ 题给；用 μ+kσ 作为分界线，由 3σ 数据求出单侧尾部概率，再乘总人数估计人数。
- 二项分布概率关于参数的极大值点：以百分数 α 为参数、令 x=α/100，写出恰有 k 个成功的概率（组合数乘 x 的 k 次方与 1−x 的其余次方），求导令导数为零得 x=k/n，即极大值点为 n 分之 k；确定该概率后再由二项分布期望分别算两种奖励方案的期望，比较成本高低。
- 样本均值的分布：总体服从正态分布时，从中随机抽取 k 个数据，样本均值服从均值为 μ、方差为总体方差除以 k 的正态分布；据此可把「平均质量是否达标」化为样本均值偏离 μ 几个标准差的问题。
- 小概率事件反证：把观测到的极端结果化成「偏离均值至少若干个标准差」的事件，算出其概率小于 0.05，即属小概率事件；小概率事件基本不发生，一旦发生便有理由怀疑原假设（如商家宣称的平均质量）。
- 二项分布的最可能成功次数：n 次独立重复试验成功次数服从二项分布时，最可能次数 k 取 (n+1)p 的整数部分（向下取整）；也可由相邻两项概率之比与 1 的大小比较，得 P(X=k) 在 (n+1)p 前递增、其后递减，从而定出最大值点。
- 由人数占比反查分数：把「不低于某分数的人数占比」看作尾部概率，用对称区间概率化成 μ 减若干倍 σ 的形式（如占比 0.84 对应 μ−σ），或化为 1 减累积概率后查标准正态表反求标准分，再由「标准分×σ＋μ」还原为分数。
- 直方图分层再抽样与条件概率：先由频率分布直方图求各区间的频率，按分层抽样定出各部分人数；再以组合数分别算「抽测结果来自不同区间」与「其中若干份来自指定区间」的联合概率，作商得条件概率。
- 标准正态化与 Φ 的对称性：令「观测值减 μ 再除以 σ」得标准正态变量，记 Φ(a)=P(Y≤a)；标准正态曲线关于 0 对称，故 Φ(−a)=P(Y≥a)=1−Φ(a)，从而 Φ(−a)+Φ(a)=1，可把所求概率化为查表值。
- 3σ 原则判异常：由题给正态分布的方差开方得 σ，若样本值落在 μ±3σ 之外，其发生概率极小，可作为停止生产、报警的依据。
- 赛制积分问题：按「3:0、3:1、3:2」三类比分分别用组合数写出概率（3:1 与 3:2 需规定最后一局为胜者赢），求导得单局胜率的最优值，再以该值算各积分的分布列与提前夺冠的临界比较。
- 等级赋分反查原始分：已知各等级人数占比及各等级对应的赋分区间，用标准正态表由累积概率反查标准分值，再按「标准分×标准差＋均值」还原为原始分，得到合格线等临界分数。
- 正态分布与二项分布两阶段：由直方图得 μ 与 s²，把阈值写成 μ 减若干倍 σ，用单侧尾部概率得单个个体满足条件的概率 p；再视抽取的个体数服从二项分布，用对立事件求「至少一个」的概率及期望。
- 二项分布正态近似反求容量：n 较大时以正态近似二项分布，均值 np、方差 np(1−p)；用标准正态表求现有容量不够用的概率，再由要求的概率（如 0.7）对应查表值反算所需容量并向上取整，注意先验证取整前的概率是否达标。
- 相邻 σ 分界带概率：把区间端点写成 μ 加减若干倍 σ，相邻两个对称区间的概率之差除以 2 即为两条分界线之间一侧的概率；据此求正态分布下各分段的数量，再算每段利润或产量。
- 正态分布估排名：已知某分数，先标准化为标准分、查表得该分数以上的概率，乘以总人数即得大致排名；已知达标比例反求分数线的方法同上。
**补充易错点**
- D(aX+b)=a²·D(X)，正态分布的「参数」是 N(μ,σ²)，方差是 σ²，D(X) 是方差而不是标准差；题目给出 N(10,2²) 时 D(X)=4。
- 正态曲线并非都关于 y 轴对称，只有标准正态分布曲线才关于 y 轴对称。

- 混合检测期望推导：混管化验次数分布由多次二项分布给出，用求和技巧（i 乘组合数化回组合数）求出期望关于每管人数 k 的函数，再求该函数在 k 为某数因数时的最值（用函数单调性）。

- 检测标准下的误诊率与漏诊率：把临界值 c 落在直方图某组内，按组内均匀分布假设用频率密度乘区间长度求概率，得到误诊率关于 c 的分段函数，再求其最小值。
- 马尔科夫与切比雪夫不等式：非负离散型随机变量可用马尔科夫不等式证明切比雪夫不等式（对 |X−E(X)|² 用马尔科夫不等式），再用于实际检测问题。
- 两个独立因素乘积的分布：亩产量与单价互相独立时，收购总价的取值等于两者相乘，同一数值由多个组合得到时要把对应概率相加；求出期望后与增收成本比较，给出是否推广技术的建议。
- 车型（方案）选择的统计建议：用频率估计概率写出两车型出租天数的分布列并比较期望；期望相近时再比较「出租天数集中在中间区间」的比例，集中程度高者更稳定，据此给出购买建议。
- 分组混检次数的期望式：每组 k 人的检测次数只取 1（混管阴性）或 k+1（混管阳性则逐个再检），期望等于 (k+1) 减去 k 乘阴性概率的 k 次方；乘以组数得总次数期望，比较不同分组人数后取次数少者。
- 出险与自费修车的判断：由回归方程预测该车保费，再按「再出险一次保费倍率提高的百分点」乘保费得增加额，与自费维修费比较，增加保费大于维修费则接受自费维修。
- 按题序抽取的得分期望比较：把总得分写成答对题数的表达式；题数少的方案按前一题答对、答错两类分别求条件期望再加权，题数多的方案直接用二项分布求期望，比较后选期望大的抽取方式。
- 交换球类马尔科夫链：设甲盒处于各关键状态的概率，按「取出什么球、换入什么球」列出下一状态概率的线性递推；对某线性组合（如 2 倍某概率加另一概率）取比值，证明其为等比数列，随机变量的期望写成各状态概率的线性组合，再由等比通项求期望。
- 接力型状态递推：设第 n 步某状态发生的概率，由「上一步在该状态」与「上一步不在该状态」两类转移相加列递推式（形如 P 等于 a 倍 P 加 b），用待定系数或不动点构造等比数列求通项；箱子逐个传递取球的递推同属此类。
- 抽红球不放回、抽黑球放回的递推：设第 i 次抽到红球的概率，按红球数减少与黑球放回写出递推并求通项；「恰在第 n 次抽到第 2 支红球」按前 n−1 次恰有 1 支红球、第 n 次抽红球列出表达式。
- 闯关类分布：每关前先掷硬币，反面即终止，按「通过某关」与「止于某关」逐关相乘求概率；分布列含未通过、通过 1 关、通过 2 关三类，最后一类可由总概率为 1 反推。
- 随机步长落点问题：设到达各标号环的概率，按「从前两步位置移动过来」两种来源列递推，相邻两项作差后构成等比差分（公比为负的某分数），累加得通项；也可按总移动距离与移动次数列举组合求同一概率。
- 抛硬币次数不同的比较：先考虑两人各抛 n 次的情形，设「次数相等」「甲多」「乙多」三事件的概率；由对称性甲多与乙多的概率相等，二者各占（1 减相等概率）的一半；甲多抛一次时只有「相等」情形能被改写为甲多（须第 n+1 次为正面），故所求概率等于「乙多」的概率加「相等」概率的一半。
- 敏感问题调查的随机化回答：由摸球决定回答敏感问题还是无关问题，用全概率公式把回答「是」的比例写成「摸到黑球概率乘真实比例」加「摸到白球概率乘无关问题答是的概率」，反解出真实比例的估计值。
- 比赛出场顺序的优化：各对手胜率不同时，把「连胜两场」的概率写成相应胜率乘积，逐一枚举六种出场顺序比较取最大；若要让需派出的人数或组数的期望最小，则按成功率从大到小安排，可用交换两项后作差证明大者在前更优。
- 高尔顿板模型：小球每次碰钉等可能向左或向右，落入格子的号码等于向右的次数，服从二项分布；分布列关于中间格子对称；奖金设为格号的函数时，先用分段函数写出奖金取值，再算奖金期望与收费比较，判断摆摊者能否盈利。
- 分赌注（继续比赛）问题：比赛中断后按「继续下去各自获胜的概率之比」分配赌注；求某人获胜概率时按还需进行的局数分类，最后一局必须由该人赢，前面若干局用组合数乘胜负概率，各类相加。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第93讲概率与统计的综合应用.pdf`（OCR 第60—114页）

### 概率统计 · 概率计算公式法（核心方法 第235—236页）
**核心思路**
- 先判断事件的逻辑关系（互斥、对立、独立、条件依赖），再选公式：古典概型计数；互斥加法（非互斥用容斥）；对立事件「$1-$ 反面」；独立乘法；条件概率；全概率（按完备事件组划分来源/阶段）；
- 「抽到不同主题 / 不同物品」类等可能抽取：直接算或用对立事件「相同」算更快；
- 已知两个条件概率与 $P(A)$ 求 $P(B)$：用全概率公式把 $P(A)$ 按 $B$、$\overline B$ 两条路径展开，得到关于 $P(B)$ 的方程一次解出；
- 不放回摸球给出黑球数求「抽到特定配置」概率最大：写出超几何分布概率，把含球数的因子整理成多项式函数，用求导或单调性取整数最优点。
**易错点**
- 公式选错（把条件概率的分子分母写反、把独立误当互斥叠加）；
- 「至少/至多」优先用对立事件，避免硬分类重复计数；
- 超几何概率最值点的自变量是球的个数，须取整数取值检验。
**依据**：`题库/2027版 数学核心方法 高一 高二 高三/高三数学核心方法_351.pdf`（OCR 第235—236页）

### 概率统计 · 统计数据分析法（核心方法 第239—241页）
**核心思路**
- 集中趋势：平均数（直方图中为「每组中点 × 该组频率」之和，线性变换后为 $a\bar x+b$）；众数（直方图取最高矩形中点横坐标）；中位数（直方图左右面积相等）；
- 离散程度：极差 = 最大 − 最小；方差 $=$ 平方的平均数 − 平均数的平方，或按定义逐项算；标准差为方差开方；数据变为 $ax+b$ 后方差为 $a^2 s^2$；
- 百分位数：排序后按「$n\times p\%$」定位，落在直方图某组内时在该组内作线性插值（累计频率达到 $p\%$ 的横坐标），中位数即第 50 百分位数；
- 分层抽样：总平均数按层权重加权；总方差为各层「层内方差 + (层均值 − 总均值)²」按权重加权之和——不是简单加权平均；
- 已知平均数与方差反推数据：由平均数列总和、由方差列「平方和 = $n$ 方差 + $n$ 均值²」，再结合数据取值（如骰子点数）分类讨论；
- 增加数据后新方差最小：把新数据与旧数据分开写，旧部分用均值、平方和整体代入，新部分用均值与平方和基本不等式求最小。
**易错点**
- 直方图纵坐标是「频率/组距」不是频率，求数字特征时要乘组距；
- 合并方差必须用含「层均值与总均值偏差」的公式；
- 百分位数落在组内要插值，不能直接取组中点。
**依据**：`题库/2027版 数学核心方法 高一 高二 高三/高三数学核心方法_351.pdf`（OCR 第239—241页）

### 概率统计 · 独立性检验公式法（核心方法 第244—246页）
**核心思路**
- 判断两个分类变量是否有关联：先写出零假设「$X$ 与 $Y$ 无关」，整理完整 $2\times2$ 列联表，再代入卡方公式（样本量 × 对角线乘积之差的平方 ÷ 四个边际合计之积）；
- 把算出的卡方值与临界值表按给定小概率值 $\alpha$ 比较：大于等于临界值则推断零假设不成立，认为有关，结论写成「在犯错误概率不超过 $\alpha$ 的前提下可认为有关」；
- 小于临界值则「没有充分证据推断零假设不成立」，可认为无关；
- 列联表不完整时先由行列合计补齐空缺（行列合计等式确定每格），再代入公式。
**易错点**
- 卡方公式分子必须平方，$ad-bc$ 的符号不影响结果；
- 结论表述不能写成「证明有关」；推断描述要带上「犯错误概率不超过 $\alpha$」。
**依据**：`题库/2027版 数学核心方法 高一 高二 高三/高三数学核心方法_351.pdf`（OCR 第244—246页）

### 统计 · 模型80 分层抽样的按比例分配与反推（A049 第190—191页）
**核心思路**
- 逐层抽取量 = 该层个体数占总体的比例 × 总样本量；反之若已知各层抽取量（或它们的比例关系），可反求各层总数；
- 「抽取量成等差数列」等条件只决定各层抽取的比例，配合已知总量才能求具体数量；
- 抽样结果的计数：先算每层抽取数，再用组合数分层相乘（分步计数原理）。
**易错点**
- 抽样比是该层个体数除以总体个体数，不是样本量除以层个体数；
- 层内总数只能由「抽取量 / 抽样比」反推，不能只用比例关系臆定。
**依据**：`题库/【A049】高考数学解题模型一本通/高考数学解题模型一本通.pdf`（OCR 第190—191页）

### 统计 · 模型81 直方图的分步读图（A049 第192—193页）
**核心思路**
- 纵轴是频率/组距，面积即频率；先查各矩形面积和是否为 1 来验证读图；
- 中位数：从左向右累加面积，落在哪一组就在该组内令「左侧累计面积 + 该组面积 ×（x−左端点）/组距 = 0.5」解出；
- 平均数：各组「组中值 × 该组频率」之和；众数取最高矩形底边中点的横坐标；
- 比率类判断：某区间的比率等于对应各矩形面积之和，据此判断选项真伪。
**易错点**
- 纵轴若只标「频率」而未标「频率/组距」，须先确认组距是否为 1，否则不能把纵坐标直接当频率用；
- 中位数、百分位数必须在所在组内线性插值，不能取该组端点或组中值。
**依据**：`题库/【A049】高考数学解题模型一本通/高考数学解题模型一本通.pdf`（OCR 第192—193页）

### 概率 · 模型162 几何分布（首次成功的试验次数）（A049 第402—404页）
**核心思路**
- 识别：独立重复试验，考查“首次成功时试验的次数”；
- 分布：第 k 次才首次成功，前 k−1 次全失败、第 k 次成功，P(K=k)=(1−p)^{k−1}p（k=1,2,…，取值无上限）；
- 期望 E(K)=1/p（可用等差×等比错位相减推导，或直接用结论）；
- 无记忆性：前 m 次均失败后，从第 m+1 次到首次成功的次数分布与从第 1 次开始相同，即 P(K>m+n|K>m)=P(K>n)；
- 若限定“最多抽 n 次”，不再是标准几何分布，须逐项列分布列（前几次均失败的组合概率，另含“n 次都没抽到”的情形）。
**易错点**
- “抽 n 次为止仍没抽到”这一情形要单独列入分布列，不能漏；
- 几何分布的随机变量取值范围是全体正整数，不允许截断。
**依据**：`题库/【A049】高考数学解题模型一本通/高考数学解题模型一本通.pdf`（OCR 第402—404页）

### 概率 · 模型167 离散型概率最值（相邻不等式组）（A049 第417—419页）
**核心思路**
- 离散型随机变量不能求导，求“概率最大的取值”用相邻项比较；
- 写出 P(X=k) 的表达式（二项、超几何或按计数得到的概率），设 X=k 时概率最大，列 P(X=k)≥P(X=k−1) 与 P(X=k)≥P(X=k+1)，解不等式组得 k 的区间；
- 在区间内按 k 的实际约束（取值范围、人数上限）选整数 k；
- 若概率由集合计数得到（如“参加语文或数学的人数”），先用容斥原理把“只参加一个”的人数用总人数与重叠人数表示，再列相邻比较；
- 求概率最小时的 k，不等式号反向。
**易错点**
- 比较式中的组合数约简时符号要保留，约分后不等号方向不能错；
- 解出的是区间时，要说明两端是否都能取；
- 题目的取值上限必须与解出的区间取交集。
**依据**：`题库/【A049】高考数学解题模型一本通/高考数学解题模型一本通.pdf`（OCR 第417—419页）

### 概率 · 模型168 枚举法（列举、树状图、正难则反）（A049 第419—422页）
**核心思路**
- 样本规模小、限制条件多、事件关系复杂时直接用枚举，比硬套计数公式更稳；
- 列举法：把符合要求的可能情况逐条写出再统计；
- 树状图法：按“逐步选择”画分支，适合有序排列、多轮比赛；
- 正难则反：符合条件的情况多、不符合的少时，列出不符合的情况，用 1 减其概率；
- 枚举按同一分类标准逐层展开（如按“甲哪几张牌赢”分类），保证不重不漏。
**易错点**
- 枚举前先确认每个基本事件等可能，否则不能直接用计数比；
- 分类必须按同一标准逐级展开，跨类混列会重复；
- “至多/至少”型常转成反面枚举更省。
**依据**：`题库/【A049】高考数学解题模型一本通/高考数学解题模型一本通.pdf`（OCR 第419—422页）

### 概率 · 模型169 马尔科夫链（一阶状态转移与随机游走）（A049 第423—425页）
**核心思路**
- 识别：下一状态的概率只依赖当前状态，用条件概率表述为 P(X_{n+1}|…,X_n)=P(X_{n+1}|X_n)；
- 设 P_n 为第 n 步处于目标状态的概率，用全概率公式由“前一状态”展开：P_{n+1}=P(目标|目标)P_n+P(目标|非目标)(1−P_n)，得到 p_{n+1}=a·p_n+b 的递推；
- 解递推：构造等比（p_{n+1}+t=a(p_n+t)）求通项，n=1 时注意由抽签或初值给出初始状态；
- 随机游走：位置每次只移 ±1 时，P_i 只与左右邻居 P_{i±1} 有关；有吸收壁时两端概率已知，中间状态在“左右概率相等”的特殊情形下构成等差数列，由两端值定公差；
- 期望用可加性：每步是否成功服从两点分布，总期望=单步概率×步数（或对等比型概率求和）。
**易错点**
- 用全概率展开时确认“前一状态”只有两类，否则要设多个状态；
- 吸收壁边界概率要单独写出并代入定通项；
- “第 n 次处于某状态的概率”与“前 n 次中处于该状态的次数”是不同变量，前者递推、后者求期望。
**依据**：`题库/【A049】高考数学解题模型一本通/高考数学解题模型一本通.pdf`（OCR 第423—425页）

### 概率统计 · 几何概型五类（长度 / 面积 / 体积 / 会面 / 随机数模拟）（破题36招 第66—69页）
**核心思路**
- 几何概型的概率 = 满足条件的测度 / 全部基本事件的测度，先判断测度的维数：区间长度、平面面积、体积；
- 「两人在某时段内到达、等待不超过 t 分钟」型 → 设到达时刻为 (x,y)，条件化为 |x−y|≤t，在正方形内算两条平行线之间的面积比；
- 立体几何中随机取点/随机投点 → 用体积比；
- 无法算面积时题干给随机数模拟 → 用落在目标区域的点数占总点数的比例估计。
**易错点**
- 会面问题中两时刻的取值区间长度不同（不是正方形）时不要按正方形算；
- 测度维数选错（该用面积用了长度）会直接错。
**依据**：`题库/高中数学破题36大招(详例精编).pdf`（OCR 第66—69页）

### 概率统计 · 概率七类错解的辨析（等可能计数 / 互斥与对立 / 互斥与独立 / 条件概率次序 / 有序与无序一致 / 等可能与独立重复 / 可辨认与隔板）（破题36招 第150—153页）
**核心思路**
- 古典概型先确认基本事件是否等可能（摸球有序/无序要在分子分母统一口径）；
- 互斥 = 不能同时发生；对立 = 互斥且必有一个发生；P(A)+P(B)=1 是对立条件而非互斥条件；
- 独立 = P(AB)=P(A)P(B)；P(AB) 是同时发生，P(B|A) 是在 A 发生的条件下 B 发生，二者不同；
- 计数时「有序/无序」必须在分子分母中使用同一种（要么都排列，要么都组合）；
- 等可能（每个基本事件概率相等，用组合计数）与独立重复试验（每次试验概率相同，用二项分布）要区分；
- 元素可辨认（不同）与不可辨认（相同）决定是否需要除以排列/用隔板法。
**易错点**
- 用排列计分子、组合计分母，概率翻倍或减半；
- 把「每个结果等可能」与「每次试验独立重复」混为一谈，套错分布。
**依据**：`题库/高中数学破题36大招(详例精编).pdf`（OCR 第150—153页）

### 概率统计 · 二项分布的参数 p 有两个解时用 P(X=k) 比较筛选（黄金模板 第195页）
**核心思路**
- 题给 X~B(n,p)、D(X)=定值：由 np(1−p)=D 解出两个互为补的 p（p 与 1−p），不可直接取；
- 再用附加条件「P(X=k₁)<P(X=k₂)」判别：由相邻项之比 P(X=k+1)/P(X=k)=(n−k)p/[(k+1)(1−p)] 判断分布偏向，k 较大侧概率更大说明 p 取较大值；
- 确定 p 后即可算 E(X)=np 或求某点概率；

### 概率 · 古典概型用表格枚举与对角线补集（怎样解题 第241—242页）

**易错点**
- 表格中「两人结果相同」只落在对角线上，数格子时容易把对角线算进或漏掉。

### 概率 · 条件概率的缩样法与「已知影响」判别（怎样解题 第245—246页）
**核心思路**
- 三种求法按题型选：定义法（先求 P(A) 与 P(AB) 再代入公式）；样本点法（先求条件事件 A 的样本点数，再求 AB 的样本点数，取比值）；缩样法（只限古典概型：直接用缩小后的样本空间做古典概型计算，如不放回抽取时已知第一只是好的，就以剩下的 9 只为新样本空间计数）；
- 判别是否需要按条件概率处理：题干有「已知」「在……前提下」一般就是条件概率；没有这些字眼但已知事件的发生会影响所求概率（如不放回抽取），也要按条件概率处理；
- 条件概率满足可加性：A 条件下两个互斥事件 B、C 的并，概率等于各自条件概率之和；
- 特别分清 P(B|A) 与 P(A|B)：前者是 A 已发生时 B 发生的概率，后者反之，题目问哪一个要看「已知」的是谁。
**易错点**
- 把 P(B|A) 与 P(A|B) 混写；
- 直接按无条件古典概型用原样本空间计数，未缩小到条件事件内；
- 用样本点法时分子与分母的样本点数取自不同的样本空间。
