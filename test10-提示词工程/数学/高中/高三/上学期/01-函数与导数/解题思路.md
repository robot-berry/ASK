## 一、函数与导数

### 1. 函数性质综合

**核心思路**
- 奇偶性 + 单调性 → 解抽象不等式（把 $f(\cdot)$ 化为自变量不等式）；
- 对称性 + 周期性互换：两条对称轴 ⇒ 周期为轴距 2 倍；一轴一中心 ⇒ 周期为距离 4 倍；
- 与导函数相关的对称性：$f'(x)$ 的奇偶性、对称性反推原函数性质；
- 「奇函数 + 常数」模型：$f_{\max}+f_{\min}=2c$。

**通法优先**：能画图就画图，能代特殊值先估；结论仅用于选填提速。

### 2. 指对比较大小

**核心思路（原文三条）**
1. 利用指数/对数函数单调性；
2. 取中间值（$0,1,2,\frac12$ 等）分界；
3. 构造函数求导判单调（压轴题）。

**提速工具**：$e^x\ge x+1>x>x-1\ge\ln x\ge1-\frac1x$；糖水不等式（对数型）；作商法（同构型）。

### 3. 导数研究函数（题型08、题型09）

**核心思路**
1. 求导 → 通分/因式分解 → 解 $f'(x)=0$；
2. 含参：按导函数能否分解、根的大小、判别式符号分类（互斥、无漏、最简）；
3. 列表判号 → 单调区间 → 极值；
4. 最值：极值与端点值比较；
5. 二阶导处理一阶导符号（题型08 技法04）。

**易错点**：定义域；分类遗漏；极值点与驻点混淆。

### 4. 恒成立与能成立

**核心思路**
- 恒成立：$f(x)\ge a$ ⇔ $a\le f_{\min}$；
- 能成立：$f(x)\ge a$ ⇔ $a\le f_{\max}$；
- 能分离参数就分离；不能分离则构造函数分类讨论；
- 端点效应：先由端点求必要条件，再证充分性（原文明确「先必要后充分」）。

**易错点**：两者最值方向相反（原文【点睛】专门提醒）。

### 5. 导数压轴方法库

**核心思路**
- 隐零点：设 $f'(x_0)=0$，整体代换超越项；
- 同构：把不等式两边化为同一函数形式 $f(g(x))\ge f(h(x))$；
- 指对处理：「对数单身狗、指数找朋友」（原文口诀）——把对数单独放一边、把指数与多项式合并；
- 双变量：消元或比值/差值换元；
- 极值点偏移：对称化构造、比值换元、对数平均不等式；
- 拐点偏移：构造 $f(x_0+x)+f(x_0-x)$ 类函数；
- 切线夹/割线夹：用切线或割线给出函数上下界；
- 主元法：把参数视为主元构造函数。

### 6. 三次函数

**核心思路**：$f(x)=ax^3+bx^2+cx+d$，先求 $f'(x)=3ax^2+2bx+c$；对称中心为拐点；韦达定理处理零点关系；切线条数转化为切点方程解的个数。

### 第6讲 函数的概念
**核心思路**
- 概念判断：紧扣"一个 x 只能对应唯一 y"，用定义检验（取两个 x 使输入相同、输出不同即可排除）；图像与竖直直线 x=1 的交点至多 1 个。
- 同一函数：定义域与对应法则完全相同才是同一函数，先比定义域，再比化简后的对应关系。
- 解析式求定义域：列使各式有意义的不等式组（分母非零、偶次根号下非负、对数真数为正且底数正且≠1、零/负指数幂底数非零），求解集，写成集合或区间；实际问题的定义域还要结合实际意义。
- 抽象函数定义域：口诀"定义域指 x 的范围，括号内范围相同"——由外层已知定义域解出内层表达式的范围，再解 x；四则运算型取各基本函数定义域的交集。
- 定义域应用（含参）：逆向转化为恒成立问题（如二次式恒正需分类 a=0 与 a≠0，开合取判别式与首项系数条件）。
- 解析式求法：已知类型用待定系数法；已知 f[g(x)] 型，易配凑用配凑法、易换元用换元法；f(x) 与 f(-x) 或 f(1/x) 成对出现时用方程组法消元；给 x、y 满足的关系式可先赋特殊值再赋 y=-x 换元；求分段函数解析式注意变量范围。
- 值域：观察法、配方法、图像法、基本不等式法（一正二定三相等）、换元法（含根式转二次）、分离常数法、判别式法（前提 x∈R）、单调性法、有界性法（反解）、导数法。
- 分段函数：先判断自变量落在哪一段再代入；嵌套 f[f(x)] 逐层自外向内讨论；含参分段比较 f(a) 与 f(-a) 时按 a>0、a<0 分情况。
**易错点**
- 换元求解析式后必须写回 t 的取值范围（如 f(1-sinx) 中 t∈[0,2]；f(x+1/x) 要结合对勾函数值域写 x 的范围）。
- 定义域应用转化为恒成立时，必要时对参数分类讨论（a=0 单独讨论）。
- 分段求值必须注意自变量所在区间；分类讨论求出解后要检验解是否落在对应分段区间内。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第6讲函数的概念.pdf`（OCR 第1—22页）

### 第7讲 函数的性质
**核心思路**
- 单调性证明：定义法"取值—作差变形—判断符号—下结论"；也可用图像法或直接法判断。
- 复合函数单调性：先求定义域，分解为内、外层，按"同增异减"判断，最后写区间。
- 单调性求最值：先确定区间上的单调性，增函数最大值在右端点、最小值在左端点，减函数反之。
- 单调性求参数：转化为关于参数的不等式，如 a>f(x) 恒成立⇔a>f(x)最大值；分段函数还要比较分界点左右端点函数值的大小关系；把参数视作已知来分析。
- 基本初等函数比较大小：把自变量化到同一单调区间（利用奇偶性、对称性），再比较函数值。
- 奇偶性判断与证明：先判断定义域是否关于原点对称，再算 f(-x) 与 f(x) 比较或画图；熟记运算规律（奇±奇=奇、偶×偶=偶等）。
- 已知奇偶性求参数：由 f(-x)=±f(x) 恒成立建方程；选择填空题可用特殊值法快速定参。
- 已知奇偶求解析式/求值：求另一区间解析式时"设 x 在该区间，则 -x 在已知区间"，借奇偶性转化，求值则对号入座。
- f(x)=奇函数+M 型：利用 f(-x)+f(x)=2M，得 f(x)最大+f(x)最小=2M，从而求参数或函数值。
- 对称性与周期性：两条对称轴或两个对称中心 T=2(b-a)；一轴一中心 T=4(b-a)。
- 类周期函数：f(x+T)=kf(x) 型按区间递推并作草图求解。
**易错点**
- 【注意】函数具有奇偶性的前提是定义域关于原点对称；奇函数在 x=0 处有定义则 f(0)=0。
- 偶函数可化为 f(x)=f(|x|)，比较大小前先利用之。
- 判断周期性需验证，不能凭表象；可用取特殊值、举反例排除错误选项。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第7讲函数的性质.pdf`（OCR 第1—32页，原文共47页，止于题型十一开头）

### 第8讲 幂函数与二次函数
**核心思路**
- 幂函数定义：同时满足"系数为1、底数为自变量、指数为常数"，据系数为1列方程求参数；再借图像过点求解析式；图像关于 y 轴对称或关于原点对称确定指数奇偶。
- 幂函数定义域：α 为分数时转化为根式考虑（偶次根式被开方式非负），α≤0 时底数非零。
- 幂函数性质综合：紧扣单调性在不等式中的作用——比较两幂值先化为同指数，转化为底数不等式并兼顾定义域；α 奇数为奇函数、α 偶数为偶函数。
- 二次方程实根分布：抓四点——开口方向、判别式、对称轴位置、区间端点函数值正负，结合图像列不等式组求解。
- 动轴定区间/定轴动区间：抓"三点一轴"（区间两端点、中点与对称轴），按对称轴在区间左侧、右侧、内部（必要时再与中点比较）分类讨论，逐段求最值后整合。
- 二次函数最大值的最小值：先分类求出分段解析式 T(a)，再分段求其最小值（或用端点值构造绝对值不等式）。
**易错点**
- 动轴定区间类必须按对称轴与区间的位置关系分类讨论，并注意结合区间端点函数值分析，最后整合结果。
- 根的分布不能只看判别式，须同时考虑对称轴、端点值符号与开口方向。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第8讲幂函数与二次函数.pdf`（OCR 第1—24页）

### 第9讲 指数与指数函数
**核心思路**
- 指数运算/方程/不等式：化成同底后用指数函数单调性；或取对数；对 a^{2x}+B·a^x+C 型换元成二次方程或二次不等式（注意 t>0）。
- 指数函数图像与性质：数形结合，由图像判参数符号（如判断底数与平移项）；恒过定点的结论用于求最值问题。
- 指数型恒成立：函数法（借单调性）、分离参数法求最值、数形结合法构造两函数；可结合奇偶性+单调性将 f(A)+f(B)>0 型转化为 A>B。
- 指数函数综合：先由 f(-x)+f(x) 常数判断对称中心，再由分区间单调性解抽象不等式；同构构造函数比大小。
**易错点**
- 底数大小不定时必须分 a>1 与 0<a<1 两种情形讨论（如最大值是最小值两倍问题）。
- 换元后必须限定 t>0；处理指数方程有解问题须保证新方程的根为正。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第9讲指数与指数函数.pdf`（OCR 第1—16页）

### 第10讲 对数与对数函数
**核心思路**
- 对数运算/方程/不等式：公式顺用、逆用、变形用；化同底后利用单调性去对数符号，再解得结果。
- 对数函数图像：以图像为载体数形结合，注意恒过定点。
- 对数函数性质（单调性/最值）：复合函数先求定义域，判内层单调（含参可求导或看二次对称轴），外层按底数分类；有最小值常需 a>1 且判别式满足条件。
- 对数型恒成立：数形结合；分离自变量与参变量转化为最值问题；同构后构造函数借导数求最值。
- 对数综合：y=a^x 与 y=log_a x 互为反函数、关于 y=x 对称，交点中点在 y=x 上，可用于 x1+x2、x1x2 类问题。
**易错点**
- 利用对数单调性去掉对数符号后，必须注意真数为正，结论要与定义域检验。
- 底数不确定时须对 a>1 与 0<a<1 分类讨论。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第10讲对数与对数函数.pdf`（OCR 第1—21页）

### 第11讲 函数的图像
**核心思路**
- 由解析式选图：依次看定义域、值域、奇偶性、单调性、周期性、特殊点，用排除法锁定答案。
- 由图像选解析式：由定义域值域判位置，由奇偶性判对称，由周期性判循环，由单调性判趋势，由特征点排除。
- 含参图像问题：对参数分类讨论（如 a>1/0<a<1），用定点、单调性、奇偶性判断。
- 图像应用题：从定义域/值域判左右上下，单调性判趋势，奇偶性判对称，特征点排除，并考虑变化速度（先慢后快等）。
- 图像变换：平移（左加右减、上加下减）、对称、翻折（|f(x)| 与 f(|x|)）、伸缩。
- 图像综合应用：方程根的个数⇔两函数图像交点个数，数形结合求解。
**易错点**

### 第12讲 函数与方程
**核心思路**
- 零点/零点所在区间：代数法（因式分解求根）或几何法（图像、结合单调性与零点存在性定理）。
- 零点确定参数范围：单调函数+端点异号列不等式；或构造函数、分离参数求其值域。
- 根个数与零点存在性：用端点值符号+单调性确定个数；构造同构函数后借单调性判断。
- 嵌套函数零点：令 t=f(x) 化为一元二次方程，分别研究 t 的解个数与 f(x)=t 的解个数相乘得总个数。

### 第15讲 单调性问题
**核心思路**
- 导函数与原函数图像关系：由 f'(x) 符号判断增减；若给的是 xf'(x) 图像，需先按 x 的符号换算回 f'(x) 的符号。
- 求单调区间：求定义域→求导→令 f'(x)=0 穿针引线→解不等式；单调区间用"和"或逗号隔开。
- 已知单调性求参数：在区间上单调⇔导函数恒≥0/≤0（转端点最值）；不单调⇔导数在区间存在变号零点（分离变量）；存在单调区间⇔导函数在区间有解。
- 不含参单调性讨论：求导化简并写定义域→变号因子保留、定号因子去除→求根作图→必要时用二阶导辅助判号。
- 含参单调性讨论：一次函数型（讨论一次项系数符号）；准一次函数（如 a^x-a/lna）；二次型可因式分解的（讨论两根大小关系与定义域）；二次型不可因式分解的（先看判别式及参数造成的恒正/恒负）；准二次型（如 (x-a)(e^x-a)，需比较 a 与 lna）。
- 分段分析法：按 x 的范围分段判断导函数符号（如 x>1 与 x<1，再分 0<a<1 与 a>1）。
**易错点**
- f'(x)>0 是单调递增的充分不必要条件；单调时导函数≥0 且不恒为0。
- 不能漏求定义域；单调区间不能用并集符号连接。
- 二次型讨论中参数为0的情形要最先讨论，遵循"先特殊后一般"；注意定义域及两根大小关系。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第15讲单调性问题.pdf`（OCR 第1—33页）

### 第16讲 极值与最值
**核心思路**
- 求极值：定义域→求导→求 f'(x)=0 的根→检验根左右两侧符号；左正右负为极大值，左负右正为极小值。口诀"原极导零"，零点须穿越 x 轴（变号零点）。
- 由极值/极值点求参数：据"极值点处导数为0"与"极值"两个条件列方程组，待定系数求出后再验证根的合理性；无导数变号则无极值（判别式条件）。
- 求不含参的最值：求区间内极值，与端点函数值比较，最大者为最大值、最小者为最小值；较复杂时先研究 f'(x) 的单调性与零点存在性再定增减。
- 含参闭区间最值：对参数分类讨论单调性，逐情形求最值。
- 由最值求参数：先讨论极值点个数（按参数分段），再由最值条件建立方程；"区间上存在最值"问题转化为"最值点在开区间内"，借图像与对称点 f(m)=f(n) 列端点不等式组。
- 单调性、极值、最值综合：先求单调区间，存在唯一极值点则极值即最值，再转化为关于极值点的不等式求解。
- 不等式恒成立/存在性问题：等价转化为函数最值问题，分离参数或不分离参数移项构造辅助函数；"对任意 x1、存在 x2"型按 f(x)max≤g(x)max 等口诀转化。
**易错点**
- 【注意】极值是局部比较，极值不一定是最值；最值可能在极值点或区间端点取得，极值点只能是开区间内的点。
- f'(x0)=0 是 x0 为极值点的既不充分也不必要条件（如 x³ 在 x=0）。
- 由极值求参数求出后必须验证。

### 第21讲 极值点偏移
**核心思路**
- 概念：单极值函数在极值点两侧增减速度不同导致图象不对称；定义 x₀ 与两交点横坐标中点大小关系，判定左偏/右偏。

### 第22讲 双变量问题
**核心思路**
- 知识梳理三步：一是转化，由条件寻找两变量关系，把双参数不等式化为单参数不等式；二是巧构函数，用导数判断单调性求最值；三是把单变量结论回归到双变量不等式完成证明。
- 题型一 双变量单调：把 |f(x₁)−f(x₂)| ≥ m|x₁−x₂| 按单调性去绝对值，化为 f(x₁)±mx₁ 与 f(x₂)±mx₂ 的大小关系，令 g(x)=f(x)±mx，要求 g′(x)≤0/≥0 恒成立，再分离参数求 m 范围。

### 第23讲 不等式恒成立
**核心思路**
- 知识梳理：构造新函数用导数求最值；可分离变量后直接转化为最值问题；分离后新函数难以求最值点时考虑分类讨论法和放缩法。
- 参变分离四原则：∀x∈D, m≤f(x) ⇔ m≤f(x)min；∀x, m≥f(x) ⇔ m≥f(x)max；∃x, m≤f(x) ⇔ m≤f(x)max；∃x, m≥f(x) ⇔ m≥f(x)min。双函数型按“∀/∃”与 a、b 的搭配（四种组合）分别落到 f 与 g 的最大/最小值上。
- 洛必达法则适用条件：分子分母应同为 0/0 或 ∞/∞ 型的“定式”；在所考察的 a 的去心邻域内两者均可导且分母导数不为零；且导函数之比的极限存在——条件满足时可连续多次使用；x→a⁺、a⁻、±∞ 各情形均适用。
- 题型一 直接法：作差构造函数 g(x)=f(x)−left，证明 g≤0 在区间恒成立，对参数分档讨论导数符号（先讨论 a≥某界、0<a<某界、a≤0）。
- 端点效应：题型二“端点恒成立”——端点处取等号（如 g(0)=0），须再研究端点附近导函数的符号（对 h(x)=sinx−3ax 按 3a≤−1、3a≥1、−1<3a<1 三档），据此定参数；题型三“端点不成立”——端点值本身越界（如 g(0)=1>0 即不合题意），不能由端点定边界，须转向区间内部用构造函数的极值/零点分布讨论。
- 题型四 分离参数：全分离（m≥h(x) 型）、半分离、换元分离（整理成“母函数” ax eˣ 与 ln(ax eˣ) 同构后换元）。
- 题型五 洛必达法则：先在端点处不能直接用导数求极限（如 0/0），再用洛必达求极限确定参数边界；题型六 同构法：整理成 e^(t)−t−1 型母函数的恒成立后，判断 a 的符号分段。
**易错点**
- 注意：利用洛必达法则求未定式极限，首先检查是否为 0/0、∞/∞ 型（可处理 1^∞、∞⁰、0⁰、∞−∞ 型等）；不满足三个前提条件时不能使用，否则会出错，应从其他途径求极限。
- 原文提示注意“恒成立”与“存在性”问题的区别（参变分离时 ∀ 与 ∃ 对应最大最小值不同）。

### 第24讲 不等式的证明问题
**核心思路**
- 知识梳理六法：直接构造 h(x)=f(x)−g(x)；适当放缩构造（已知条件放缩、常见放缩结论）；构造“形似”函数（同解变形后按相似结构构造）；“对数单身狗，指数找朋友”；凹凸反转转为最值；“同构变形”。
- 题型一直接法：作差构造后求导，证明最小值≥0（或最大值≤0）。
- 题型二构造（差构造、变形构造、换元构造、递推构造）：先证明一个母不等式（如 ln(1+t)<t），代换后得到目标；数列型可对 n 与 n±1 递推两边同时构造。
- 题型三分析法：把不等式等价变形，找“中间不等式”/虚设零点，证明充分性——例如把 f(2lna)>0 转化成单变量问题再证明。
- 题型四凹凸反转、拆分函数：把两边拆成 p(x)、q(x) 两个函数，分别求最小/最大，若 max q(x) ≤ min p(x)（两点不同时取等），则不等式成立。
- 题型五对数单身狗、指数找朋友：含 ln 的不等式把 ln 项集中到一侧，含 e 的不等式先两边同乘/除使 e 项与 x 项分离；题型六放缩法：用 eᵗ≥t+1 把 e^(lnx+x+1) 化为 t+1 形；题型七虚设零点：导数零点不可解时，设零点 x₀ 满足 g′(x₀)=0，把 x₀ 代回得到关系式（如 e^x₀=1/x₀）求极值。
- 题型八同构法：把待证不等式整理成同一结构函数的不等式；题型九泰勒展开、拉格朗日中值定理：用函数在某点的泰勒公式（含余项）给不等式定界。
**易错点**
- 凹凸反转法要求两侧最值“等号不能同时取到”，否则只能得 ≥，不能得严格的 >（原文的 q(x) 与 p(x) 取等点不同）。

### 第25讲 函数的零点问题

### 第7讲 函数的性质 · 续
**补充思路**
- 类周期函数：满足 f(x+m)=kf(x)（或 f(x)=kf(x−m)）时，横坐标每增加 m 个单位函数值扩大 k 倍，称周期为 m 的类周期函数；解题时先由已知区间解析式按 f(x)=f(x+m)/k（或 f(x)=kf(x−m)）逐段回推目标区间解析式，在目标区间上求最值，再解恒成立不等式。
- 倍增函数：满足 f(mx)=kf(x) 时横坐标每扩大 m 倍函数值扩大 k 倍；当 m=k 时构成一系列平行的分段函数，按区间写成 g(x)、g(x−m+1)、g(x−m²+1)……的平移形式。
- 类周期函数与数列综合：先求各段 [2n−2,2n) 上的最大值 aₙ（常为等比数列），得 Sₙ 后把“对任意正整数 n 恒成立”化为 k≥cₙ 型，再研究数列 {cₙ} 的单调性（作差/商判增减）找出最大项。
- 抽象函数赋值：由 f(x−y)=f(x)f(y)−g(x)g(y) 型关系，令 x=y 得 f²(x)−g²(x)=f(0)；令 x=0 并借 g 为奇函数得 g(0)=0；再令 x=0 得 f(−x)=f(0)f(x)−g(0)g(x)=f(x) 判偶。
- 抽象函数判单调：把 f(x−y) 的关系改写成 f(x+y) 形式（用 y 换 −y），或把 f(x₁)−f(x₂) 拆成“半和、半差”的自变量组合再作差判号。
- 抽象函数的“模特函数”清单：f(x+y)=f(x)+f(y)→正比例函数；f(x+y)=f(x)f(y)→指数函数；f(xy)=f(x)+f(y)→对数函数；f(xy)=f(x)f(y)→幂函数；f(x+y)=f(x)+f(y)+m→一次函数；判断抽象函数单调性要结合题给区间内比较大小，必要时先作适当变形。
- 对称性+单调性解不等式：由 f(x+a) 为偶函数得 f 关于直线 x=a 对称；再由单调性把 f(A)>f(B) 化为“离对称轴的距离”比较（如化为 |A−a|>|B−a|）。
- 偶函数+对数型函数解不等式：先求定义域（如分母、真数条件），验证偶性，再在 (0,+∞) 上判单调，最后把 f(某式)>f(1) 化为 |某式|<1 并兼顾定义域。
- 偶函数与其导函数联动：f 为偶函数两边求导得 f′(x)=−f′(−x)；若又给出“f′(x)+某偶函数”为偶函数，两式联立可解出 f′(x) 的表达式，再对其求导判单调，从而得 f 在 [0,+∞) 上的单调性，最后用 |·| 比较。
- 平移构造奇偶性：如 f(x)=e^(x−2)+e^(2−x)+2(x−2)²−1 型，先配方平移，令 g(x)=f(x+2) 得 g 为偶函数，再对 g′ 用二阶导判其单调，得 g 在 (0,+∞) 增。
- 奇函数+基本不等式判增：f′(x)=e^x+e^(−x)−2cosx 型，用 e^x+e^(−x)≥2≥2cosx 得 f′≥0（等号仅一处），得 f 在 R 上增，再把 f(A)+f(B)<0 化为 A<−B。
- 奇函数幂型：x≥0 时 f(x)=x² 的奇函数在 R 上增；遇到 f(x+a)≥2f(x) 时先用 2f(x)=f(√2·x)（因 f(√2x)=(√2x)²=2x²）把系数并入自变量，再用单调性化为 x+a≥√2x 在区间上恒成立，取端点最值定参数。
- 复合平移构造：令 g(x)=f(x+1)−2 把 f(A)+f(B)>4 化为 g 的奇函数不等式，再用 g′≤0 得 g 递减，脱去 g 号。
**补充易错点**

### 第12讲 函数与方程 · 续
**补充思路**
- 二分法操作：先由零点存在性定理锁定含根区间 (a,b)，每次取中点算函数值，保留两端异号的半区间；判断精度看区间长度 |b−a| 是否小于给定精确度，满足则取区间内（或中点）的近似值，不满足继续二分。
- 二分法求近似解的区间选择：把方程移项成 f(x)=g(x) 形式后令 h(x)=f(x)−g(x)，只需找 h(a)h(b)<0 的区间即可作为初始区间。
- 牛顿迭代法：设 x₀ 为初始近似值，过 (x₀,f(x₀)) 作切线，切线与 x 轴交点的横坐标 x₁=x₀−f(x₀)/f′(x₀)（f′(x₀)≠0），重复得 x_{n+1}=x_n−f(x_n)/f′(x_n)，称 x_n 为 n+1 次近似值；题目常限定“初始近似值不超过零点”以取定初始值。
- 四个实根型：分段函数（如左段 log₃x、右段一次式）与 y=m 有四个交点时，借对数对称得 x₁x₂=1、借二次（或一次）对称得 x₃+x₄=定值，再把目标式化为只含一个变量（如 x₃）的二次函数，在对应开区间上求值域。
- 三个函数值相等型：设 f(x₁)=f(x₂)=f(x₃)=t，按各段单调性把 x₁、x₂、x₃ 用 t 表示（或写出所在区间），相加后得关于 t 的表达式，再由 t 的范围求值域。
**补充易错点**
- 二分法判断精度用的是区间长度，不是函数值大小；题目给的参考数据要按顺序使用，别跳步。
- 牛顿迭代法只在 f′(x)≠0 时可用；初始值取法会影响近似序列是否单调趋向零点。

### 第22讲 双变量问题 · 续
**补充思路**
- 剪刀模型完整步骤：①求曲线与 x 轴交点 P 处的切线 y=h(x)，构造 F(x)=f(x)−h(x)，用 F′ 判号证 f(x)≥h(x)（曲线在切线上方）；②再取另一条更“缓”的界（如过原点的切线 y=t(x) 或 y=2x），同样证 f(x)≥t(x)；③设 y=m 与两条界线的交点横坐标为 x′、x″，由 f(xᵢ)=m 与 f≥界 比较得 x₁≤x′、x₂≥x″；④两界交点之差即得 |x₂−x₁| 的上界，代入切线方程算出具体界。
- 剪刀模型取第二条界的技巧：常选过原点的切线（如 f(0)=0 处切线），需再证该切线与曲线的高低关系；两条界一上一下把曲线夹住，才能同时夹住两根。
- 主元法（对称和函数）：证 f(a)+(a+b)ln2 ≥ f(a+b)−f(b) 型，先变形为 f(a)+f(b) ≥ f(a+b)−(a+b)ln2，设 g(x)=f(x)+f(k−x)（k>0），用导数求 g 的最小值，得 g(x)≥f(k)−kln2，再令 k=a+b、x=a 即得结论。
- 更换主元处理双变量恒成立：对“任意 a∈[1,2]、关于 x 的不等式在 [1,3] 上恒成立”，先固定 a 对 x 求 h(x) 的最大值（判断对称轴与区间位置定单调），得 h(3)=5a−b+13，再对 a 求最值得 b≥23——即“先对一个变量取最值，再对另一个变量取最值”。
- 参数作变量（主元法）：把含参数 a 的表达式看成关于 a 的一次函数，如 sinx−ax²+2a−e=(−x²+2)a+sinx−e，要它在 a 的区间上恒负，只需两个端点值都负（一次函数端点法），再分别证明。
- 含参恒成立先“放缩掉参数”：把 f(x)≥g(x) 整理为两边同构（如 lnx^a−x^a ≥ lne^(−x)−e^(−x)），用 h(t)=lnt−t（0<t<1）的单调性脱去函数符号，再分离参数求最值。
**补充易错点**
- 剪刀模型必须证两条界与曲线的上下关系都成立，只证一条无法同时夹住两根；最后一步要说明根与界线交点的大小方向不能反。
- 更换主元时，先固定的变量要说明“其范围不影响另一变量最值的取法”（如对称轴不落在区间内）。

### 第23讲 不等式恒成立 · 续
**补充思路**
- 题型七 必要性探路（端点效应）：先由端点处 g(x₀)=0 且要求 g≥0，得 g′(x₀)≥0 作为必要条件解出参数范围（如 g′(0)=2−m≥0 ⇒ m≤2；f(0)=0、f′(0)=3−3a ⇒ a=1），再证该范围是充分的；若端点处 g′(x₀)<0，则端点邻域内 g<0，直接排除。
- 必要性探路中“两个方向都排除”的用法：a>1 时 f′(0)<0、a<1 时 f′(0)>0 均导致邻域内符号不符题意，故只能 a=1，再分区间用二阶导证充分性（如 x∈[0,π/2] 与 [π/2,3π/4] 分别判 h、g 的单调）。
- m>1 的反证细节：构造 G(x)=g′(x)，证 G 在 [1,+∞) 递增且 G(1)=1−m<0、x→+∞ 时 G→0⁺，故 G 有零点，g 先减后增，出现 g(x)<g(1)=0，与恒成立矛盾。
- 同构+分离参数型：f(x)≥g(x) 整理成 (e^?+1)lne^? ≥ (x²+1)lnx²，令 h(x)=(x+1)lnx，先证 h′>0（对 h′ 再构造 m(x)=lnx+1/x+1 判最小值为 2），得 h 单调，脱去 h 得 e^?≥x²，再分离参数求最值。
- 换元 t=x+lnx 型：把不等式整理成 e^t−(t+1)≥0 型，先说明 t=x+lnx 在 (0,+∞) 单调递增且值域为 R（或取值零点存在），再用 e^t≥t+1 放缩得参数界（如 a≤2）。
- 放缩定界：形如 e^(2x+lnx) ≥ 2x+lnx+1 ≥ ax+lnx+1，比较系数得 a≤2；或用 e^x≥x+1 把 e^(2x−ln(1+2x)) 型放缩后逐项抵消。
- 题型八 max/min 函数问题：F(x)=max{f(x),g(x)}≥0 恒成立，先由第(1)问确定 f 的符号分界点（如 x≥0 时 f≥0），于是只需在 f<0 的区间上要求 g≥0；再对 a 按 g′(x)=cosx−a 的符号分类（a≤0、0<a<1、a≥1），并用 g(0)=0 比较邻域内 g 与 0 的大小排除不合情形。
- min 型零点问题：p(x)=min{h(x),g(x)} 的零点个数，先证 h 的符号（如 h(x)=1−lnx 在 x<e 时正），在 h>0 的区间上 p=h 无零点，只在 h<0 的区间讨论 g 的零点，再对 a 分类用 g′ 与端点值计数。
**补充易错点**
- 必要性探路只是必要条件，必须补证充分性；端点处 g′=0 时（不能由一阶导定号）要改用二阶导或更高阶分析。
- max 型恒成立不能直接对 max 求导，须先确定“哪一支更小/更大”把 max 拆开，转化到具体区间上。
- 同构时若 h′ 的符号不能直接看出，要对 h′ 再构造辅助函数求最小（原文例 17 即 m(x)=lnx+1/x+1 最小值为 2）。

### 第24讲 不等式的证明问题 · 续
**补充思路**
- 由“f(x)≥0 且 f(1)=0”定参数：x=1 必为极小值点，令 f′(1)=0 解出参数（如 a=1），再验证单调性；这是必要性探路在证明题中的用法。
- 数列不等式（裂项累加）：由已证的 lnx ≥ 1−1/x（x≥1）取 x=k/(k−1)，得 1/k < lnk−ln(k−1)（取 x=1+1/k 则为 ln(1+1/k)<1/k），对 k=2,…,n 累加即得 Σ1/k < lnn。
- 三角放缩入数列：先证 sinx<x（令 g=x−sinx，g′≥0），再把它与“sin(1/k)<1/k”结合放缩得 Σ sin(1/k) < lnn。
- 逐阶求导（n 阶泰勒余项型）：设 f(x)=e^x−1−x−x²/2!−…−xⁿ/n!，依次求 f′,f″,…,f⁽ⁿ⁾，由 f⁽ⁿ⁾ 单调得 f⁽ⁿ⁻¹⁾>0 逐级回推，最终 f(x)>f(0)=0，得 e^x ≥ 1+x+…+xⁿ/n!。
- 泰勒展开比较：分别求 f(x)=sinx 与 g(x)=x−x³/6、cosx 与 1−x²/2 的差函数，用三阶导/二阶导判号，分 x<0、x=0、x>0 讨论大小；再用 e^x 的三阶展开与 sinx、cosx 的展开组合放缩证 e^x+sinx+cosx≥2+2x。
- 切线/割线型放缩证零点差：先求曲线在交点处的切线（或过原点的切线）并证 f(x)≥该直线（构造 F=f−直线，F′ 判号，F≥0）；再设 y=m 与两条界线的交点横坐标，由 f(xᵢ)=m 与 f≥界比较根的位置，两界交点之差即零点差的界（切线法得小于某值，割线法得大于某值）。
- 证明 g(x₁+x₂)<g(x₁)+g(x₂) 型：用“存在 ξ∈(x₁,x₂) 使 g(x₂)−g(x₁)=g′(ξ)(x₂−x₁)”，由 g′ 递增得 g(x₂)−g(x₁)≤g′(x₂)(x₂−x₁)；再对 x₁ 处同样放缩，两式分别乘权重后相加，凑出 g(x₁+x₂) 的展开。
- 含参不等式先放缩参数：如 a≥(7−e²)/4 时把 a 换成端点值，把待证式化为 e^x+ax²−1 ≥ e^x+(7−e²)x²/4−1，构造 h(x) 并把 h′(x) 因式分解成 (x−2)(2x+e²−9) 型，用单调区间与端点值证 h≤4。
- 同构证明 f(x)<e^x−1 型：化为 e^(x−1)−m(x−1) > e^(lnx)−m·lnx，令 h(t)=e^t−mt，由 h′>0 得 h 单调，再用 x−1 ≥ lnx 得结论。
- 三角函数型：证 sinx−axcosx ≤ 2ax，移项化为 sinx/(2+cosx) ≤ ax，令 g(x)=sinx/(2+cosx)−ax，求导得 (2cosx+1)/(2+cosx)²−a，由 a 的范围（a≥1/3）放缩 g′≤0，得 g 递减、g≤g(0)=0。
**补充易错点**
- 用泰勒展开或逐阶求导时，必须逐级说明“上一阶导函数在区间上单调且端点值为 0”，跳步会丢掉符号依据。
- 切线/割线放缩证零点差时，两条界与曲线的上下关系要分别证明，最后根的大小方向要写清（不能默认 x₁ 对应哪条界）。
- 凹凸反转/泰勒型放缩中，等号成立点要单独核对，否则只能得非严格不等号。

### 第23讲 不等式恒成立 · 续
**补充思路**
- 隐零点消参：设导函数零点 x₀，用 f′(x₀)=0 把参数解成 x₀ 的式子（如由二次零点方程得 m=x₀−1/x₀），代回原式后最值问题不再含参，只需对新构造的无参函数求最值（例25）。
- 隐零点处做同构识别：由 x₀²e^{x₀}+lnx₀=0 得 x₀e^{x₀}=−lnx₀/x₀，再借 g(x)=xe^x 在 (0,1) 上单调递增推出 x₀=−lnx₀，于是 e^{x₀}=1/x₀，最小值的表达式化为常数 1，参数界随即得出（例27 解法一、变式25）。
- 双侧夹逼用判别式定参：题设为 f(x)≥h(x)≥g(x) 时，把两侧分别整理成一元二次不等式，各用判别式不超过 0 定出参数范围再取交集，可免去求导；必要时先用特殊点（如 x=0 得 b=0、x=e 得 k≥0）缩小范围（例26(1)(2)）。
- 反证法证区间长度上界：设 n−m 超过目标值，由 √2−(−1) 小于该值推出 [−1,1] 含于 [m,n]，取 x=−1、0、1 三点建立参数不等式夹出参数区间，再对二次不等式的判别式估计解集长度，导出与假设矛盾（例26(3)）。
- 边界外举反例排除：证完 a≤1 后，对 a>1 取使 x+lnx=0 的 x₀，此时 f(x₀)=x₀<ax₀，与恒成立矛盾，说明该范围不能再扩大（例27 解法二）。
- 双变量比值的最值：先由恒成立取特殊点（如 x=e）得候选界（如 b/a≥−e），再构造差函数证明该界可取到等号，避免只给出必要而不充分的界（例29）。
- 公切线定参数：两曲线有公切线时，切点同时满足"在两曲线上"与"两处导数都等于公切线斜率"，联立即可解出参数（变式28(1)）。
- 切线处的二阶导判据：两函数在 x=0 处函数值与一阶导数值都相等、且差函数二阶导非负时，差函数在 0 点具有"三重零点"结构，于是恒成立等价于二阶导在 0 点非负；由该不等式直接解出参数的最大值（b 不超过 (a²+a+1)/2），再把参数最值代回目标式，化为单参数函数求最值（"例25 后的补充习题"(2)）。
- 指数型恒成立求比值最小：a·e^x≥x+b 化为 a·e^x−x 的最小值 1+lna 不小于 b，得 b/a 不超过 (1+lna)/a，再对该单变量函数求导，在 a=1 处取最小值 1（变式30）。
- 过定点的切线有几条：设切点并写切线方程，把"过定点"条件整理成只含切点横坐标的方程，用导数研究该方程（原文构造 (1/x)+lnx−1，最小值在其唯一零点处为 0）的根数，根数即切线条数（变式31(1)）。
- 含参乘积型目标嵌套求最值：先否定参数使函数单调无上界的情形（取 x 使函数值非负与恒成立矛盾），再在有上界时于 1/(k+1) 处取最大值，由"最大值不大于零"得 k+1≥e^(−1−m)，目标最小值成为 m·e^(−1−m)，再对它求导得 m=1 时最大（变式32）。
- 先猜等号成立的参数再验证：取使各项同时取等号的特殊值（如 x=1 代入）得到必要界 a+b≥0，再取该组参数代入验证不等式确实恒成立，从而确认该界可取到（变式33）。
- 两次换元后改写目标分式：先把 ln(x−1) 换元为 t 求函数最大值得到 b 的下界，再把所求分式拆成"(b−1)/(k−1) 减去 2"的形式，对 (b−1)/(k−1) 再换元 u=k−1 并求导，最小值在 u 等于根号 e 处取得（变式34）。
**补充易错点**
- 隐零点代换后得到的关系式（如 x₀e^{x₀}=−lnx₀/x₀）不能直接断言 x₀=−lnx₀，必须借某个单调函数（原文用 g(x)=xe^x）把两个自变量对应起来。
- 恒成立题必须先排除"函数单调、无最值"的参数范围（如 k≤1 时函数递增趋于正无穷），否则直接求最值会漏掉这一情形（变式32、变式34 原文均先作此判断）。

### 第24讲 不等式的证明问题 · 续
**补充思路**
- 设整体后用切线放缩：把 xe^x 写成 e^{x+lnx}，令 t=x+1+lnx，由 e^t≥t+1 得 e^{x+1+lnx}≥1+x+1+lnx，两边同型相消即得目标不等式（例38）。

### 函数与导数 · 偶函数与导数奇偶联动（浙大优辅5 第10—15页）
**核心思路**
- 题给 f 与其导函数 g=f′ 的偶/奇性并求值：f 为偶函数则 f′ 为奇函数，f 为奇函数则 f′ 为偶函数，可直接互换；

- 求导与对称互换时，自变量系数（如 ω）不为 1 时要链式求导；
- 不能直接假定 f(0)=0，除非由条件推得。

### 函数与导数 · f′>k 型比较大小的指数构造（浙大优辅5 第10—15页）

### 函数与导数 · 三次因式分解与构造 Q(x)（浙大优辅4 第31—37页）

### 函数 · 复合函数定义域（A049 第31—32页）
**核心思路**

### 函数 · 解析式五大求法（A049 第33—34页）

### 函数 · 分段函数（A049 第35—36页）
**核心思路**

- 自变量范围不确定时按分段端点分类讨论；
- 已知函数值求自变量：分段解方程后，检验解是否落在该段定义域内，落在外面的舍去（可能多解）；

- 分段不等式各段解集取了交集而非并集。

### 函数 · 脱“f”解不等式（A049 第37—38页）
**核心思路**
- 题目形如 f(g(x))>f(h(x)) 或 f(g(x))+f(h(x))>0 的解集，优先“从外向内”脱 f；
- 步骤一：判断 f 的单调性（由定义式、解析式中的已知单调函数组合或奇偶+部分区间单调推全区间）；
- 步骤二：单增区间上 f(g)>f(h) ⇔ g>h，单减区间上 ⇔ g<h；同时列入 g(x)、h(x) 都属于 f 定义域的条件；
- 奇函数型：f(g)+f(h)>0 ⇒ f(g)>−f(h)=f(−h)，再按单调性脱 f；
- 偶函数型：f(g)>f(h) ⇔ |g|>|h|（离 y 轴越远函数值越大，要求该方向单调），两边平方求解。
**易错点**
- 脱 f 后遗漏定义域对 g(x)、h(x) 的限制；
- 偶函数型直接按单调性比较 g、h 大小，未取绝对值；
- 只在部分区间知单调就整域脱 f（需先确定整个定义域上的单调方向）。

### 函数 · 对勾函数与飘带函数（A049 第39—40页）
**核心思路**
- 对勾函数 f(x)=ax+b/x（a,b>0）：定义域为(−∞,0)∪(0,+∞)，值域分两支 [2√ab,+∞) 与 (−∞,−2√ab]，极值点在最值处（用基本不等式理解：ax+b/x≥2√ab，当 ax=b/x 时取等），在 (0,√(b/a)) 上递减、在 (√(b/a),+∞) 上递增，奇函数；
- 飘带函数 f(x)=ax−b/x（a,b>0）：值域为 R，无顶点，在两段 (0,+∞) 与 (−∞,0) 上都单调递增，奇函数；
- 求区间上的值域/最值：先看区间位于对勾函数哪一支、取等点 √(b/a) 是否落在区间内；落在区间内用最小值 2√ab，不落在区间内则用端点处的单调性；
- 形如 ax/(bx+c) 的“倒对勾”只研究分母中的对勾部分；
- 分式函数可通过换元（如令 t=x−1）化成飘带函数，按飘带函数单调性在 t 的区间上求值域。
**易错点**
- 区间不含极值点仍写 2√ab（取等点不在区间时要取端点值）；
- 对勾函数的 x 可为负时用 x>0 分支的结论；
- 换元后忘记改写 t 的取值范围。

### 函数 · 直接法求值域（配方法 + 单调性法）（A049 第41—42页）
**核心思路**
- 结构简单、能直接读基本函数性质时用直接法；三步：先定定义域 → 再定单调性 → 由单调性取端点（最值）得值域；
- 配方法：二次函数或可转化为二次的（根号内二次式）先配方成顶点式，结合开口方向与定义域范围取值域；
- 单调性法：单调递增则最小值在左端、最大值在右端；区间内先增后减则较大者为端点最大值、较小端点为最小值；
- 判断复合结构单调用运算性质：增+增=增，增−减=增，正数乘保持、负数乘反转，f>0且单调时 1/f 反向，√f 保持；
- 两项一增一减不能确定单调时，对式子做变形（如分子分母同乘共轭式化成反比例型）再判断。
**易错点**
- 不定定义域直接说值域；
- 根号内二次式不考虑被开方数非负对定义域的限制；
- 复合函数内外层单调性判定漏掉内层值域（外层需在内层值域上讨论）。

### 函数 · 数形结合求值域（A049 第43—44页）
**核心思路**
- 识别代数式的几何意义：根式和 √((x−a)²+…) 化成动点到定点距离（之和/差）；分式 (f(x)−b)/(x−a) 化成动点与定点连线斜率；|x−a|±|x−b| 化成数轴上的距离和/差；y=√f(x) 且二次项系数为 −1 表示半圆（y≥0）；

### 函数 · 多零点求范围（和定值 / 积定值 / 差定值）（A049 第91—93页）
**核心思路**
- 多零点题先画图找零点间结构，三类：和定值——对称型函数（|x−a|、(x−a)²、f(a+x)=f(a−x)）零点关于对称轴对称，根之和为 2a 乘对数的个数；反函数型（f(x) 与 f⁻¹(x) 同时与斜率为 −1 的直线相交）两零点之和等于截距之和；

### 函数 · 抽象函数模型识别与赋值（A049 第94—95页）
**核心思路**
- 先记常见结构对应的原函数，按“关系式 → 模型”直接类比：f(x+y)=f(x)+f(y) → 一次函数；f(x+y)=f(x)+f(y)+kxy → 二次函数；f(x+y)=f(x)·f(y) → 指数函数；f(xy)=f(x)+f(y)、f(x^n)=nf(x) → 对数函数；f(x+y)+f(x−y)=2f(x)f(y) → 余弦函数；f(x±y)=[f(x)±f(y)]/[1∓f(x)f(y)] → 正切函数；

- 由抽象关系式推导周期时赋值次数不够、方向推错；
- 把“f(xy)=f(x)+f(y)”与“f(x+y)=f(x)f(y)”模型混淆。

### 函数与导数 · 增函数与其反函数交点必在 y=x（浙大优辅20 第38页）
**核心思路**
- 若 $f$ 与 $g$ 互为反函数且 $f$ 单调递增，则两图象的交点必在直线 $y=x$ 上，交点个数问题直接化为 $f(x)=x$ 的根的个数；
- 利用这一结论可把"$f(x)=g(x)$ 有几个根"降为"$f(x)=x$ 有几个根"，避免解超越方程；
- 该结论只对单调递增的反函数对成立，单调递减时交点可不在 $y=x$ 上，不能套用。
**易错点**
- 对递减的反函数对（如 $y=1/x$ 型）误用结论；
- 未先证明 $f$ 严格单调就下结论。

### 函数与导数 · f(f(x))=x 与 f(x)=x 同解的条件（浙大优辅20 第38—39页）
**核心思路**
- 处理 $f(f(x))=x$ 的根，先看能否转化为 $f(x)=x$：若 $f$ 的图象上不存在关于直线 $y=x$ 对称的两点（即 $f$ 与其反函数图象除 $y=x$ 外无交点），则两方程同解；
- 判断方法：设 $f(a)=b$ 且 $f(b)=a$（$a\ne b$），若能推出矛盾（如与单调性、值域冲突），则同解成立；
- 转化为 $f(x)=x$ 后，根的个数与范围问题按普通方程处理。
**易错点**
- 无条件地把 $f(f(x))=x$ 直接换成 $f(x)=x$，未验证"无对称点"这一前提；
- 只验证存在性而不说明理由。

### 函数与导数 · 复合函数零点由外到内逐层拆解（浙大优辅20 第33—34页）
**核心思路**
- 求 $f(g(x))=0$ 的零点，先解外层方程 $f(t)=0$ 得到全部 $t$ 值；
- 再对每个 $t$ 解内层方程 $g(x)=t$，内层解的个数由 $t$ 是否落在 $g$ 的值域内决定，落在值域外则无解；
- 各层解数相乘/相加得到总零点个数；若外层是分段或含绝对值，先拆外层再逐支处理。
**易错点**
- 把外层根直接当作零点；
- 内层方程解得的值未检验是否在原函数定义域内。

### 函数与导数 · 放缩取点证明零点存在（浙大优辅20 第46—48页）
**核心思路**
- 零点存在定理只保证区间内有零点，端点函数值符号需要自己"取点"证明；取点时按函数的主导项放缩：$x$ 很大时保留最高次项、丢掉低次项与常数，得到符号确定的下界或上界；
- 常用取法：$x$ 取形如 $e^{-(|a|+k)}$ 或 $\dfrac{|a|+1}{k}$ 的量，使含参项被常数控制，从而算出函数值符号；
- 先放缩出 $f(x)<0$（或 $>0$）的一个明确点，再与另一端点异号，即可用零点存在定理。
**易错点**
- 放缩方向用反，得出无法判断符号的式子；
- 取的点不在定义域内（如对数需正数）。

### 函数与导数 · 零点即最值点或极值点的判定（浙大优辅20 第74—76页）
**核心思路**
- $|g(x)|$ 的零点就是 $g$ 的零点，而若题设说"$|g(x)|$ 的最小值为 0"，则零点必是最小值点；同理"零点处取极值"可反推该点是极值点，用 $g'(x_0)=0$ 建立方程；
- 形如 $(e^x-a)[\ln(x+1)-b]\ge0$ 恒成立的双因子不等式，若等号能取到，则两因子在同一 $x$ 处同时为零，该公共零点也是各自函数的零点与极值点；
- 由"零点即极值点"列出导数条件与原函数条件，联立求参数。
**易错点**
- 恒成立只验证了等号成立，未说明该点确为极小值（左右符号）；
- 两因子零点不相同却强行令其相等。

### 函数与导数 · 零点反代参数用几何意义求最值（浙大优辅20 第70—71页）

### 导数 · 「在点」与「过点」切线的区别（浙大优辅18 第6讲）
**核心思路**
- 「在点 P 处的切线」：P 是切点，斜率 = f'(x_P)；
- 「过点 P 的切线」：P 不一定是切点，设切点 (x0,f(x0))，写切线方程 y−f(x0)=f'(x0)(x−x0)，再把 P 代入解出 x0；
- 切线条数 = 该方程关于 x0 的实根个数（在定义域内），可用构造函数求根个数判断。
**易错点**
- 「过点」的切线可能不止一条，也可能无解，不能默认只有一条；
- 方程根需在 f 的定义域内，解出后要检验。

### 导数 · 切线条数转方程根个数（浙大优辅18 第6讲）

### 导数 · 公切线求参数范围（浙大优辅18 第6讲）
**核心思路**
- 看到两曲线存在（或恰有）公切线：设切点 (x1,f(x1))、(x2,g(x2))，令两切线斜率相等且切线方程相同；
- 得方程组 f'(x1)=g'(x2)，f(x1)−x1·f'(x1)=g(x2)−x2·g'(x2)，消 x2 得关于 x1 的方程，转为讨论根的存在；
- 求参数范围时把参数写成关于 x1 的函数，用单调性求值域。
**易错点**
- 只写斜率相等不写切线方程相同会丢失条件；
- 两曲线重合（同一条曲线）时任意点都有公切线，需单独区分。

### 导数 · 切线平行法求两点间最短距离（浙大优辅18 第6讲）
**核心思路**
- 求「一点到曲线的最短距离」或「两曲线间最短距离」：在曲线上找切线斜率等于该点到点连线斜率的位置（或两曲线平行切线的位置）；
- 取点 (x0,f(x0)) 使 f'(x0)=(f(x0)−y0)/(x0−xP)（两曲线则取 f'(x)=g'(t) 且连线斜率等于它）；

### 导数 · 「双切函数」与「切线重合函数」新定义（浙大优辅18 第6讲）
**核心思路**
- 新定义「双切函数」：对任意点都存在另一条切线与之重合（即两处切线的切线方程相同）——翻译为「存在 x1≠x2 使 f'(x1)=f'(x2) 且切线截距相同」，等价于 f'(x) 在切点间等值并满足切线重合条件；
- 新定义「切线重合函数」：两不同点的切线完全重合，即满足 f(x1)−x1f'(x1)=f(x2)−x2f'(x2)；

**易错点**
- 「双切」要求对定义域内每个点都成立，不能只举一例；
- 判断「不是」要给出反例，判断「是」要证明。

### 函数与导数 · 特值法（核心方法 第14—16页）
**核心思路**
- 选择题/填空题中，一般结论（大小关系唯一确定、含参范围、恒成立）难以直接判断时：取满足题目全部条件的简单特殊值代入，逐一排除不成立的选项；
- 抽象函数只给对称性/奇偶性条件、结果与具体函数无关时：构造具备同样对称轴的典型函数（如图象有对称轴、有对称中心可借余弦型函数或分段函数“建模”）代入检验；
- 恒成立求参数范围：先用特殊点（如真数为 1、x 取端点）试探出参数的临界值或候选范围，再看选项或转向证明；
- 也可用特殊位置、特殊图形（正三角形、正方体、中点、端点）把几何题退化为可算的模型。
**易错点**
- 特值必须满足题目所有条件，取值尽量简单；特值得出的结论不能作为解答题的证明依据，只能用于排除错误选项或验证猜想；
- 若条件不足以确定唯一结果（如抽象函数可整体加常数），不能凭特值认定选项正确。

### 函数与导数 · 图象法（核心方法 第33—35页）

### 函数与导数 · 定义法（核心方法 第29—32页）
**核心思路**
- 题设没有明确的等量/不等/位置关系，看不出该用哪个公式时：回到概念定义出发，直接由定义推理；
- 椭圆（双曲线、抛物线）上一点与焦点距离的乘积、和差的最值：先用定义把两距离之和（差）化为定值，再用基本不等式处理；
- 立体几何中动点轨迹判断：按线面角、二面角的定义作出对应平面角，由两角相等得到距离关系，再与圆锥曲线定义比对；
- 判断“是否存在函数 f 满足对任意 x 都有某关系”：直接用函数定义的“唯一对应”做检验，同一自变量对应两个不同值即排除。
**易错点**
- 用定义前要明确定义的前提、适用范围和表示形式，并能把题目条件拆解成与定义对应的部分；

### 函数与导数 · 分析法（核心方法 第20—23页）
**核心思路**
- 要证的不等式/等式从结论出发不好下手、思路不明显时：把结论当“目的地”，逐层寻找使它成立的充分条件，直到与已知条件吻合；
- 幂的形式不同底不同指数比较：两边同取对数把比较转化为某函数在两个点处值的比较，再用单调性；
- 抽象三角不等式（如两函数值的平均数与中点函数值的关系）：一连串“只要证……”等价变形，最后化到显然成立的形式；
- 含对数换底的恒等式：先用换底公式把结论化简，再反推，看是否等价于题给的已知关系。
**易错点**
- 分析法执果索因，书写时必须把每一步“只要证”写清，保证每步推理可逆，最后注明“以上各步可逆，故原命题成立”。

### 函数与导数 · 反证法（核心方法 第24—28页）
**核心思路**
- 正面证明无从下手，或关键词是“不”“不存在”“至少”“至多”时：反设结论不成立→由假设推出矛盾→说明假设错误；
- 反设要准确：是/不是、都/不都、至少一个/一个也没有、至少 n 个/至多 n−1 个、至多一个/至少两个；
- 导矛盾要“有源”：从反设出发推导，矛盾可来自与已知条件、公理/定理/公式、反设本身或自相矛盾；
- 抽象函数题中目标区间性质未知、另一区间已知时：把目标变量通过反设“拉回”已知区间再比较函数值，得出矛盾。
**易错点**
- 一定要从反设出发找矛盾，不能脱离假设空推；
- 要与独立性检验中的“零假设”区分：后者不是反证法的假设，不能混用逻辑。

### 函数与导数 · 换元减元法（核心方法 第36—39页）
**核心思路**
- 函数结构复杂、变量多或变量间关系隐蔽时：引入新元简化结构、减少变量个数；常见手段有三角换元、齐次化换元（差值换元、比值换元）、整体代换；
- 有理分式含高次且分母是二次的平方：用正切三角代换降次，化为单角正弦型再求值域；
- 双变量且满足 f(x₁)=f(x₂)：差值换元令 t = x₁−x₂ 或比值换元令 t = x₁/x₂，把目标不等式化为单变量 t 的不等式，构造函数证明；
- “参数乘以某整体”的隐蔽关系（如 a·lnx 型）：把该整体设为 t，再把 x 表示为 t 的函数，转化为只含 t 的问题。
**易错点**
- 忽略新元范围是最常见错误：换元后必须由原变量约束推出新变量的准确取值范围（如 t>0、t>1）；
- 三角换元时保持原变量的定义域一致。

### 函数与导数 · 待定系数法（核心方法 第40—43页）
**核心思路**
- 题目给出表达式类型（一次函数、二次函数、等差/等比结构、特定递推变形）但系数未知时：先设出含待定系数的结构，再用恒等关系/对应项系数相等建立方程（组）求解；
- 求 x+y 这类目标式在“条件分式”下的最值：设目标式是两个分母式的线性组合，比较系数解出两个待定系数，再对每一项用基本不等式；
- 数列求和（等差×等比型）想避开错位相减：设和式为含待定系数的结构，作差得递推，比较系数求出参数，进而构造等比数列。
**易错点**
- 预设的结构类型必须正确（如已知一次函数设 kx+b 且 k≠0）；
- 解出系数后要代回原条件检验。

### 函数与导数 · 区间转移法（核心方法 第44—47页）
**核心思路**
- 目标区间上函数的性质没有给出、只给了另一区间（或其对称形式）的性质时：借偶性/奇性、平移、对称、周期把目标区间的问题转移到已知区间；
- 函数图象关于直线 x=a 对称且以 T=2b 为周期：图象关于直线 x=a+kb 也对称；关于点 (a,c) 对称时同理得到关于点 (a+kb,c) 对称；
- 求 [−N,N] 上方程根个数或某点函数值：先用对称/周期确定一个周期内的根，再整数倍平移计数，注意端点是否落在周期边界；
- 原函数与导函数的对称性联动：f(x) 关于点 (a,f(a)) 对称⇒f' 关于直线 x=a 对称；f(x) 关于直线 x=a 对称⇒f' 关于点 (a,0) 对称；再由两个对称轴推出周期。
**易错点**
- 转移必须等价（充要），注意端点与边界；要区分“整体”对称与“局部”性质；
- 由 f(x+C) 为偶函数得到的是对称轴 x=C（不是 x=−C）；f(x)−bx 关于直线 x=a 对称的反向推导也常用。

### 函数与导数 · 分离变量（核心方法 第48—52页）
**核心思路**
- 恒成立、能成立、有解、两曲线交点个数、给定单调性求参数：把参数一侧与变量一侧分离，转化为求一侧函数的最值；
- 三类判定：恒成立 a≥f(x)ₘₐₓ 或 a≤f(x)ₘᵢₙ；能成立 a≤f(x)ₘₐₓ 或 a≥f(x)ₘᵢₙ；方程有解 a 等于 f(x) 的值域；

- 指数方程直接分离困难：两边同时取对数化成等价形式后再分离，构造新函数研究单调性与最值。
**易错点**
- 分离过程必须等价（如两边同除时注意因式不为零、取对数时须保证为正）；

### 函数与导数 · 变更主元（核心方法 第53—56页）
**核心思路**
- 不等式对某参数（如 m∈[−1,1]）恒成立、求另一变量范围：把参数视作主元，构造关于参数的一次/二次函数，转化为该函数在该区间上的最值条件；
- 证明含参数的不等式：把参数作为主元求导，找到 g(a) 的最小值（常是 a=x 处），再证明其非负；
- 问题以参数为主元讨论繁琐、或需先定参数范围：先取特殊点求出参数的必要范围，再以参数为主元证充分性；
**易错点**

### 函数与导数 · 放缩法（核心方法 第63—67页）
**核心思路**
- 要证含参不等式、直接求最值讨论太繁时：先用经典放缩式把超越式变成简单式，再证中间不等式，利用传递性；
- 常用放缩链：eˣ ≥ x+1 ≥ ln(x+2)（两个等号不同时成立，所以能得严格不等）；eˣ 在 0 处切线为 y=x+1；
- 切线法：曲线在展开点处的切线若在曲线下方则可作放缩依据；也可用前问已证结论或函数单调性作放缩；
- 证明含参恒成立：先用 m≤2 一类条件把含 m 的一侧放大（ln(x+m)≤ln(x+2)），把问题降到不含参的形式；
- 求参数范围时借放缩判断函数值趋势，说明零点存在。
**易错点**
- 放缩的方向与幅度必须匹配目标不等式，放缩过头会让结论不成立；
- 用两条放缩串联时，必须说明等号不能同时取到，否则得不到严格不等号。
**依据**：`题库/2027版 数学核心方法 高一 高二 高三/高三数学核心方法_351.pdf`（OCR 第63—67页）

### 函数与导数 · 隐零点代换法（核心方法 第68—73页）
**核心思路**
- 导函数的零点解不出来、但可判断唯一存在时：设零点为 x₀，判断其所在区间（用零点存在定理，合理选点算导数值符号），利用 f'(x₀)=0 得到的等式把超越项整体代换；
- 代换目标：把 e^x₀、ln x₀ 等用 x₀ 的有理式或一次式代替，实现降次、消参、减元，求出最值；
- 含双变量的最值（如最小值中含参数 a）：把 x₀ 视为主元，再用基本不等式或一次式处理；
- 隐零点方程同时含指数与对数（如 e^{3x₀} 与 ln x₀ 的关系）：先用指对同构（x₀e^{x₀} 型）化简，再用单调性转化为 e^{3x₀} = 1/x₀ 一类关系代回。
**易错点**
- 判断零点区间时要合理赋值，保证导数值符号明确；
- 代换过程可能需多次操作，每次代换后要重新确认剩余表达式的范围；忽视 x₀ 所在区间会导致不等号方向错误。

### 函数与导数 · 必要性探路（核心方法 第74—78页）
**核心思路**
- 恒成立求参数（尤其参数限定为整数、求最小/最大整数）或含参函数性质问题：取定义域内的特殊点（端点、零点、极值点）代入题设条件，得到参数必须满足的条件，先缩范围；
- 端点处 f(x₀)=f'(x₀)=0 时：若 f(x)≥0 恒成立，必有 f''(x₀)≥0，以此定出参数界；
- 得到必要条件后必须补证充分性：通常取边界值代入，用放缩或构造 g(x) 证明；
- 有多变量（含参数区间、带整数参数）时，可按主元先处理参数，再选特殊值（常取 e 的幂以方便计算）。
**易错点**
- 必要性探路求得的范围不一定是最终范围，必须补充分性证明；
- 端点处一阶导为 0 时不能由一阶导定参数，要用二阶导或更高阶或高阶展开分析。

### 导数 · 模型128 切线条数问题（A049 第323—324页）
**核心思路**
- 步骤：设切点 (x0,f(x0))，写切线 y−f(x0)=f′(x0)(x−x0)；把已知点 (a,b) 代入，整理成关于 x0 的方程；
- 切线条数 = 该方程的不同实根个数（每个根对应一个切点、一条切线）；
- 已知条数求参数：把方程整理成「参数 = g(x0)」的形式，转化为 y=g(x) 与水平线的交点个数问题，用单调性与极值、端点趋势定参数范围；

**易错点**
- 把「过某点」误当成「在某点」：点在曲线上也只是候选切点，还可能有另一条切于别处的切线；
- 解出的 x0 要检查是否在原函数定义域内；
- 方程的重根对应同一条切线，计数时按不同根算。

### 导数 · 模型129 公切线模型（A049 第324—326页）
**核心思路**
- 设 f 的切点为 x1、g 的切点为 x2；公切线要求斜率相等 f′(x1)=g′(x2)、截距相等 f(x1)−x1f′(x1)=g(x2)−x2g′(x2)；
- 联立两式后消去 x1 或 x2（选更容易消的那个），得到只含一个变量的方程；方程解的个数就是公切线条数；
- 已知存在公切线求参数：把方程整理成「参数 = φ(x)」的形式，在保留定义域的前提下求 φ 的值域（单调性、极值、端点）；
- 注意两个切点各自的定义域（如对数要求 x>0、题设限定 x<0），消元后变量的范围要保留。
**易错点**
- 只联立斜率相等而漏掉截距相等，会多出假解；
- 消元后忘记带回原定义域限制，参数范围会扩大；
- 两曲线切于同一点也算一条公切线，要单独验证。

### 导数 · 模型130 与切线有关的距离最值（A049 第326—327页）
**核心思路**
- 直接问（曲线上动点到定直线的距离）：把直线平移至与曲线相切，切点处距离最小；令 f′(x)=已知直线斜率求切点，再用点到直线距离；
- 也可设平行直线系与曲线联立，令判别式为零求切线（适用于圆、二次曲线）；
- 间接问（目标形如 (x1−x2)²+(f(x1)−g(x2))²）：把它看成两条图象上两点距离的平方，最小值在两处切线平行、且两点连线与切线垂直时取到；
- 先识别几何意义：形如 (x−a)²+(y−b)² 的式子配方成两点距离平方，并指出其中一点所在的曲线或直线。
**易错点**
- 求点线距离时代入的是切点，不是曲线上任意点；
- 两图象都不是直线时变量多，要先借「切线平行」建立两切点坐标的关系；

### 导数 · 模型132 含参不等式三类处理（A049 第331—333页）
**核心思路**
- 含参不等式恒成立先看参数能否分离：分离后新函数结构简单，就全分离，化为“a≤f(x)”型后求 f 的最值；
- 分离后一侧是简单曲线、另一侧是随参数变化的直线族（如含参直线绕定点旋转），就用半分离：只把参数项移到一边，作图找直线与曲线的临界位置（相切或过端点）；
- 作临界切线时，“相切”条件由导数列出：导数等于直线斜率、切点坐标同时满足曲线方程，联立解参数；“恰好相切”也可令判别式为零（对二次曲线一侧可行）；
- 两种分离都得到复杂结构时就不分离，直接作差构造含参函数，按参数分段讨论导数符号与极值；
- 分离时涉及除以含 x 的式子，要先判 x 的正负与是否为零。

### 函数 · 两图象共对称中心的交点成对求和（培优讲义 第34—35页）

### 函数 · 嵌套方程的 t 根分配与值域筛选（培优讲义 第51—54页）

- 解 f(f(x))+k=0 型：令 t=f(x)，先解外层方程 f(t)=−k 得 t 的候选值；
- 把候选 t 与内层 f(x) 的值域比对，不在值域内的 t 直接舍去（f(x)=t 必无解），这一步是减少无效讨论的关键；

### 函数与导数 · 有最值不讨论（解题方法 第248—261页）

### 函数与导数 · 切线放缩与先指后对（解题方法 第262—270页）
**核心思路**
- 证不等式或求参数时优先用两条切线不等式：e^x≥x+1（x=0 取等）、lnx≤x−1（x=1 取等），把超越式降为一次式；
- 含 λx−lnx 型先配成「lnx≤x−1」的倍数形式，得 λx−lnx≥1+lnλ，等号在 x=1/λ 处；
- 指数、对数同时出现时「先指后对」：先用 e^t≥t+1 放缩指数部分，再用 lnx≤x−1 放缩对数部分，两步都取到等号时证明最紧；
- 放缩后若需保留更多精度，可换成二阶切线（e^x≥1+x+x²/2 型）；
- 也可用反函数法：把 e^x 与 lnx 的图象关于 y=x 对称，转化为同一函数在两点取值比较。
**易错点**
- 放缩方向必须与目标不等式一致，放缩过头会证不出（如证 ≥ 时把左边缩小）；
- 等号成立条件要能同时满足，否则放缩链在某步已严格，结论只能得严格不等号。

### 函数与导数 · 分离函数的凹凸翻转（解题方法 第307—325页）

- 典型如 xlnx 是凸函数，乘 x 后 x²lnx 仍凸，除以 x 得 lnx 变凹，按目标选择乘除幂次；

- 乘除负数会改变不等号方向，区间含负值时不能整体乘除 x^n；

### 函数与导数 · 共零点判双因子不等式（解题方法 第333—341页）
**核心思路**
- 形如 f(x)·g(x)≥0 恒成立：两个因子要么同号，要么在同一 x 处同时变号（共零点），据此定参数；
- 若已知其中一个因子的变号零点 x₀，则另一个因子也必以 x₀ 为零点，代入解参数；
- 形如 [f(x)−a][g(x)−a]≤0：等价于直线 y=a 夹在两条曲线之间，a 的取值范围由两曲线交点（第一个交点给出端点）确定；
- 两因子均不变号（恒正或恒负）时不等式自动成立，须单独作为一类。
**易错点**
- 定义域不连续（分段函数）时不能直接按共零点处理，须逐段判断；
- 只验证「共零点」不够，还要确认两因子在零点两侧确实异号，否则乘积不变号。

### 函数与导数 · 对称性语句转化为方程有解（解题方法 第374—391页）

- 「存在两对关于原点对称的点」⇔ 方程有两个不同解，转化为两曲线交点个数；

### 函数与导数 · 切线语句转化为导数方程（解题方法 第374—391页）
**核心思路**
- 「存在两点处切线互相垂直」⇔ 存在 x₁、x₂ 使 f′(x₁)f′(x₂)=−1：因 f′ 的取值构成区间，条件化为 f′(x)min·f′(x)max≤−1（异号且乘积可达 −1）；
- 「存在两条倾斜角互补的切线」⇔ f′(x₁)+f′(x₂)=0，即 f′ 有变号零点（图象关于某水平线上下对称）；
- 「过点 A(m,0) 可作三条切线」⇔ 设切点 x₀ 写切线方程并代入 A，所得关于 x₀ 的方程有三个不同实根；

**易错点**
- 切线垂直只要求斜率乘积为 −1，斜率不存在的竖直切线要单独讨论；

### 函数与导数 · 多量词命题分而治之（解题方法 第374—391页）
**核心思路**
- 含「任意/存在」多个量词的命题，按量词出现顺序逐个处理（就近原则，先近后远），每处理一个量词就把该变量化为函数的最值；
- 常用转化：∀x, f(x)≥m ⇔ f(x)min≥m；∃x, f(x)≥m ⇔ f(x)max≥m；∀x, f(x)≤m ⇔ f(x)max≤m；∃x, f(x)≤m ⇔ f(x)min≤m；
- 处理过程中用分离参数避免分类讨论；剩余变量再按同样规则转化；
- 「∀a∈A，∃x∈B，f(x)≥g(a)」型先对 x 取最值、再对 a 取最值，两个量词方向相反不要合并。
**易错点**
- 量词顺序不可交换：∀a∃x 与 ∃x∀a 含义不同，结论也不同；
- 双量词命题强行同构变形会掉进陷阱，应按量词逐个处理。

### 函数与导数 · 三边长条件的极值判据（解题方法 第374—391页）

### 函数与导数 · 待定函数法解抽象函数方程（解题通法 第181—183页）
**核心思路**
- 抽象函数方程两边都是多项式型（如 f(x+y)+f(x)f(y) 等于某个二元多项式）时：先比较左右两边关于 x、y 的最高次数，猜函数类型（一次函数设 kx+b、二次函数设 ax²+bx+c），再代入原方程；

### 函数与导数 · 试根待定系数法解三次方程（解题通法 第184—187页）
**核心思路**
- 三次方程无法直接因式分解时：先看首项系数是否为 1，若为 1 则整数根必是常数项的因数，列出常数项的全部正负因数作为候选根；
- 逐个代入试根，找到一个使多项式为 0 的整数根 r 后，由因式定理 (x−r) 是该多项式的一个因式；

- 该不等式只对 (0,π/2) 成立；
- sinx/x 在区间 (0,π) 递减，不等于全区间递减。
**依据**：`题库/《高考数学•优质解法》（405P）.pdf`（OCR 第311—312页）

### 函数与导数 · 两次判别式求二元函数最值（解题方法 第39—43页）
**核心思路**
- 触发：二元函数（含平方项与交叉项）求最小值，直接用一元函数法要两层讨论；
- 步骤：把 z 视为关于其中一个变量的二次方程（对另一变量整理系数），由判别式≥0 得只含另一变量与 z 的不等式；
- 再把这个不等式看成关于该变量的二次不等式，令判别式≤0，解出 z 的下界；
- 取等要求两次判别式同时为零，代回验证 a、b 确实存在且取到该值；
- 可用柯西不等式或配方一步得界，作为核对（两者答案应一致）。
**易错点**
- 判别式≥0 只保证方程有实根，根是否在原范围须回代检验；
- 二次项系数含参数时要分「正/零/负」讨论，不能直接写判别式条件。
**依据**：`题库/高中数学解题方法.pdf`（OCR 第39—43页）

### 函数与导数 · m+|n|=max{m+n,m−n} 的等值关系（解题方法 第63—68页）
**核心思路**
- 触发：f(x)=g(x)+|h(x)|（或两段绝对值之和）的最小值为 M，求其中参数；
- 等值关系：m+|n|=max{m+n, m−n}，|m|+|n|=max{|m+n|,|m−n|}——把绝对值化为两个不含绝对值函数的较大者；
- 由 max 的上包络性质，最小值 M 在两条曲线交点或其端点处取得，于是列方程组 g(x)+h(x)=M 与 g(x)−h(x)=M，解出参数；
- 有多个解时结合图象检验，舍去不在定义域或不在正确交点处的解；
- 另用「M=max{a,b} ⇒ M≥a 且 M≥b」，两不等式相加得 2M≥|a+b| 类下界，取等时得最小值。
**易错点**
- 求 min{a,b} 的最大值时用 m≤a、m≤b 相加，方向与 max 情形相反，别写反；
- 解出的参数须代回原式验证等号可取得。
**依据**：`题库/高中数学解题方法.pdf`（OCR 第63—68页）

### 函数与导数 · 易混十一对辨析（定义域/值域 / 有意义 / 恒成立 / 主次元 / 有解与恒成立 / 单调区间与区间单调 / 在点切线与过点切线 / 对称与周期 / 中心对称 / 单变量与双变量 / 函数单调与数列单调）（破题36招 第76—82页）
**核心思路**
- 「定义域」问题先要求被开方数/分母/真数有意义，再按条件求参数；「值域」问题反过来由 y 的取值反解 x 的范围；
- 「有解」与「恒成立」区分：前者取最值的方向与后者相反（有解只要求一个 x 满足，用 min 或 max 的对应端）；
- 主元/次元：题目中「关于 a 的式子对任意 x 成立」时，把 a 当变量、x 当常数；
- 单调区间：求的是「函数在哪些区间上单调」必须写开区间；说「在区间 D 上单调」是条件，不能按求解单调区间来处理；
- 切线：说「在点 P 处的切线」切点已定；说「过点 P 的切线」须设切点再列两条件（切点在线上、切线过 P）；
- f(x+a)=f(b−x) 是对称关系（对称轴 x=(a+b)/2），不是周期；f(x+a)=−f(b−x) 为中心对称；
- 双变量 f(x₁)≤g(x₂) 对任意 x₁、x₂ 成立 ⇔ f 的最大值 ≤ g 的最小值；单变量是对同一 x 比较；
- 函数 f(x) 单调与数列 aₙ=f(n) 单调：数列只看整数点，端点处的跳跃可能不同。
**易错点**
- 过点切线漏设切点，直接代点求斜率；
- 对称式与周期式混淆，导致周期算成 2a 或 2(b−a)。
**依据**：`题库/高中数学破题36大招(详例精编).pdf`（OCR 第76—82页）

### 函数与导数 · 零点的三类寻找（存在性定理仅于单调时/拆为两函数交点/导数作图看极值与零/构造奇函数配对）（破题36招 第195—199页）
**核心思路**
- 零点存在性定理只能保证区间内至少一个零点，只有函数在区间上单调时「两端异号」才是唯一的充要条件；
- 方程 f(x)=g(x) 拆成两条曲线求交点，把解的个数转成交点数；
- 超越式方程先求导作出图象，看极值点相对 x 轴的位置并分类讨论参数；
- 方程中含 x²、x 的奇函数结构可构造 g(x)=x²+x 之类的奇函数，把 g(A)=g(B) 转成 A=B（如 g(5x+3)=g(−x)，由奇函数得 5x+3+x=0）。
**易错点**
- 不单调时两端异号也只有一个零点，不能直接下结论；
- 构造奇函数须验证在其定义域上单调，否则 g(A)=g(B) 不能推出 A=B。
**依据**：`题库/高中数学破题36大招(详例精编).pdf`（OCR 第195—199页）

### 函数与导数 · 记住常用对数值直接估算法比较大小（黄金模板 第22—23页）
**核心思路**
- 见到「形如 ln a / b 或 log 底数不同」的比大小，先背下五个近似值：ln2≈0.7、ln3≈1.1、lnπ≈1.14、ln5≈1.6、ln7≈1.95；
- 把每个量换算成小数（如 ln2/2≈0.35、ln3/3≈0.367、ln5/5≈0.32），再排序；
- 换成同底的对数后再除以 ln 底数，分子分母都用近似值；
- 若两个量的小数非常接近（差值小于 0.02），改用构造函数或中介值法复核，不要在此法上硬判。
**易错点**
- 近似值只取一位小数就下结论，遇到接近的选项会排错；
- 把 ln 近似值直接当成 log 的值（换底后要除以底数的 ln）。

### 函数 · 部分奇偶性（偶部与奇部分解）（解题觉醒 第10—11页）
**核心思路**
- 定义域关于原点对称的函数都可写成 f(x)=g(x)+h(x)，其中 g 为偶函数、h 为奇函数（偶部与奇部）。
- 已知 f(x₀)=m 求 f(−x₀)：先观察解析式，把"无参数、结构简单"的那一部分定为偶部或奇部。
- 若奇部简单，用 h(−x₀)=−h(x₀) 作桥梁；若偶部简单，用 g(−x₀)=g(x₀) 作桥梁，联立 f(x₀)=g(x₀)+h(x₀) 解出所求。
- 含参时先判断参数落在偶部还是奇部，再决定用哪条关系。
**易错点**
- 分解前必须确认定义域关于原点对称，否则奇偶性不成立。
- 题目给的定义域若有限制，最后代入 x₀、−x₀ 时要注意二者都需在定义域内。
- 不要直接把整个函数当奇函数或偶函数处理，非奇非偶是常态。

### 函数 · 双对称推周期的三条距离公式（解题觉醒 第13—15页）
**核心思路**
- 两条对称轴 x=a、x=b：周期 T=2|b−a|（"双轴二周期"）。
- 两个对称中心 (a,0)、(b,0)：周期 T=2|b−a|（"双心二周期"）。
- 一条对称轴 x=b 加一个对称中心 (a,0)：周期 T=4|b−a|（"一轴一心四周期"）。
- 特例：偶函数且图象关于 x=a 对称，T=2|a|；奇函数且图象关于 (a,0) 对称，T=2|a|。
- 证法统一：由 f(x)=f(2b−x) 或 f(x)+f(2a−x)=0，用 2a−x 替换 x 两次，消去中间量得 f(x+T)=f(x)。
**易错点**
- 反向不成立：函数以 2|a| 为周期，不一定满足 f(x)+f(x+a)=b 这类"半周期"关系，不能由周期反推对称式。
- 一轴一心先得到的是 f(x)+f(2b−2a+x)=0 的"半周期"关系，必须再替换一次才能得 4|b−a|，直接写 2|b−a| 是错的。
- 对称中心必须落在 x 轴上（形如 (a,0)），中心纵坐标不为 0 时上述周期公式不适用。
**依据**：`题库/02-【数学】解题觉醒27版/数学解题觉醒-第2册 名师大招册.pdf`（OCR 第13—15页）

### 导数 · 分割法证明不等式（解题觉醒 第34页）
**核心思路**
- 要证 f(x)=g(x)−h(x)>0，可分别求 g 的最小值与 h 的最大值，证 g_min>h_max。
- 要证 f(x)<0，则证 g_max<h_min。
- 适用前提：题目本身的分割特征明显，拆出的两个函数一个凹、一个凸（f″>0 为凹，f″<0 为凸），最值才便于分别在端点/极值点取得。
- 两个函数各自独立求最值，避免对 f 直接求导后面对复杂的导函数。
**易错点**
- 凹凸前提不满足时，g_min 与 h_max 可能不在同一位置取得，比较失去意义。
- 两个最值必须取自同一区间；区间不同则不能直接比较。
- 等号不能同时取到时只能写严格不等号，结论中的"≥"要降为">"。

### 导数 · 零点比大小破双参比值（申老师一轮一册 第131—133页）
**核心思路**
- 适用题型：形如 kx+b≤f(x) 或 kx+b≥f(x) 在一段区间（或全 R）上恒成立，求 b/k、b−2k+1 这类「只含直线截距与斜率」的式子的最值或范围；解答题可构造函数 g(x)=f(x)−kx 求最值，选填压轴用本法则省去大量运算；
- 先做「直曲分离」：把不等式整理成直线在一侧、曲线在另一侧，并判断 f 的凹凸——f″>0（凹）时 kx+b≤f(x) 的临界状态是直线与曲线相切，f″<0（凸）时 kx+b≥f(x) 的临界状态是相切；
- 记直线与 x 轴交点的横坐标为 −b/k，曲线在相应单调区间上的唯一零点为 x₀；恒成立等价于交点与零点的大小关系：kx+b≤f(x) 要求 −b/k ≥ x₀，kx+b≥f(x) 要求 −b/k ≤ x₀（相切时取等号）；
- 于是「求 b/k 的最值」被换成「用 f 的零点去卡 b/k 的界」，最值在相切位置取得；题目给的是 e^x、ln x、二次式与一次式的混合时，先移项配成标准形，再读出直线的零点。
**易错点**
- 凹凸方向判断错会导致不等号方向取反，务必先看 f″ 的符号再定「≥ x₀」还是「≤ x₀」；
- 直线零点是 −b/k，题目若求 b−2k+1 之类偏移量，要先把一次式写成 k(x−x₀) 的形式再套结论；
- 只在「直线与曲线相切」这一临界处取最值，不要拿曲线端点值代替。

### 导数 · 三次函数三零点处切线斜率的倒数和为零（申老师一轮一册 第134—135页）
**核心思路**
- 设三次函数有三个零点 x₁、x₂、x₃，在点 (xᵢ,f(xᵢ))（i=1,2,3）处切线斜率为 kᵢ：若函数形如 a(x−x₁)(x−x₂)(x−x₃)，则 kᵢ=a(xᵢ−xⱼ)(xᵢ−xₖ)，三者取倒数后相加恰好抵消，得 1/k₁+1/k₂+1/k₃=0；
- 求「k₁+mk₂」一类最值时，把上式与已知的某个斜率联立，消去 k₃，再用基本不等式或二次函数求最值；
- 该式成立的前提是三个零点互不相等（有重根时某条切线斜率可能为零，倒数无意义）；
- 同一节的两个配套结论可直接用：对称中心横坐标是导函数的对称轴，也是两极值点的中点（二阶导零点）；对称中心处的导数值等于两极值点连线斜率，即 (f(x₁)−f(x₂))/(x₁−x₂)=f′(x₀)。
**易错点**
- 只对「三零点」情形成立，两零点（其中一个为切点）时不能套；
- kᵢ 的顺序与零点顺序要对应，乱序代入会把和式写错。
