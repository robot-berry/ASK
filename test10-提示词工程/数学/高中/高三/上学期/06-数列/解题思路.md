## 五、数列

### 13. 数列通项与求和（题型15—18）

**核心思路**
- 选填速算：等差中项性质、片段和、和比/项比；
- 通项：$a_n=S_n-S_{n-1}$（$n\ge2$）、累加、累乘、构造（$a_{n+1}=pa_n+q$ 等五类）、隔项数列；
- 求和：分组、裂项、错位相减（可用速算公式）、奇偶并项、周期；
- 不等式：放缩为裂项/等比结构；数学归纳法。

**易错点**：$n=1$ 未验证；裂项系数；错位相减项数。

### 13.1 等差、等比的性质与片段和（题型15）

**核心思路**

- 等差：$a_n=a_m+(n-m)d$，$a_m+a_n=a_p+a_q$（$m+n=p+q$）；$S_n$、$S_{2n}-S_n$、$S_{3n}-S_{2n}$ 成等差；
- 等比：$a_n=a_m q^{n-m}$，$a_m a_n=a_p a_q$；$S_n$、$S_{2n}-S_n$、$S_{3n}-S_{2n}$ 成等比（需 $S_n\ne0$）；
- 和比 $\dfrac{S_n}{T_n}$ → 项比：$S_{2k-1}=(2k-1)a_k$，故 $\dfrac{a_k}{b_k}=\dfrac{S_{2k-1}}{T_{2k-1}}$；
- 奇数项和 / 偶数项和之比用 $n$ 的奇偶分别表示。

**易错点**：等比片段和成等比要检验 $S_n\ne0$（$q=-1$ 且 $n$ 为偶数时失效）；用和比求项比时下标必须是 $2k-1$。

### 13.2 通项：$a_n=S_n-S_{n-1}$ 与五类构造（题型16）

**核心思路**

1. 已知 $S_n$ 求 $a_n$：$a_1=S_1$；$n\ge2$ 时 $a_n=S_n-S_{n-1}$；结果分 $n=1$ 与 $n\ge2$ 写出，再检验能否合并；
2. 累加：$a_{n+1}-a_n=f(n)$（$f(n)$ 可求和）；
3. 累乘：$\dfrac{a_{n+1}}{a_n}=f(n)$（$f(n)$ 可求积）；
4. 构造 ${a_{n+1}=pa_n+q}$：设 $a_{n+1}+t=p(a_n+t)$，$t=\dfrac{q}{p-1}$；
5. 构造 $a_{n+1}=pa_n+q^n$：两边同除 $q^{n+1}$，得 $\dfrac{a_{n+1}}{q^{n+1}}=\dfrac{p}{q}\cdot\dfrac{a_n}{q^n}+\dfrac1q$；
6. 构造 $\dfrac{a_{n+1}}{a_n}=\dfrac{p a_n}{q a_n+r}$：取倒数得 $\dfrac{1}{a_{n+1}}=\dfrac{r}{p}\cdot\dfrac{1}{a_n}+\dfrac{q}{p}$；
7. 隔项递推 / 奇偶分段：分别求奇数项、偶数项，再按 $n$ 的奇偶合并。

**易错点**：用 $S_n$ 时忘记先算 $a_1$；构造后遗漏首项检验；隔项数列合并时下标写错。

### 13.3 求和的五种套路（题型17）

**核心思路**

- 分组求和：$\{a_n\pm b_n\}$ 型，分别求等差 / 等比和再加减；
- 裂项相消：$\dfrac{1}{n(n+k)}=\dfrac1k\left(\dfrac1n-\dfrac1{n+k}\right)$；根式型 $\dfrac{1}{\sqrt{n}+\sqrt{n+k}}$ 有理化；
- 错位相减：$\{a_n b_n\}$（等差×等比），$S_n$ 与 $qS_n$ 相减后中间成等比；
- 奇偶并项：$(-1)^n$ 型，按 $n$ 的奇偶分情况求和；
- 周期与类周期：先找 $\{a_n\}$ 的最小正周期，整周期部分整体求和。

**易错点**：裂项系数 $1/k$ 漏写；错位相减后剩余项数（首项 + 末项）；奇偶讨论要覆盖 $n$ 为奇、偶两种。

### 13.4 数列不等式（题型18）

**核心思路**

- 放缩方向：证「和 < 常数」时把小项放大成可裂项 / 可等比的结构，证「和 > 常数」时缩小；
- 常用放缩：$\dfrac{2}{\sqrt n}<2(\sqrt n-\sqrt{n-1})$ 一类根式放缩；$\dfrac{1}{n^2}<\dfrac{1}{n(n-1)}$；$\dfrac{1}{2^n}$ 等比界；
- 证明方法：数学归纳法（先验证 $n=1$，再用归纳假设）；构造函数用导数；
- 参数问题：由单调性 / 最值反推参数范围，注意 $n\in\mathbb N^*$ 离散性。

**易错点**：放缩过头导致目标不成立；归纳假设只用于 $n$ 却当成 $n+1$；离散最值不能直接用连续函数的端点。

### 第40讲 数列的基本知识与概念
**核心思路**
- 周期性：由递推式先算出数列前几项，确定周期后再按周期性求值，这是本讲对周期问题的唯一方法指引。
- 单调性：源文给出三种方法——作差比较（看相邻两项差的符号）、作商比较（看相邻两项之比与 1 的大小）、数形结合（结合相应函数图象直观判断）。
- 最大（小）项：可把通项视为 f(n) 求函数最值；或用相邻项不等式组（前项不小于后项、后项不小于前项）夹出最值项；或比较相邻项判断单调后取端点。
- 规律问题：用特殊值法、列举法找规律，多为图形计数、数学文化类数列。
- 恒成立问题：分离参数，转化为最值问题处理。
- 递推数列：按递推式具体变形——本例中用到取倒数构造等差数列、算前几项观察周期、特殊值猜想通项三条路径。
**易错点**
- 由 S_n 求 a_n 时，不要忽视对 n=1 的验证（源文【注意】）。
- 用相邻项不等式组定最大（小）项时，"n≥2" 的条件不能漏，首项须单独检验。

### 第41讲 等差数列及其前n项和
**核心思路**
- 基本量运算：贯穿方程思想，求公差 d 或项数 n 一般列方程；求通项抓 a_1 与 d 两个基本元素；求特定项用通项公式或性质；求前 n 项和可直接用公式，也可借等差中项间接求。
- 判定与证明四法：定义法（相邻两项差为同一常数）、等差中项法（2a_n = a_{n+1} + a_{n-1}）、通项公式法（a_n 为 n 的一次式）、前 n 项和公式法（S_n 为无常数项的二次式）。
- 性质：若 m+n=p+q，则 a_m+a_n=a_p+a_q；出现 a_{m-n}、a_m、a_{m+n} 这类项时借此把条件集中到某一项；求 a_m 可用 a_m 等于 a_{m-n} 与 a_{m+n} 之和的一半。
- 前 n 项和性质：S_n、S_2n−S_n、S_3n−S_2n 仍成等差数列；S_n/n 也成等差数列。
- 前 n 项和最值两法：函数法（把 S_n 看作关于 n 的二次函数，配方或借图象求最值）；邻项变号法（首项正、公差负时由"该项非负、下一项非正"定最大项数；首项负、公差正时由"该项非正、下一项非负"定最小项数）。
- 奇偶项、含绝对值求和：奇偶项通项不统一时按 n 的奇偶分类讨论；正项起始的递减等差数列求绝对值和，先找零值或符号由正变负的项 a_m，再分段——n≤m 时取 S_n，n>m 时取 2S_m−S_n。
**易错点**
- 基本量问题以方程思想为主，要注意公式使用的准确性与合理性、运算的准确性；遇到较复杂方程组时运用整体代换思想（源文【注意】）。
- 奇偶项通项不统一的求和必须分类讨论，从 n 为奇数、偶数入手。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第41讲等差数列及其前n项和.pdf`（OCR 第1—31页，原文共37页，OCR 止于第31页）

### 第42讲 等比数列及其前n项和
**核心思路**
- 基本量运算：等比数列有首项、项数、公比、通项、前 n 项和五个量，一般"知三求二"，列方程（组）解决；前 n 项和公式涉及对公比是否为 1 的分类讨论。
- 判定四法：定义法（相邻两项之比为非零常数）、中项公式法（a_{n+1} 的平方等于 a_n 与 a_{n+2} 之积）、通项公式法（可写成 c 乘 q 的 n−1 次方）、前 n 项和公式法（S_n 形如 k 乘 q 的 n 次方再减 k）。
- 项的性质：注意挖掘隐含条件，用"若 m+n=p+q=2k，则相应两项之积相等（且等于 a_k 的平方）"减少运算量；用性质时注意前提条件，必要时适当变形，并注意设而不求。
- 前 n 项和性质：奇数项和与偶数项和之比与公比有关（项数为偶数时为 q）；q≠−1 时 S_k、S_2k−S_k、S_3k−S_2k 也成等比数列，公比为 q 的 k 次方。
- 奇偶项求和：准确记求和公式、合理选取公式，尤其注意项数 n；奇偶项通项不统一时按 n 奇偶分类。
**易错点**
- 由 S_n 求 a_n：n=1 时若适合"相邻前 n 项和之差"的形式，可并入 n≥2 的通项；若不适合，须用分段函数表示（源文"注意"）。
- 求前 n 项和要准确记住公式并合理选取，尤其注意项数 n 的取值。
- 等比性质成立有前提条件，套用前要核验。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第42讲等比数列及其前n项和.pdf`（OCR 第1—36页，原文共59页，OCR 止于第36页）

### 第43讲 数列的通项公式
**核心思路**
- 观察法：由一列数、式或图形观察各项变化求通项；注意三点——符号变化是否含 (−1) 的 n 次方或 n−1 次方、各项规律与序号的关系、熟记自然数列/正奇数列/正偶数列/平方数列/2 的 n 次方/等差/等比这些基本块及其组合。
- 叠加法：形如"后项等于前项加 f(n)"且 f(1)+…+f(n) 可求时，变形为相邻项之差等于 f(n)，累加求通项。
- 叠乘法：形如"后项等于 f(n) 乘前项"且 f(1)…f(n) 之积可求时，变形为相邻项之比等于 f(n)，累乘求通项。
- 待定系数法：形如"后项等于 p 倍前项加 q"（p、q 为常数，p≠1）可构造等比数列；也可与前一式作差，构造相邻项之差成等比，再用叠加法。
- 同除以指数：形如"后项等于 p 倍前项加 d 的 n 次方"（p≠1，d≠1），p=d 时两边同除以 d 的 n+1 次方化为等差数列；p≠d 时同除后化为可继续用待定系数处理的递推式。
- 取倒数法：分式递推式中系数相同则倒数列为等差；系数不同则令新数列为原项的倒数，再用待定系数法。
- 取对数法：形如"后项等于 c 乘前项的某次幂"（c>0，各项为正），两边取对数化为等比数列。
- 已知通项与前 n 项和关系：先把 n 与 n−1 两式相减消去和，构造辅助等比（如把 S_n−n 作为整体），再由和差求通项并单独验证首项。
**易错点**
- 取对数时底数不一定要取 10，可根据题意选择（源文括注）。
- 由 S_n 求 a_n 必须单独验证 n=1，否则易漏分段。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第43讲数列的通项公式.pdf`（OCR 第1—36页，原文共80页，OCR 止于第36页）

### 第44讲 数列求和
**核心思路**
- 通项分析法：先分析通项特点，再据此选择求和方法；这是求前 n 项和首先应强化的意识。
- 公式法：先确定数列类型，符合等差或等比时直接用相应求和公式。
- 错位相减法：适用于"等差乘等比"型数列；步骤为展开、乘公比、错位相减、求和；等差乘等比型的和可设为含 n 的一次式乘 q 的 n 次方形式再作差。
- 分组求和法：从通项入手，无通项先求通项，把通项变形拆成等差或等比数列的和差再分别求和；常见类型是通项为两个等差/等比数列之和差，或按 n 的奇偶分段给出不同通项。
- 裂项相消法：三步为裂项（把通项拆成两项之差）、累加、消项（中间项相消，剩余有限项相加）。
- 倒序相加法：若数列与首末两端等"距离"的两项之和相等或为同一常数，即可倒序相加。
**易错点**
- 写 S_n 与 qS_n 时必须"错位对齐"，否则下一步的差写不准；作差后减式中所剩各项要变号（源文注意事项）。
- 裂项原则：前边裂几项、后边就裂几项，直到看出被消项的规律；消项后前边剩第几项、后边就剩倒数第几项。
**依据**：`题库/2027年高考数学一轮复习讲义/2027年高考一轮复习讲义-解析版/第44讲数列求和.pdf`（OCR 第1—36页，原文共56页，OCR 止于第36页）

### 第45讲 数列的综合应用
**核心思路**
- 数学文化与实际应用：三步走——脱去文化背景读懂题意、构造等差/等比/递推模型、求解模型；解应用题要过"四关"：审题关、建模关（分清等差还是等比）、求解关、还原关。
- 新定义问题：耐心读题，分析新定义的特点与性质，按新定义要求"照章办事"，逐条分析、运算、验证。
- 与函数、不等式综合：函数条件解数列题借函数性质与图象；数列条件解函数题借通项、前 n 项和与求和方法化简；不等式恒成立转化为最值——大于某式恒成立取该式最大值，小于某式恒成立取该式最小值。并注意数列只是自变量为正整数的一类函数，有其特殊性。
- 实际应用模型：增量固定为等差模型，比值固定为等比模型，前后关系随项变化则为递推模型；涉及递增率或递减率用等比，涉及依次增加或减少用等差。
- 不等式证明：构造辅助函数（数列）证明；或用放缩法——对通项放缩后再求和（化为可裂项相消或可压缩等比）、添舍放缩、把另一边含 n 的式子看作某数列的前 n 项和（积）后一对一比较、单调放缩。
- 公共项与插项：源文例题显示，公共项组成的新数列仍是等差或等比数列（公差为原两公差的最小公倍数，如公差 4 与 6 得 12；或公比按固定倍数出现）；插项后新数列公差为原公差除以"插入个数加 1"（如相邻两项间插 3 个数，公差变为原来的四分之一）。
**易错点**
- 数列只能看作自变量为正整数的一类函数，解决问题时要注意这一特殊性。
- 实际问题作答不要忽视问题的实际意义。
- 放缩法必须有目标，目标从要证的结论中查找，并对照结论调整、控制放缩的度。

### 第41讲 等差数列及其前n项和 · 续
**补充思路**
- 数列单调性：源文【解题方法总结】指明，处理单调性应先利用数列单调性的定义，即「递增数列等价于对任意正整数 n，后项恒不小于前项」；但需注意 a_n = f(n) 的单调性与相应连续函数在 n≥1 上的单调性并不完全一致，源文表述为「离散函数有单调性则连续函数有单调性；连续函数有单调性则离散函数有单调性」，可借助对应连续函数的单调性求解。
- 新题型「等差数列中的范围与恒成立问题」：把「S_n 不超过某个固定项 S_k 恒成立」化为 S_k 是前 n 项和的最大值；判断给定通项是否满足时可看作 S_n 有无最大项——若数列递增且某起点后各项为正，则 S_n 无最大项，不满足。
- 已知数列递推式证明其为等差数列：可用「n 与 n+1 两式作差」得到后项、前项与再前项的关系（形如后项减两倍中间项加前项为零），从而判定为等差数列。
- 求形如 S_n 除以某指数式所得数列的最值：作相邻项之差判断单调性，发现从某项起数列递减后，最大项在前几项中比较得出。
- 由「存在正整数 k 使对任意 n 都有 S_n 不超过 S_k」求 k：先由条件列出关于首项与公差的方程组求出首项、公差，再写出 S_n，用函数法（配方或二次函数图象）求最大值点即为 k。
- 「S_n 恒有最大值」与「公差负」的关系：源文例题说明，公差为负时无论首项正负，S_n 都有最大项；反之若 S_n 有最大项则公差必为负。
**补充易错点**
- 数列单调性不能直接套用连续函数单调性，二者只是单向蕴含，须以「对任意正整数 n 后项不小于前项」的定义为准。

### 第42讲 等比数列及其前n项和 · 续
**补充思路**
- 新题型「等差数列与等比数列的综合应用」：源文【解题方法总结】给出两条交汇规律——等差数列通过指数运算转化为正项等比数列，正项等比数列通过对数运算转化为等差数列；若一个数列既是等差数列又是等比数列，则该数列为非零常数数列。
- 「任意三项不能构成等比数列」的证明：用反证法，假设存在不同三项成等比，代入通项公式得到关于序号的方程组，结合等差中项关系推出两序号相等，与「不同三项」矛盾。
- 等比数列奇偶项递推问题：先取偶数项作新数列，验证其相邻项之比为常数，再用奇数项与偶数项的递推关系回代求出奇数项通项。
- 分式型 b_n 为 S_n 除以 n 的形式转成等比数列后求通项：先得出等比数列的通项，再借递推式反解 a_n；或直接用等比数列通项反求原项（源文例题方法二）。
- 插入项求公差：在相邻两项间插入 n 个数组成等差数列时，公差等于两项之差除以（n+1）；等比数列插入项问题可用该公差表示各项，再用「三项成等比、序号成等差」推得序号相等而得出「不存在」的结论。
- 新题型「等比数列的范围与最值问题」：判断数列及其相邻项乘积、相邻两项之和的单调性，用相邻项之差与零比较（结合公比范围 q 与 1 的大小、q 在 -1 与 0 之间时相邻项的符号）得出最大项、最小项；前 n 项和的最大值、最小值按公比的正负区间分类讨论。
- 前 n 项积 T_n 的最值：由「某项之前的积小于 1、某项的积大于 1」确定使 T_n 超过（或小于）1 的最大或最小自然数；常用「T 为奇数项个数乘各项之积」「拆成首末配对的两项之积」来比较与 1 的大小。
- 含条件「a_n 减 1 之积小于 0、相邻两项乘积大于 1」的不等式选择题：先由条件推出公比大于 0 且在 0 与 1 之间，再逐项验证前 n 项和的变化与前 n 项积的最大项。
- 三角形三边成等比数列求公比范围：分公比不小于 1 与小于 1 两种情况，用两边之和大于第三边列二次不等式求解。
- 新题型「等比数列的实际应用」：增长型实际问题可设「相邻项减去常数 k 后成等比」的形式，先对照递推式求出 k，再转化为等比数列求前 n 项和；古代数学文化题（如《增减算法统宗》）把每天行走路程排成等比数列求和求某一天。
- 数表型实际应用：数表相邻行第一个数之差为 2 的幂，导出「后行首项等于两倍前行首项加上 2 的某次幂」的递推式，两边同除以适当次幂化为等差数列；再由「2 的幂的个位数以 4 为周期」逐个确定个位数字反推届别年份。

**补充易错点**
- 讨论等比数列前 n 项和的最值须区分公比大于 0 小于 1、公比在 -1 与 0 之间两种情形，后者 S_n 不单调。

- 二阶递推奇偶分项：由相邻差求出后，按 n 为奇数、偶数分别累加（只隔一项累加），最后写成分段形式。
- 纠缠型双数列：两数列的递推式相加得等比、相减得等差，联立求 aₙ+bₙ、aₙ−bₙ 后相加求出 aₙ；或用消元法把第二个数列消掉，化为单数列二阶递推，再用特征根法。
- 一个数列由两个数列关系给定时，先消元成单一数列的二阶递推，再用特征根求出通项。
- 通项含 aₙ₊₁+aₙ 的结构（如抛沙包、接力传球类）：由 aₙ₊₁+aₙ=常数（如 2ⁿ）看出 {aₙ₊₁+aₙ} 为等比数列，再给各项同乘 (−1)ⁿ 后交错累加求出 aₙ。
- 实际情境构建递推：由相邻两步的实际关系列出 aₙ 与 aₙ₋₁ 的关系，再用等比数列求通项。如溶液互换浓度的调和问题，由浓度差成等比求出 aₙ−bₙ，再由浓度和不变求出 aₙ、bₙ；市场占比类，设 bₙ₊₁=(1−转移率)bₙ+转入率·aₙ，求不动点构造等比数列。
- 双曲线与直线交替取点：从曲线上一点作水平线交另一曲线，再作垂直线交回，由两曲线方程求出横坐标递推，再构造递推式求通项（原文配图，OCR 无法还原）。
**补充易错点**
- 二阶递推构造等比时，需先说明相邻差不为零（否则不能作比值），原文均先验证该差与已知首项不矛盾。

### 数列 · 已知 S_n 关系式时利用隐藏 S_n 转化（浙大优辅16 第1讲）
**核心思路**
- 看到「S_n 与 a_n 混在同一个递推式中且不能直接解出 a_n」：用 a_n=S_n−S_{n−1} 把含 a_n 的项全部换成 S，得到只含 S_n 的递推，先求 S_n 再求 a_n；
- 若关系式是「对任意 n 的恒等式」（如 S_n=a_n−某式），令 n=1 先得 a_1，再作差消去 S；
- 若给的是「S_n 与 n 的关系」直接求 S_n 通式，再分段求 a_n。
**易错点**
- 用 a_n=S_n−S_{n−1} 只在 n≥2 成立，n=1 单独算；
- 换 S 后得到的递推还需补充 S_1=a_1。

### 数列 · a_n 与 S_n 互化（浙大优辅16 第1讲）
**核心思路**
- 已知 S_n 求 a_n：a_1=S_1，n≥2 时 a_n=S_n−S_{n−1}，最后统一写出并检验能否合并；
- 已知 a_n 求 S_n：先把 a_n 拆成可求和结构，再按错位/裂项/分组求和；
- 递推式含 S_n 时可改为「S_{n}−S_{n−1} 代入」，若递推式是关于 a_n 的一阶式，也可两边累加得 S_n。
**易错点**
- 分段写出的 a_n 必须检验 n=1 是否合并；
- S_n−S_{n−1} 时下标不能提前代入。

### 数列 · 待定系数构造等比数列（浙大优辅16 第4讲）
**核心思路**
- a_{n+1}=pa_{n}+q：设 a_{n+1}+t=p(a_n+t)，解 t=q/(p−1)，得 {a_n+t} 等比，先求 t 再写通项；
- a_{n+1}=pa_n+q·r^n（底数不同）：先除以 r^{n+1} 或先设 a_{n+1}+λr^{n+1}=p(a_n+λr^n) 求 λ；
- a_{n+1}=pa_n+f(n)（f 为一次式）：设 a_{n+1}+A(n+1)+B=p(a_n+An+B)，比较系数定 A、B。
**易错点**
- p=1 时 t 公式失效，此时改为累加；
- 求通项前须补首项 a_1+t 的值，否则等比首项缺项。

### 数列 · 取倒数转化为等差（浙大优辅16 第4讲）
**核心思路**
- 看到 a_{n+1}=a_n/(k·a_n+1) 或 a_{n+1}·a_n 与 a_{n+1}−a_n 同时出现：两边取倒数，得 1/a_{n+1}=1/a_n+k，化为等差；
- 若取倒数后仍带常数项（形如 1/a_{n+1}=A/a_n+B），改为对 1/a_n 用待定系数构造等比；
- 递推式分母含 a_n 的一次式时也可先同除 a_n 再换元 1/a_n。
**易错点**
- 取倒数前须确认 a_n≠0 对所有 n 成立（若可能为 0 先单独讨论）；
- 首项 1/a_1 要单独写出，别把 n=1 漏掉。

### 数列 · 取对数降幂（浙大优辅16 第4讲）
**核心思路**
- 看到 a_{n+1}=c·a_n^k（k≠1）式的乘方递推：两边取对数得 lg a_{n+1}=k·lg a_n+lg c，再对待定系数构造等比；
- 若 a_{n+1}=(a_n)^k 且首项为幂的形式，可直接观察出 lg a_n 的通项，再还原 a_n；

- 取对数要求 a_n>0 恒成立，需先证正项（如由 a_1>0 与递推式归纳）；

### 数列 · 同除以指数幂构造（浙大优辅16 第4讲）
**核心思路**
- 看到 a_{n+1}=pa_n+q^n：两边同除 q^{n+1}，得 a_{n+1}/q^{n+1}=(p/q)(a_n/q^n)+1/q，对 a_n/q^n 构造；

- 若递推为 a_{n+1}=p·a_n/q^n，先取倒数与同除结合，两边同乘 q^n 化为常数系数形式。
**易错点**
- 除以 q^{n+1} 而不是 q^n，指数差一位会导致常数项 1/q 变成 1；
- q 为负数时除以 q 的幂需注意符号。

### 数列 · 累加法与累乘法的适用判别（浙大优辅16 第4讲）
**核心思路**
- a_{n+1}−a_n=f(n)、f(n) 可求和：累加，n≥2 时 a_n=a_1+Σf(k)（k=1 到 n−1）；
- a_{n+1}/a_n=f(n)、f(n) 可求积：累乘，a_n=a_1·Πf(k)；
- 判断可求和/可求积：f(n) 为多项式、指数、简单分式（可裂项）时用累加；f(n) 为 (an+b)/(cn+d) 可化约时用累乘。
**易错点**
- 累加上限是 n−1（n≥2），写成 n 会多一项；
- 累乘时 a_1 不能参与乘积，须单独乘上；
- f(n) 含 0 项时累乘结果需验证。

### 数列 · 周期数列的判定与求值（浙大优辅16 第1讲）
**核心思路**
- 递推式只含相邻几项（如 a_{n+2}=f(a_{n+1},a_n)）时，先代 a_1、a_2 依次算前几项，找到重复的项即得周期；
- 周期确定后，对任意大下标 n 求 a_n：用 n 除以 T 取余，余 0 对应第 T 项；
- 若递推式可变形为 a_{n+1}=±1/a_n 型，周期常为 3 或 4，先算三项即可确认。
**易错点**
- 周期从哪一项开始重复（有的含前项的例外）须按实际重复起点判断，不能默认从 a_1；
- 求 a_n 时下标从 1 起算，余数 0 不能写成第 0 项。

### 数列 · 单调性判断与最值项定位（浙大优辅16 第1讲）

### 数列 · 不动点法与特征根法求通项（浙大优辅16 第5讲）
**核心思路**
- 分式递推 a_{n+1}=(p·a_n+q)/(r·a_n+s)：先解不动点方程 x=(px+q)/(rx+s)，两不动点时构造等比（1/(a_n−x1) 与 1/(a_n−x2) 的比）；一不动点时取倒数化为等差；

**易错点**
- 分式递推的不动点重根情形不能套两不动点的构造式，改用倒数；
- 特征根为复数时仍需用原式，不能直接套实数形式。

### 数列 · 递推式变形中的同构构造（浙大优辅16 第5讲）

### 数列 · 等差与等比性质在通项中的运用（浙大优辅16 第2—3讲）
**核心思路**
- 等差：a_m+a_n=a_p+a_q（m+n=p+q）；a_n=a_m+(n−m)d；a_p、a_q、a_r 成等差则 2a_q=a_p+a_r；
- 等比：b_m·b_n=b_p·b_q（m+n=p+q）；b_n=b_m·q^{n−m}；正项等比中项；
- 求通项时优先用性质消元减少未知量（如三项相等关系代出 d 或 q）。
**易错点**
- 下标和相等的性质对等差、等比分别成立，不能交叉；
- 等比中用性质时各项不为 0、公比不为 0。

### 数列 · 数列中的恒成立与最值（浙大优辅16 第1讲）
**核心思路**
- 含参不等式对 n∈N* 恒成立：分离参数，得参数大于（小于）相应表达式的最值；
- 表达式最值用作差比较得单调性，找出 n 取何值时取到（可能在某项处）；
- 若参数与 n 的项号相联系，可分 n 为奇、偶两情形分别取最值，再合并参数范围。
**易错点**
- 离散最值只能用项比较，不能用导数连续结论代入；
- 分离参数时除以的式子在 N* 上的符号要固定（如有零项需分开）。

### 数列 · 基本量法（核心方法 第115—117页）

### 数列 · 错位相减法（核心方法 第125—127页）
**核心思路**
- 见到通项是「等差 × 等比」型（等差部分与等比部分相乘），求前 n 项和就用错位相减：写出 $S_n$，再写 $q S_n$（各项乘以公比），两式相减；
- 相减后中间一段正好是等比数列，用等比求和公式一次算出，只保留首项与末项两组「错位项」；

### 数列 · 裂项相消法（核心方法 第130—132页）
**核心思路**

### 数列 · 模型111 一阶线性递推的待定系数构造（A049 第285—288页）
**核心思路**

**易错点**
- 构造出的新等比数列，首项要用原数列首项现算，不能沿用；
- 换元后最后一定要还原成 a(n)；
- λ=1 时不能用待定系数构造等比。

### 数列 · 模型116 二阶递推的降阶与特征根（A049 第295—297页）
**核心思路**
- 形如 a(n+2)=p·a(n+1)+q·a(n)（p、q≠0）；
- 降阶构造：设 a(n+2)−m·a(n+1)=t(a(n+1)−m·a(n))，展开对比得 m+t=p、mt=−q；解出 m、t 后 {a(n+1)−m·a(n)} 是等比数列，求出它再按一阶递推求 a(n)；
- 若降阶后只剩一个关系（例如得到 a(n+1)+a(n)=g(n)），把它当作一阶线性递推处理（两边同除公比的 n+1 次幂后累加）再求 a(n)；

**易错点**
- m、t 的二次方程两根可交换，选使构造更简单的顺序；
- 重根时通项形式与两根不同时不一样；
- 大题必须写构造过程，特征根法只能验算。

### 数列 · 模型117 周期数列的判定与求和（A049 第297—299页）
**核心思路**

- 和型：a(n)+a(n−1)+…+a(n−k)=s（常数）⇒ 周期 k+1；两两和型 a(n)+a(n−1)=s ⇒ 周期 2；

- n=qT+r 中 r=0 应取整周期末项，不要取第 0 项；

### 数列 · 模型118 裂项（根式、三角与符号型）（A049 第300—303页）
**核心思路**

- 有理化：1/(√(n+1)+√n)=√(n+1)−√n；1/(√n+√(n+k)) 先乘共轭再裂项，裂项后常出现首尾若干项相消；

- 裂项后要数清首尾各剩几项；

### 数列 · 中心对称函数与等差数列（优质解法 第14—15页）
**核心思路**
- 见到 f(a₁)+f(a₂)+…+f(aₙ)=nk，且 {aₙ} 是公差不为 0 的等差数列：先找 f(x) 的对称中心 (h,k)，则必有 a₁+a₂+…+aₙ=nh；

- 若和为 0 且中心为原点，则 Σaᵢ=0，由等差性质得中间项为 0，可直接定位 a_k=0；
- 函数先平移再问（如 h(x)=f(x−4)+x），先求 h 的对称中心，再用同一结论。

- 公差为 0 时中项定位失效，结论退化；

### 数列 · 等差与等比公共项的二项式定位（优质解法 第14页）

### 数列 · 隔项递推的三类处理（优质解法 第24—26页）
**核心思路**
- 类型 1：aₙ−aₙ₋₂=常数 或 aₙ/aₙ₋₂=常数 → 奇数项、偶数项各成等差（等比），分别写出 a₂ₖ₋₁、a₂ₖ，再把 k 用 n 表示合并（可用 (−1)ⁿ 统一成一支）；
- 类型 2：a₂ₖ=a₂ₖ₋₁+f(k)、a₂ₖ₊₁=a₂ₖ+g(k) 交替给出 → 两式合并得 a₂ₖ₊₁−a₂ₖ₋₁=f(k)+g(k)，对奇数项累加，偶数项再回代；
- 类型 3：aₙ₊₁+aₙ=f(n) 或 aₙ₊₁aₙ=f(n) → 写 n+1 的式子与原式相减（相除），得 aₙ₊₂−aₙ 或 aₙ₊₂/aₙ 的关系，再按类型 1 处理。
**易错点**
- 合并后的首项是 a₁（或 a₂），不是 a₀；
- 分奇偶写通项时 k 的换算式（n=2k−1 → k=(n+1)/2）最易错位；
- 乘积型先验证各项非零，否则不能相除。

### 数列 · 根式递推配方成等差（优质解法 第23—24页）
**核心思路**

- 形如 aₙ₊₁=2aₙ²−1、aₙ₊₁=2√aₙ 的递推，也可先配方或直接取对数，化为 log 的线性递推。
**易错点**

### 数列 · 待定系数法裂项（优质解法 第33—36页）

### 数列 · 变号数列的绝对值求和（优质解法 第38页）
**核心思路**
- 先由通项求变号分界：解 aₙ=0 或解 aₙ>0 的不等式，定出最后一个正项的下标 k；

**易错点**
- 分界点要取「最后一个正项」，不是第一个负项；
- 两段公式在 n=k 处应一致，可用来验算；
- 等差通项要先解不等式定 k，不能凭观察。

### 数列 · 类周期数列的周期内捆绑求和（优质解法 第39—40页）
**核心思路**

### 数列 · 互嵌数列组的两条路线（优质解法 第40—43页）

### 数列 · 整除思想解数列不定方程（优质解法 第43—44页）

### 数列 · 伪等比放缩（作商定常数与起放缩项）（优质解法 第45页）
**核心思路**
- 通项含指数式（如 1/(3ⁿ−1)）且要证和小于常数：令 bₙ=通项，计算 bₙ₊₁/bₙ，证明它 ≤ 一个小于 1 的常数（作商后「伪等比变等比」）；
- 由 bₙ₊₁≤q·bₙ 得从第 N 项起 bₙ≤b_N·q^{n−N}，再用等比数列求和；
- 起放缩项 N 由前几项分母与目标分母的共性决定（最多试到第四项），前 N−1 项保留原值；
- 求和后若界仍偏大，可再丢去若干项（第二次放缩）。
**易错点**
- 起放缩项取早了会放缩过头，取晚了界不够；
- 作商时不等号方向要与「放大/缩小」一致；
- 首项参与放缩可能使分母为零或使不等式反向。

### 数列 · 二次函数型裂项放缩（优质解法 第46—47页）
**核心思路**
- 分母为 n²+bn+c 且要证和小于常数：配方后放大成 k²−(n+…)² 的平方差形式，再分解为两个相邻一次因式之积（等差数列相邻项）；
- 于是 1/分母 可裂成两个一次分式之差，求和后首尾相消；
- 分母是 (2n+1)² 时，放大成 4n(n+1) 再裂项；形如 1/[aₙ(aₙ+1)] 且 aₙ=2n 时，先放成 1/[(2n)(2n+1)]；
- 放缩后必须能求和（裂项或等比），不能求和就换放缩方式。
**易错点**
- 放缩方向必须使分母变小（分式变大），方向写反无法传递结论；

- 裂项系数（两因式公差分之一）最易漏写。

### 数列 · 迭代法化常数列求通项（解题方法 第119—122页）
**核心思路**
- 触发：递推中含 (−1)^n 或反复加减同型项，直接分类讨论繁（如 aₙ₊₁=−aₙ+3）；
- 步骤：对递推式连续使用两次（迭代一次）消去符号项：把 n 换成 n+1 再代入，得到 aₙ₊₂ 与 aₙ 的关系；
- 若得到 aₙ₊₂−aₙ=常数（或 aₙ₊₂=qaₙ 型），则奇偶子列各自成等差/等比；分别求两子列通项，再合成；
- 也可找「常数列化」搭档：把式子两侧配成关于 n 的常数项，使某项为定值；
- 对含 (−1)^n·aₙ 的项，整体变形为 aₙ₊₁+(−1)^n·aₙ 型的常数列（两式相加抵消符号项，所得为常数）；

**易错点**
- 合成通项时须按 n 的奇偶写两式，不能只写一个；
- 奇数项子列的项数与偶数项子列项数可能相差 1，求和或个数题中要数清。

### 数列 · 变量替换两式加减消 (−1)^n（解题方法 第119—122页）

### 数列 · 周期性判断 (−1)^n 递推（解题方法 第119—122页）

### 数列 · (an+b)qⁿ 求和的「常数列思想」（解题方法 第110—113页）
**核心思路**
- 触发：数列的通项形如 (an+b)qⁿ，直接错位相减步骤多；
- 步骤：预设 Sₙ=(An+B)qⁿ−B 型（A、B 待定），利用 Sₙ−Sₙ₋₁=aₙ 或 Sₙ₊₁−Sₙ=(an+b)qⁿ 比较系数，解出 A、B；
- 也可对 aₙ₊₁−q·aₙ 写成等比形式再叠加：aₙ₊₁−qaₙ=d·qⁿ 时，可构造「某个常数列」求解；

**易错点**
- Ansatz 形式须与 q≠1 对应；q=1 时为等差数列，不能用此型；

### 数列 · 分式裂项的「线性表示」判据（解题方法 第114—117页）
**核心思路**
- 触发：分式 aₙ=1/(bₙ bₙ₊₁) 或更复杂的分式，要判断能否裂项、怎样裂项；
- 步骤：先看原分式的分母能否被 bₙ、bₙ₊₁（或乘 q 后的相邻项）线性表示：若能写成「k·bₙ₊₁−m·bₙ」的形式，则原式 = A/bₙ + B/bₙ₊₁ 型的拆分；
- 求 A、B：比较分子恒等式，即 1=A·bₙ₊₁+B·bₙ 对 n 恒成立；
- 若分母是二次整式（如 n²+2n−1 型）无法直接拆，可用待定系数裂项（设成 1/Aₙ − 1/Aₙ₊₁ 的倍数）替代错位相减；
- 对数差分数列（ln(n+1)−lnn 型）直接按定义写成叠加和，不必拆分。
**易错点**
- 裂项后缺首项或尾项（「起点丢项」）是常见错误，叠加后要写清剩余项；
- 若线性表示中的系数依赖 n，则不能简单写成两项差；
- 三项连乘时先取中间项，裂项后相邻项相消，剩余首尾项要逐项写出。

### 数列 · 三项递推逆向：两式相减化为一阶（解题方法 第105—109页）
**核心思路**
- 触发：一阶递推 aₙ₊₁=q·aₙ+f(n)（f 为常数、n 的多项式、指数型或几项之和），待定系数构造较繁；
- 步骤：把递推式中的 n 换成 n+1 得第二式，两式相减，得 aₙ₊₂−aₙ₊₁ 的式子；f 为常数时得 aₙ₊₂−aₙ₊₁=q(aₙ₊₁−aₙ)，即差数列成等比；
- f 为多项式或指数时差数列仍是一阶递推，令 bₙ=aₙ₊₁−aₙ 后再回到第一步处理，层层降为求差数列；
- 求出 bₙ 后用叠加法（累加相邻差）求 aₙ；
- f(n) 兼含指数与 n 时，先同除以指数幂化为不含指数的情形，再两式相减；
- 连续三项递推转为相邻两项「往往更简单」，不要一见三项递推就回避。
**易错点**
- 两式相减所得关系对 n 的下限有要求（视原式下标范围），首项要单独给出；
- 差数列首项是 a₂−a₁，须先由原式算出 a₂，不能默认 a₂ 已知。

### 数列 · 递推式主动变形：「尘归尘、土归土」配对（解题方法 第106页）
**核心思路**
- 触发：递推式中同时出现 (n+1)、n 与 aₙ₊₁、aₙ 的乘积混合项，形式复杂（如 (n+1)aₙ₊₁ 与 n·aₙ 分处两边）；
- 步骤：把 (n+1) 与 aₙ₊₁「配成一对」、n 与 aₙ「配成一对」，两边同除以 n(n+1)，使每项都变成「aₙ₊₁/(n+1)」或「aₙ/n」的形式；
- 于是新数列 bₙ=aₙ/n 的相邻差与剩下的整式项构成等差（或一阶递推），问题化为基本型；

**易错点**
- 除因子 n(n+1) 在 n=1 时非零才可直接除，首项 a₁ 要按变形后的式子重新核对；
- 配对方向不唯一，选错方向会得到仍含混合项的式子，须换一种配法再试。

### 数列 · 连乘式写成「首项 × 相邻比值链」（1987解题方法 第22—24页）

- 证明含连乘积的不等式或恒等式时，把连乘积记作 x_n，并写成 x_n=x₁·(x₂/x₁)·(x₃/x₂)…(x_n/x_{n−1})；

### 数列 · 错位相减的规范操作（申老师一轮二册 第33—41页）

### 数列 · 加权和式 Σc(k)a(k)=g(n) 两式相减求通项（怎样解题 第123页）
**核心思路**
- 已知形如「数列各项乘以一个与项数有关的系数后再求和」等于关于 n 的式子（如 Σ c(k)a(k)=g(n)），求 a(n)：把和式中每一项的项数统一换成 n−1，写出 n−1 时的对应和式；
- 两式相减，左边只剩第 n 项 c(n)a(n)，右边只剩 g(n)−g(n−1)，从而解出 a(n)；相减时 n≥2；
- n=1 时和式只剩第一项，单独由原式解出 a(1)，最后验证 a(1) 是否符合 n≥2 的表达式，不符合就分段写；
- 若相减后得到的是 a(n) 与 a(n−1) 的关系式，再按等差、等比或待定系数构造继续求通项。
**易错点**
- 忘记验证 n=1 是否统一；
- 相减后把左边的系数 c(n) 漏掉，直接当成 a(n)；
- 写 n−1 的和式时只把末项换成 a(n−1)，没有同时把系数换成 c(n−1)。
