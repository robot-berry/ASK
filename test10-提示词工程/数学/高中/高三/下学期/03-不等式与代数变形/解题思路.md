## 一、结构识别（先看形，再选法）

### 1. 分式结构：分母是一次式的和
**核心思路**：见到 $\sum \frac{x_i^{m+1}}{y_i^m}$ 或 $\frac{a^2}{x}+\frac{b^2}{y}$，优先**权方和不等式**
$$\sum\frac{x_i^{m+1}}{y_i^m}\ \ge\ \frac{\left(\sum x_i\right)^{m+1}}{\left(\sum y_i\right)^m},$$
等号当 $\frac{x_i}{y_i}$ 全相等时取得。

**易错点**：指数 $m$ 必须与分子、分母的次数匹配；分母须为正。

**依据**：`题型01` 权方和不等式部分。

### 2. 和与积同时出现：均值不等式链
**核心思路**：把条件化成「和」或「积」为定值，再用
$$\frac{n}{\sum \frac{1}{a_i}}\ \le\ \sqrt[n]{\prod a_i}\ \le\ \frac{\sum a_i}{n}\ \le\ \sqrt{\frac{\sum a_i^2}{n}}.$$
凑定值的手段：乘「1」法（用已知等式构造 $1$）、拆项、配凑系数。

**适用**：「一正二定三相等」缺一不可；等号不能取到时，改用单调性求最值。

### 3. 双变量比值/差值：齐次化与换元
**核心思路**：条件与目标都是齐次式时，令 $t=\frac{b}{a}$（或 $t=a-b$）化为一元；非齐次先通过条件消元变成齐次。

**易错点**：换元后 $t$ 的范围（由 $a,b>0$ 等条件推出）最容易漏。

### 4. 含根号或平方和：三角换元 / 柯西
**核心思路**：
- $\sqrt{1-x^2}$、$\sqrt{a^2-x^2}$ → 设 $x=a\sin\theta$；
- 目标为 $px+qy$、条件为 $x^2+y^2=r^2$ → 柯西不等式 $(p^2+q^2)(x^2+y^2)\ge(px+qy)^2$；
- 目标含 $\sqrt{(x-a)^2+(y-b)^2}$ → 转化为距离，用几何意义。

**易错点**：三角换元后角的范围决定最值能否取到。

## 二、求谁设谁：万能 k 法

### 5. 万能 k 法
**核心思路**：要求 $k=\frac{f(x,y)}{g(x,y)}$ 的最值，令 $k$ 为参数，把等式整理成关于某个变量的**一元二次方程**，由「方程有实根」得 $\Delta\ge0$，解出 $k$ 的范围。

**适用**：分子分母都是二次（或一次）且变量有实数约束。

**易错点**：二次项系数为 $0$ 的情形要单独讨论；$\Delta\ge0$ 只是必要条件，需回代验证等号可取。

**依据**：`题型01` 与 `A049` 模块2。

## 三、放缩与变形

### 6. 糖水不等式（含对数型）
**核心思路**：$0<b<a,\ m>0$ 时 $\frac{b}{a}<\frac{b+m}{a+m}<\frac{b}{a+m}$ 一类不等式，用于分式比较与对数式放缩；对数型常配合 $\ln(1+x)<x$ 使用。

**易错点**：分子分母同加的前提是正数；放缩方向要与目标一致。

### 7. 地位等价法
**核心思路**：目标与条件关于各变量对称时，最值必在变量相等处取得（先猜后证）；证明用均值或调整法。

**易错点**：只适用于**完全对称**的情形；出现 $a\ge b$ 之类的非对称约束时失效。

## 四、答题规范

### 8. 等号成立条件的书写
**核心思路**：每一处不等式都要写出取等条件并回代检验；多个不等式连用时，取等条件必须**同时**成立，否则结论无效。

**易错点**：连续放缩后不检验取等；「恒成立」与「能成立」的最值方向写反。

### 不等式 · 多元最值的分母代换与三角代换（更高更妙 第259—261页）
**核心思路**
- 分式最值题中分母由某几个线性组合组成：直接把每个分母整体设为新变量（分母代换），把原式中各变量都用新变量解出，再套均值不等式，等号条件由新变量比例给出；
- 含根式的最值题（如 √(x²+y²)）：令 x = rcosθ、y = rsinθ 作三角代换，把根式变成 r，将问题变为求 r 与 θ 的函数最值，再求导或配凑；
- 根式可写成「两变量平方和的模」时：设其方向（cosθ, sinθ），利用已知线性式与模的关系（柯西）直接读出最小值，等号时方向与该线性式的法向量对应；
- 二次型无线性约束题（如 x²−3xy−4y² 为定值）：设 x²+y² = t² 后三角代换，把二次式化成 t² 乘以 sin、cos 的线性组合，由该组合的范围求出 t² 的下界。
**易错点**
- 分母代换要保证新变量实际可取到（原变量为正时新变量也有下界），否则等号不可达；
- 三角代换后 θ 的取值范围（象限）必须与题设一致，否则最值会取到不存在的方向。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第259—261页）

### 不等式 · 多元最值的判别式法与待定系数法（更高更妙 第261—262页）
**核心思路**
- 求 t = 含根式的线性式 的最小值：先把根式用 t 和一个变量解出，平方化成关于该变量的一元二次方程，用判别式 ≥0 得到 t 的不等式；等号时再把 t 代回求变量；
- 已知一个二次型关系求 x²+y² 的最小值：构造「t(x²+y²) = 原关系式」的齐次方程（t 为待求最小值），视作另一变量的一元二次方程，判别式 ≥0 解出 t 的下界；
- 也可以用「原关系式因式分解后设其中一因子为 t」把 x、y 都用 t 表示，再代入所求式直接求最值；
- 求含「两个部分和」的分式最值、已知两个部分各自的线性约束：用待定系数把目标写成两约束的线性组合，再拆成互反式套均值，系数由两约束中变量的配比确定。
**易错点**
- 判别式法得到的下界须验证等号时变量确实满足约束，否则只是下界不一定是最近；
- 待定系数需在等式两边「系数恒等」，并保证拆出的两项都为正，才能用均值。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第261—262页）

### 不等式 · 多元最值的向量法、构造函数法与「1」的妙用（更高更妙 第262—264页）
**核心思路**
- 线性组合除以根式型（如 (x + √3y)/√(x²+y²)）：构造两个向量（一个给定、一个为 (x,y)），式子就是两向量夹角的余弦乘定值，按角度范围读最值；
- 二次型最值（如 xy + 2yz）：把每个乘积写成两个向量分量积，再拆成两对，用待定系数让两对平方和恰好还原给定条件，凑成条件型；
- 二次型与线性式混合（如 4x²+y²+xy 为定值求 2x+y）：构造两向量使目标式恰为它们的内积，用模长之积上界；
- 同构对称式（形如 1/(√ + a − b) 与 y + √(4y²+1)）：把一边取倒数化为与另一边同型，看出是同一函数在两点取值，再由单调性得到关系，剩下的是二元最值；
- 带参数线性式恒在曲线下方的题：构造差函数求最值，得参数关系后再对参数构造二次函数求最大；几何看法是对曲线作切线，切线斜率与截距给出 a、b 的关系；
- 「1」的妙用：所求式分母恰是某两变量组合时，把条件中的 1 分配进各项并同加 1，构造出可以套柯西的分式之和。
**易错点**
- 向量法要检查夹角能否取到给定范围（x、y 有符号或正负限制时角度受限）；
- 同构后得到的关系式是必要条件还是充要条件要清楚：单调函数才能由相等推出自变量相等。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第262—264页）

### 不等式 · 多元最值的数形结合：投影与对称（更高更妙 第264—266页）
**核心思路**
- 两定点所在三角形的某乘积条件 + 求某点距离范围：把两距离之积改成数量积（夹角余弦），再用极化恒等式把数量积与到中点的距离挂钩，由夹角余弦范围读最值；
- 线性约束下的根式最值：把根式看成点到原点距离，另一个变量看成点到坐标轴距离，问题变成「到某点 + 到某条直线」的距离和，作对称点后两点之间直线最短；
- 三变量平方和最小、约束为线性式：把目标看成点到平面距离的平方（球心到平面），或用拉格朗日乘数法、权方和、判别式快速求；
- 表面上是用投影定义给出的向量题，实质是三元线性约束 + 平方和最值，应先化成纯代数题再选方法。
**易错点**
- 对称点法只有在两点连线确实穿过可行区域时才有效，须检查路径与约束一致；
- 极值在平面与球面相切处取得，直接写最小值前要验证切点坐标落在可行域内。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第264—266页）

### 不等式 · 双参数比值的零点比大小（解题方法 第231—238页）
**核心思路**
- 见到「f(x)≥ax+b 恒成立，求 (b+n)/(a+m) 的最值」：先把不等式整理成 f(x)+mx+n ≥ (a+m)x+(b+n)，使左右两边出现同一组系数；
- 两边零点比大小：左边（常为凹/凸函数）的零点用观察法得出，右边零点为 −(b+n)/(a+m)，由两零点位置关系直接得比值范围；
- 赋值法：令 x 取使左边为零的点 x₀，代入原不等式即得 (b+n)/(a+m) 与 x₀ 的大小关系，x₀ 常是零点、切点或极值点；
- 目标若是 ma+nb（线性型），按 a、b 的系数比与 m∶n 相等来赋值（等比例赋值），再代回原式。
**易错点**
- 曲线过定点时不能简单赋值（如过 (0,1) 的曲线族），需改用公切线斜率比较；
- 赋值点必须落在定义域内，落在定义域外的转化工作量极大、不适合考场。
**依据**：`题库/高中数学解题方法.pdf`（OCR 第231—238页）

### 不等式 · 双参数积 ab 的切线找点比较（解题方法 第231—238页）
**核心思路**
- 见到「f(x)≥ax+b 恒成立，求 ab 的最值」：令 f(x₀)=a 解出切点横坐标，由 f(x₀)≥ax₀+b 得 b≤f(x₀)−ax₀；
- 于是 ab≤a[f(x₀)−ax₀]，右边是只含 a 的函数，再求该函数最值即得 ab 的上界；
- 若目标为 a²+b²，把 f(x)=ax+b 视作关于 a、b 的直线 x·a+b−f(x)=0，a²+b² 即原点到该直线的距离平方，用点到直线距离公式化为 x 的函数求最值。
**易错点**
- 用切线找点时须先确认取得最值处确实是相切状态（曲线凹凸性与不等式方向一致）；
- ab 的符号未定时不能直接开方或取倒数，先定号再求最值。
**依据**：`题库/高中数学解题方法.pdf`（OCR 第231—238页）

### 不等式 · 构造平方差换元求二元最值（优质解法 第346—347页）
**核心思路**
- 二次型带 xy 项（如 4x²+y²+xy=1、x²+y²+xy=1、x²+y²−xy=1）：作线性换元，把二次式拆成「和×差」两组，使 xy 项相消；
- 换元后方程变成标准椭圆型 Aa²+Bb²=常数，由 a²、b² 的范围得到 a、b 的范围；
- 目标式（如 2x+y、x+y、x²+y²）写成 a、b 的线性/二次式，用椭圆极值即得范围；
- 多选判断选项：逐个把选项改写成 a、b 的条件比对。
**易错点**
- 换元的系数要与二次项系数匹配（4x² 对应用 2x 分组），OCR 原式含糊，实际系数以题目为准；
- 范围端点能否取到要看换元后的等号条件。
**依据**：`题库/《高考数学•优质解法》（405P）.pdf`（OCR 第346—347页）

### 不等式 · 绝对值不等式七类型（破题36招 第13—19页）
**核心思路**
- 见 |f(x)| 与常数/另一式比较：先按常数 a 的符号去绝对值，a≤0 时可直接判无解或恒成立；
- a<|f(x)|<b 型拆成双向区间分别解再取交集；|f(x)|<g(x) 型要求 g(x)>0，等价于 −g<f<g；
- |f(x)|<|g(x)| 型直接平方去绝对值（两边均非负，平方等价）；
- |f(x)|<f(x) 型必无解（左≤右要求 f≥0 且 f<f 矛盾），|f(x)|>f(x) ⇔ f(x)<0，可快速判型；
- 恒成立求参数用三角不等式 ||a|−|b||≤|a±b|≤|a|+|b| 取极端值；
- 含两个绝对值相加 |f|+|g| 时，尝试写成 |f±g| 或用零点分段去号，分段后逐段解再并集。
**易错点**
- |f|<g 未先要求 g>0，会产出非法解；
- 零点分段后忘回代检验各段解是否落在本段区间内。
**依据**：`题库/高中数学破题36大招(详例精编).pdf`（OCR 第13—19页）

### 不等式 · 均值不等式拼凑八法（拼凑定和 / 拼凑定积 / 拼凑常数降幂 / 升幂 / 「1」代换约分 / 引入参数待定系数 / 对偶式 / 确立主元）（破题36招 第43—49页）
**核心思路**
- 求积的最大值 → 先拼凑出「和为定值」：把积写成能因式分解的结构，或把项移入根号凑成两因式之和为常数；
- 求和的最小值 → 先拼凑出「积为定值」：对分式裂项、分子常数化、或有理化把式子拆成两项使其乘积固定；
- 次数不一致先把高次项用条件降幂（结合已知的常数关系），或用升幂把低次项补齐再求积定；
- 分式求和可以乘上已知条件中的「1」再逐项约分（1 代换）；
- 结构复杂时引入待定参数，令两项相等（取等条件）定出参数后套用均值不等式；
- 对称的两个式子可写成「对偶式」（和与积互换）借助另一式定值；多变量时先确立主元，把其余量视为常数逐个消去。
**易错点**
- 拼凑后必须能验证等号成立（两项相等时变量取值在原范围内）；
- 多项连续使用均值不等式时需保证等号能同时取到。
**依据**：`题库/高中数学破题36大招(详例精编).pdf`（OCR 第43—49页）

### 不等式与代数变形 · 转化思想十项（等与不等 / 正反补集 / 动静互换 / 主次元 / 逆否 / 数形 / 特殊一般 / 抽象具体 / 整体局部 / 对偶）（破题36招 第183—195页）
**核心思路**
- 等与不等互化：等式条件用来消元，不等式条件用来定范围，求最值时把相等情形当作「等号取到」的临界；
- 正面难求时转补集/反面（「至少」「都不是」）；
- 动的问题令变量取特殊值观察（动静互换），再回到一般；
- 条件多时变更主元（谁是变量谁是参数）；
- 命题要证 A⇒B，可证其逆否；
- 函数/不等式有几何背景时转成图形关系（数形）；
- 特殊值先猜结论，再用一般证明；
- 抽象函数令成满足条件的具体函数（如 f(x+a)=(1+f(x))/(1−f(x)) 可类比 tan 型，得周期 4a）；
- 立体或多元问题用整体/局部割补；
- 球的问题降维到截面圆；
- 对称式写对偶式。
**易错点**
- 特殊值猜出的结论不能直接作为答案，须补一般性证明；
- 抽象具体的类比只在结构完全相同时成立。
**依据**：`题库/高中数学破题36大招(详例精编).pdf`（OCR 第183—195页）

### 不等式与代数变形 · 两个等式之后的加减乘除选择（1987解题方法 第157—159页）
**核心思路**
- 由条件导出两个等式后，先看两式的常数项：常数项绝对值相等、符号相反时优先相加，可直接消去常数项并得到不带分母的公共量；
- 两式结构相同、比值只含目标变量时优先相除，可一次降次得到目标关系；相乘通常使次数升高，非必要不用；
- 相减适合消去相同的一次项；相除可能失根，除前要确认分母不为零并找回使分母为零的解；
- 选完运算后立即检查：所得式子是否只含待求量、是否引入了附加条件（如分母不为零）。
**易错点**
- 相减后得到含分母的表达式，再代入时又要讨论分母非零，增加出错点；
- 相除后未检查分母为零的情形，失根。
**依据**：`题库/高中数学解题方法与技巧_《中学生学习报》编辑部编1987.pdf`（OCR 第157—159页）

### 不等式与代数变形 · 构造对偶式与「无意义改写」用均值（1987解题方法 第160—162页）
**核心思路**
- 证连乘不等式时，构造一个结构相同、分子分母互换的对偶式 B，使 A·B 的每一项都约成 1，从而由 A²<A·B 给出上界；
- 求 x²(2a−x) 型最值：把 x² 改写为 4·(x/2)·(x/2)，使三个因子之和为常数，再用三元均值；
- 证明不等式时经常构造「看似无意义」的恒等改写：0=a−a、1=a·(1/a)、x=x/2+x/2，目的都是凑出定和或定积；
- 改写的方向由「基本不等式需要什么」倒推：需要定和就把变量拆成和，需要定积就把常数拆成积。
**易错点**
- 对偶式构造后 A·B 不能完全约简，得不到 A² 的界；
- 拆分后各因子不为正，不能使用均值不等式。
**依据**：`题库/高中数学解题方法与技巧_《中学生学习报》编辑部编1987.pdf`（OCR 第160—162页）

### 不等式与代数变形 · 根式函数值域：代数换元与三角换元的分工（1987解题方法 第171—176页）
**核心思路**
- 形如 y=ax+√(bx+c)（根号内是一次式）：设 t=√(bx+c)，反解 x 为 t 的二次式，函数化为 t 的二次函数，再由 t≥0 求值域；
- 形如 y=x+√(a²−x²)（同时含 x 与 x²）：代数换元无法有理化，改用 x=a sinθ，注意 θ 的范围要与 x 的定义域一致；
- 三角换元后化为 A sinθ+B cosθ 型，用辅助角合并，再按 θ 的实际范围（不是默认的全体）取最值；
- 判别式法对此类函数不可靠：平方会放宽范围、判别式只保证 x 为实数而不保证落在根号定义域内，只能作参考。
**易错点**
- 三角换元后按 θ∈R 取最值，忘记 θ 由 x∈[−a,a] 限定；
- 用判别式法求根式函数值域，得到比真实值域更宽的结果。
**依据**：`题库/高中数学解题方法与技巧_《中学生学习报》编辑部编1987.pdf`（OCR 第171—176页）
