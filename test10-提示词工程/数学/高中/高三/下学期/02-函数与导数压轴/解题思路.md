## 二、函数与导数压轴

### 4. 构造函数解不等式（大招 2—3）

**核心思路**
| 条件结构 | 构造 |
| --- | --- |
| $f(x)+f'(x)>0$ | $[e^x f(x)]'>0$ |
| $f(x)-f'(x)<0$ | $\left[\frac{f(x)}{e^x}\right]'>0$ |
| $xf'(x)-f(x)<0$ | $\left[\frac{f(x)}{x}\right]'<0$ |
| $xf'(x)+f(x)>0$ | $[xf(x)]'>0$ |

**易错点**：不等号方向与构造函数符号的对应；定义域（$x>0$ 等）。

### 5. 同构（大招 6）

**核心思路**：把不等式/方程两边化为同一函数形式 $f(g(x))\ge f(h(x))$，再利用 $f$ 的单调性去掉外层；辅助手段：指对变换、常见放缩。原文「同构三重境界」：直接同构 → 变形同构 → 放缩后同构。

### 6. 指对处理口诀（大招 7）

**核心思路**：「对数单身狗，指数找朋友」——含 $\ln x$ 时常把对数单独放一边；含 $e^x$ 时常把指数与多项式合并，便于求导。

### 7. 导数放缩（大招 4）

**常用不等式**
- $e^x\ge x+1$（$x=0$ 取等）
- $e^x\ge ex$（$x=1$ 取等）
- $\ln x\le x-1$（$x=1$ 取等）
- $\ln x\le\frac{x}{e}$（$x=e$ 取等）
- $\sin x<x<\tan x$（$x\in(0,\frac\pi2)$）

**易错点**：取等条件不满足仍使用；放缩方向与题目所需相反。

### 8. 极值点偏移三法（大招 11—13）

**核心思路**
1. 对称化构造：证 $f(x_0+x)>f(x_0-x)$，结合单调性推 $x_1+x_2$ 与 $2x_0$ 的关系；
2. 比值/差值换元：令 $t=\frac{x_2}{x_1}$ 或 $t=x_2-x_1$，化为单变量；
3. 对数平均不等式：利用 $\frac{x_2-x_1}{\ln x_2-\ln x_1}>\sqrt{x_1x_2}$ 等。

**易错点**：未证对称函数单调；换元后范围。

### 9. 隐零点、端点效应、极点效应（大招 8—9）

**核心思路**
- 隐零点：$f'(x_0)=0$ 根不可显式表达时，设 $x_0$ 并代回原函数化简；
- 端点效应：把端点代入不等式求参数必要范围；
- 极点效应：在极值点处取得等号时，用「取等处导数也为 0」确定参数。

**易错点**：只求必要条件；隐零点存在性未说明。

### 10. 切线夹、割线夹、主元法、洛必达（大招 14—18）

- 切线夹：用切线给出单侧界；割线夹：用割线给出另一侧界，两者结合证明；
- 主元法：把参数当作主元，把 $x$ 当参数；
- 洛必达：处理端点处的 $\frac00$ 极限（需说明使用依据）；
- 导数与三角函数：三角放缩 + 有界性 + 周期性。

### 导数 · 极值点偏移的对称函数法（浙大优辅19 第4讲）
**核心思路**
- 遇到 f(x1)=f(x2)（x1≠x2）要证 x1+x2>或<2x0（x0 为极值点）：构造对称函数 g(x)=f(x)−f(2x0−x)；
- 判断 g(x) 在 x0 左右两侧的符号（或在 (x0,∞) 上单调），由 f(x1)=f(x2) 得 x1 与 2x0−x2 的大小关系；
- 若证 x1x2 大小，构造 g(x)=f(x)−f(c/x) 型（用商的对称）。
**易错点**
- 对称函数要在极值点处对称，极值点坐标须先求出；
- 需先证 f 的单调性（在极值点两侧单调），否则无法从函数值大小得自变量大小。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第37—48页）

### 导数 · 极值点偏移的比值代换（浙大优辅19 第4讲）
**核心思路**
- 令 x2/x1=t（t>1）：由 f(x1)=f(x2) 得关于 x1、t 的关系，解出 x1 用 t 表示（或两边同除）；
- 待证不等式化为关于 t 的不等式，构造函数 h(t) 在 (1,∞) 上最值；
- 若待证式含 x1+x2，先写成 x1(1+t) 形式再代换。
**易错点**
- 代换后需保证 t>1 且所有式子在 t 定义域内；
- 解 x1 时若方程复杂，可用同构式把 x1 表达为 t 的函数。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第37—48页）

### 导数 · 极值点偏移的齐次化（浙大优辅19 第4讲）
**核心思路**
- 由 f(x1)=f(x2) 得两式，作差或比值，通过「加项减项」把式子整理为只含 x1/x2 的齐次式；
- 令 t=x1/x2，把目标不等式用 t 表达，再构造函数求最值；
- 齐次化的关键在于把 e^{x1}、e^{x2}、ln x1、ln x2 分别配成 t 的幂或对数。
**易错点**
- 齐次化要保证两式指数同层（如两边都同除 e^{x2} 或 x2），否则结构不齐；
- 齐次化的结果要与待证不等式的齐次度一致。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第37—48页）

### 导数 · 对数平均不等式（浙大优辅19 第4讲）
**核心思路**
- 涉及两个正数 a、b 的不等式且含 (a−b)/(ln a−ln b) 结构：用对数平均不等式 √ab < (a−b)/(ln a−ln b) < (a+b)/2；
- 极值点偏移中 ln x1−ln x2 出现时，把其换成 b−a 的倍数，把待证式化为 a、b 的代数不等式；
- 若待证式为 x1+x2>…型，先用对数平均不等式得 a−b 与 (a+b)/2 的关系，再与其他条件结合。
**易错点**
- 对数平均不等式要求 a、b>0 且 a≠b；
- 不等号两侧方向（√ab 与 (a+b)/2）不能写反。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第37—48页）

### 导数 · 不等式恒成立的三条路径（浙大优辅19 第5讲）
**核心思路**
- 直接求最值：f(x)≥g(x) 恒成立 ⇔ [f−g]' 求极值与端点最小值 ≥0；
- 分离参数：参数 a 可分离时化为 a≥h(x)（或 ≤），求 h 的最值；
- 必要性探路：选一个方便的特殊 x0 代入得参数必要条件，再证该条件充分（常用于含 e^x 的复杂式）。
**易错点**
- 必要性探路后必须补充分性证明；
- 分离参数时除以的式子符号须固定或分奇偶/区间讨论。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第49—59页）

### 导数 · 同构的三种积型构造（浙大优辅19 第5讲）
**核心思路**
- 积型一：x·e^x 与 (ln x)·x 等结构——遇到 a·e^a 与 b·ln b 比较时，把 b·ln b 写成 (ln b)·e^{ln b}，化为同一函数 f(t)=t·e^t 在 a 与 ln b 处的值；
- 积型二：x/ln x 与 e^x/x——两边同除或同乘，配成同形；
- 积型三：含 x·ln x 与 x·e^x 的混合：先用对数恒等式 x=e^{ln x} 统一指数形式；
- 判同构：两边函数结构完全相同后，用单调性比较两个自变量。
**易错点**
- 换元时要保证换元变量（如 ln b）在函数定义域内；
- 同构只在函数单调时才能由函数值大小推自变量大小。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第49—59页）

### 导数 · 同构的商型构造（浙大优辅19 第5讲）
**核心思路**
- 看到 a/e^a、b/e^b 或 ln a/a、ln b/b 型：两边同除以共同的结构（如都除以 e^x 或 x），得到 f(t)=t/e^t 或 f(t)=ln t/t 同构；
- 若待证式含 (e^{x1}−e^{x2})/(x1−x2)，先化为 e 的幂的差与自变量差的比，同构到 g(t)=e^t/t 或 (e^t−1)/t；
- 商型同构后仍需判断同构函数的单调区间（在两侧单调）。
**易错点**
- 商型同构后两自变量可能分处不同单调区间，不能直接比较；
- 除以的式子需恒正。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第49—59页）

### 导数 · 隔离切线放缩（浙大优辅19 第5讲）
**核心思路**
- 用切线为曲线找到一条「隔离线」：在 x0 处切线 y=f(x0)+f'(x0)(x−x0) 位于曲线一侧（下凸曲线切线在下）；
- 常见：e^x≥x+1（在 x=0 处切线），可由此换元得到其他指数组合的切线界，再用于证明；
- 不等式恒成立的证明：把待证式化为一边为切线、一边为函数差，用切线界放缩。
**易错点**
- 切线的上下位置取决于凹凸性，选错方向不等式反向；
- 切线放缩只在切点附近最紧，远离切点误差大，必要时分段。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第49—59页）

### 导数 · 洛必达法则处理端点极限（浙大优辅19 第5讲）
**核心思路**
- 恒成立问题中遇到 x→x0 时 0/0 或 ∞/∞ 型极限（如 x→0 时 x/e^x−1、ln x/(x−1)）：用洛必达法则求极限；
- 求出端点极限值后判断参数边界（参数临界值由极限与条件比较给出）；
- 洛必达只用于求极限辅助判定，最终结论仍要回到不等式证明。
**易错点**
- 洛必达的前提是分子分母同为 0 或同为 ∞ 的未定式，直接套会错；
- 求导后若仍为未定式可再次洛必达，但不能无限套。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第49—59页）

### 导数 · 零点个数问题的「相切临界」判断（浙大优辅19 第3讲）
**核心思路**
- 参数变化时零点个数改变，临界发生在两曲线相切处：令两函数在某点值与导数同时相等；
- 解出切点与参数临界值，临界两侧零点个数不同（如 0、1、2 个）；
- 结合单调性写各参数区间对应的零点个数。
**易错点**
- 相切只是临界的一个来源，另一个是端点值符号变化，需一并讨论；
- 相切临界处零点个数为 1（重根）还是 0，取决于相切曲线与横轴的位置。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第26—36页）

### 导数 · 隐零点与双变量问题的结合（浙大优辅19 第3—4讲）
**核心思路**
- 双变量 f(x1)=f(x2) 且 f'(x) 的零点不可解时：先用隐零点法确定极值点 x0 的范围；
- 由 x0 的范围给出 f(x0) 的界（单调性 + 零点代换），进而约束 x1+x2 或 x1x2 的范围；
- 证明过程中同时使用 f'(x0)=0 的代换与 x0 的区间估计：代换消去超越项，区间估计给出不等式方向。
**易错点**
- 两边都只在估计范围内，不等号方向要随单调性判断；
- 极点偏移与隐零点同时出现时，先确定 x0 的范围再作对称函数。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破19-导数的应用.pdf`（OCR 第26—48页）

### 函数与导数 · 指对同构（核心方法 第79—82页）
**核心思路**
- 方程/不等式两边同时含指数与对数，或两个等式结构相似时：用 x = e^{ln x} = ln(eˣ)（x>0）把一边的指数式写成对数式（或相反），整理成“结构完全相同”的两式，再构造同一个函数用单调性；
- 对数同构：把 a·e^{a−c} 中的 a 写成 e^{ln a}，两项合并为 e^{ln a+a−c}，使左右两侧都成为“ln t+t=常数”的方程，构造 f(t)=ln t+t；
- 指数同构：把一侧的对数式写成 e^{ln t}，与相邻的 e^t 合并成“t·eᵗ = 常数”，另一侧也整理成同一形式，构造 f(t)=t·eᵗ；
- 不等式恒成立：把 lna 与 a 的项凑成 e^{lna+x−1}+(lna+x−1) 的形式，另一侧凑成 lnx+lnx 型，再用 eᵗ+t 的单调性脱去函数，分离参数；
**易错点**
- 构造的函数必须单调（先验证导数恒正或恒负），且两侧自变量都落在该函数的定义域内；
- 同构公式常结合换元使用，变形要逐项凑成同一结构，不能只凑一边。
**依据**：`题库/2027版 数学核心方法 高一 高二 高三/高三数学核心方法_351.pdf`（OCR 第79—82页）

### 函数与导数 · 泰勒展开式（核心方法 第83—88页）
**核心思路**
- 比较大小、证明不等式、探求参数临界值（如极值点问题）：把 eˣ、sinx、cosx、ln(1+x)、(1+x)^α 在 0 处展开为幂级数，保留到需要的那一项，比较一次项/低次项系数即得临界值，再严格证明；
- 常用不等式（x≥0 时）：eˣ ≥ 1+x+x²/2 类下界；sinx ≤ x 且 sinx ≥ x−x³/3!；1−x²/2 ≤ cosx ≤ 1；ln(1+x) 介于 x−x²/2 与 x 之间；α≤0 或 α≥1 时 (1+x)^α ≥ 1+αx，0<α<1 时相反；
- “极值点判定”：求 f 在 x₀ 处第一个不为零的导数值 f⁽ⁿ⁾(x₀)，n 为奇数则不是极值点；n 为偶数且 f⁽ⁿ⁾>0 极小，<0 极大，据此反过来定参数；
- 展开式与不等式方向匹配：比较式（如 √(1+x)、ln(1+x)）中若多项式的系数与展开式不符，则该不等式不成立。
**易错点**
- 泰勒展开只是近似（带余项），不能直接拿展开式当证明，临界值需再用导数严格证明；
- 用“第一个非零导数阶数”判极值时，必须限定在原点附近的区间内讨论，且逐阶保证上一阶导的单调性。
**依据**：`题库/2027版 数学核心方法 高一 高二 高三/高三数学核心方法_351.pdf`（OCR 第83—88页）

### 函数与导数 · 极值点偏移（核心方法 第57—62页）
**核心思路**
- 单极值函数左右增减速度不同、两零点（等函数值点）的中点不等于极值点时：先判断是左偏还是右偏（看二阶导/导函数单调性），把双变量不等式化为单变量函数问题；
- 证“和型”不等式（x₁+x₂ > 2x₀ 或 < 2x₀）：构造差函数 F(x)=f(x)−f(2x₀−x)，在对应区间证其单调，比较 F(x) 与 F(x₀)=0 的符号，再用 f 的单调性把函数值大小化成自变量大小；
- 证“积型”不等式（x₁x₂ > 常数 或 < 常数）：构造 F(x)=f(x)−f(c/x) 一类对称函数（或对数化后按和型处理），在 (0,x₀] 上证单调；
- 题给条件是对数式交叉相乘的对称等式（两变量分别处在对数内、外）：先两边同除以两变量之积，整理成“m(1−lnm)=n(1−lnn)”型，化成某函数两等值点的问题，再用对称化构造；证上界可另构造 h(x)=f(x)+x 证单调。
**易错点**

### 导数 · 模型148 三角与导数交汇（A049 第372—376页）
**核心思路**
- 三角函数的周期、对称、有界使求导后仍含三角、零点不可显式解出，常用三条路径：
- 分段分析法：以三角函数取 0 或 ±1 的点为端点把区间分段，每段内判导数符号与端点值，逐段确认零点或单调性；
- 放缩法：先证三角与多项式的比较式（如 x−x²<sinx<x），再把含三角项放缩为多项式，转化为纯多项式函数研究；
- 有界性放缩：sin/cos 与一次项相加时，用 −1≤sin≤1 直接定导数符号（如 f′(x)=a+sinx 的符号由 a 与 ±1 的大小决定）；
- 双逻辑连接词（“存在 φ，使对任意 x 都有…≤b”）：先固定 φ，对 x 求最大值 h(φ)，再对 φ 求最小值，即“先内层最值、再外层最值”；
- 存在性证明（证存在 y∈[a−θ,a+θ] 使 cosy≤cosθ）：只需找到一例，取 y=θ 或 y=a−θ，由余弦在相应区间的单调性说明即可，不必求导。
**易错点**
- 分段端点必须选在三角函数取 0 或 ±1 的点上，否则该段内导数符号不统一；
- 换元（如令 cos²x=t）后 t 与 x 的单调方向可能相反，x 区间与 t 区间要对应转换；
- 双逻辑词题要分清内层“任意 x”求最大、外层“存在 φ”求最小，顺序反了就错。

### 函数与导数 · 切比雪夫最佳逼近的三偏差点判据（更高更妙 第272—273页）

- 只有区间上二阶导数不变号（曲线整体凹或凸）才有「两端点 + 一个内切点」的三点形式，否则偏差点个数与位置要重新判断；

### 函数与导数 · f′ 递减时切线恒在曲线上方（更高更妙 第317—318页）

### 导数 · 中间点效应补端点效应的漏网参数（解题觉醒 第54—55页）
**核心思路**
- 端点效应：区间 [1,+∞) 上 h(1)=0 且 h(x)≥0 恒成立，则必要条件 h′(1)≥0，由此得参数的一个上界。
- 端点效应只给必要条件；当参数继续增大、端点条件仍成立时，需在区间内部取"中间点"代入构造矛盾。
- 具体做法：写出 h′(x) 的分子（如二次式），由判别式与两根位置 x₁<1<x₂ 说明 h′ 在 (1,x₂) 上为负，h 递减到 h(x₂)<h(1)=0，与 h≥0 矛盾。
- 于是把端点条件给出的范围再切掉一段，得到精确范围；讨论要按参数分段（如 α≤某值、α>某值）完整覆盖。
**易错点**
- 把端点效应得到的必要条件当成充要条件，直接写答案。
- 中间点效应否定某段参数时，必须写出"与 h(x)≥0 矛盾"的完整推理，不能只算一个负值就下结论。
- 分段讨论容易漏掉端点外侧的区间（如 α 大于第二个根对应的值那一段）。
