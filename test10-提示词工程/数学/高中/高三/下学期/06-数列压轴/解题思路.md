## 四、概率与数列压轴

### 22. 数列速算（大招 1—13）

**核心思路**
- 等差：$S_n=na_{\text{中}}$；
- 片段和：$S_n,S_{2n}-S_n,S_{3n}-S_{2n}$ 成等差/等比；
- 和比/项比公式直接求；
- 错位相减速算公式（适合等差×等比）；
- 裂项：待定系数法确定拆分系数。

**易错点**：公式适用条件（等比 $q\ne1$）；裂项系数。

### 23. 通项构造（题型16：11 类）

**核心思路**：把递推式化成可求和 / 可求积的标准形。

| 递推形式 | 做法 |
| --- | --- |
| $a_{n+1}=a_n+f(n)$ | 累加：$a_n=a_1+\sum_{k=1}^{n-1}f(k)$ |
| $a_{n+1}=a_n\cdot f(n)$ | 累乘（注意 $a_n\ne0$） |
| $a_{n+1}=pa_n+q$（$p\ne1$） | 配成 $a_{n+1}+t=p(a_n+t)$，$t=\dfrac{q}{p-1}$ |
| $a_{n+1}=pa_n+q^n$ | 两边同除 $q^{n+1}$，化为一阶线性 |
| $a_{n+1}=\dfrac{pa_n}{ca_n+d}$ | 取倒数，化为 $1/a_n$ 的一阶线性 |
| $S_n$ 与 $a_n$ 混用 | 用 $a_n=S_n-S_{n-1}$（$n\ge2$），再验证 $n=1$ |
| 已知 $a_n$ 为前 $n$ 项和形式 | 先求 $S_n$ 再作差 |

**易错点**：作差后必须单独验证 $n=1$；除数为 0 或 $a_n=0$ 的情形要先排除。

### 24. 求和的五种套路（题型17）

**核心思路**

- **分组求和**：把通项拆成等差部分 + 等比部分分别求和；
- **裂项相消**：$\dfrac{1}{n(n+k)}=\dfrac1k\left(\dfrac1n-\dfrac1{n+k}\right)$，$\dfrac{1}{\sqrt n+\sqrt{n+1}}=\sqrt{n+1}-\sqrt n$；系数用待定系数法定；
- **错位相减**：$c_n=(an+b)q^n$ 型，两边乘 $q$ 后作差；也可直接用万能公式（大招速算）；
- **奇偶并项**：含 $(-1)^n$ 的项两两合并，分别讨论 $n$ 的奇偶；
- **周期 / 类周期**：先由递推式看出周期，再按余数归类。

**易错点**：裂项后剩余项随 $n$ 的奇偶而变；错位相减后第一项与末项要单独处理。

### 25. 数列不等式与放缩（题型18）

**核心思路**

- **证明 $S_n<k$**：先放缩通项成可裂项形式，如 $\dfrac{1}{n^2}<\dfrac{1}{n(n-1)}$，$\dfrac{1}{2^n-1}<\dfrac{1}{2^{n-1}}$；
- **证明 $a_n$ 与 $b_n$ 大小**：作差 / 作商后判断符号，或数学归纳法；
- **求参数范围**：把不等式转成“恒成立”，转化为求最大 / 最小值（分离参数）；
- **与三角、对数综合**：先求出 $a_n$ 表达式再代入。

**易错点**：放缩方向要与结论一致（放大证明上界、缩小证明下界）；从第几项开始放缩要交代清楚。

### 26. 等比 / 等差判定与“新定义”数列

**核心思路**

- 判定等差：证 $a_{n+1}-a_n$ 为常数，或证 $2a_{n+1}=a_n+a_{n+2}$；
- 判定等比：证 $\dfrac{a_{n+1}}{a_n}$ 为常数（$a_n\ne0$），或证 $a_{n+1}^2=a_na_{n+2}$；
- 新定义（“$k$ 阶等差”“数列的分拆”等）：先按定义写出前几项找规律，再证明一般性。

**易错点**：等比数列首项不能为 0；判定时要说明对一切 $n$ 成立。

### 数列 · n²q^n 型求和的两次错位（浙大优辅17 第4讲）
**核心思路**
- 通项为 n²q^n（或二次式乘等比）：第一次错位相减得含 n·q^n 的新式，第二次错位相减得纯等比，最后化成通式；
- 若不便两次错位，改用逐项求导：对 Σx^k 求和后再求导，代 x=q 得 Σkx^{k−1}，再求导二次得 Σk²…；
- 检查结果可代 n=1 小数值验证。
**易错点**
- 第二次错位的末项指数比第一次再高一阶，容易写错；
- 导数法需在 q≠1 下使用，q=1 直接平方求和。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破17-数列求和.pdf`（OCR 第34—41页）

### 数列 · 求和放缩保留前几项提高精度（浙大优辅17 第7讲）
**核心思路**
- 题要求「和 < 某精确常数」且单用放大式精度不足：前几项精确计算（不放缩），从第 m+1 项起重项放大，求和后合并；
- 保留项数 m 由放缩误差决定：若放大式整体求和后与目标只差 ε，就保留使 Σ_{前m} 的差抵消 ε 的项数；
- 也可用糖水不等式型：a/b<(a+c)/(b+c)（大分数加同数后比值变大）对通项作精细放大。
**易错点**
- 保留前几项后剩余部分的起始下标要随之调整，不能仍从 n=1 起算；
- 放缩方向若为缩小（证和 > 常数），保留前几项反而更难，需换放缩式。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破17-数列求和.pdf`（OCR 第60—69页）

### 数列 · 求和放缩的执果索因（浙大优辅17 第7讲）
**核心思路**
- 看到「求证 Σ<某个给定常数」但不知用哪种放缩：先设放大常数 c，令等比和或裂项和等于目标，反推放大式的公比或裂项系数；
- 从目标常数反推出的放缩式为「恰好不等号严格成立」的临界形式，再向简单侧微调；
- 若目标含 n 的项（如 <3−1/n），把右端写成与 n 相关的形式，使放缩后的和恰为右端。
**易错点**
- 目标常数是精确值（等于放缩和）时不等号不严，需再放小一点；
- 反推的放缩式要验证对每一项成立，不能只在最后一项成立。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破17-数列求和.pdf`（OCR 第60—69页）

### 数列 · 类等比与类等差放缩的比较取舍（浙大优辅17 第7讲）
**核心思路**
- 通项为多项式倒数（如 1/(n²+n)）：可放大为 1/[n(n+1)] 裂项型，也可放大为 (1/某数)·等比型；选哪种看目标常数，能直接求和到目标即可；
- 通项为 n/2^n 型：放大到等比结构（把 n 换成等比系数倍）；
- 比较两者精度：类等差/裂项型放缩误差小但结构要求严格，类等比误差大；若目标常数较宽选易求和的类等比。
**易错点**
- 类等差放缩在分母为 n(n−1) 时 n=1 项不成立，须从 n=2 起；
- 放缩后每项必须比原项大（或小），方向判错会导致结论反。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破17-数列求和.pdf`（OCR 第60—69页）

### 数列 · 差比型放缩与逐项相消（浙大优辅17 第7讲）
**核心思路**
- 若能把通项放大成「a_n−a_{n+1}」形（两项之差为另一可求和的数列），则求和时逐项相消只剩 a_1−a_{n+1}；
- 构造方法：先观察通项结构，寻找其与原式的差；如 1/√n < 2(√n−√(n−1)) 型根式差；
- 若原式为「相邻两项倒数的差」可直接裂项，不用另外构造。
**易错点**
- 放大后的差式方向必须是「a_n−a_{n+1}>0」项逐项相消后剩 a_1−a_{n+1}，符号写反结果会变成负数；
- n=1 项需单独处理（差式在 n=1 可能无定义）。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破17-数列求和.pdf`（OCR 第60—69页）

### 数列 · 裂项放缩法（核心方法 第134—136页）
**核心思路**
- 当求和式无法精确求出、只能证不等式（无限和或部分和的估计）时用裂项放缩：把通项放缩成可裂项相消的形式，求和得到简洁估计；
- 先定放缩方向：证上界就把通项放大，证下界就缩小，方向与结论一致；
- 常见放缩方向：含 $n^2$ 的通项可走「$1/[n(n-1)]$」「$1/[(n-1)(n+1)]$」「$1/[(2n-1)(2n+1)]$」几条拆分路线；含 $1/\sqrt{n(n+1)}$ 的通项可缩为两根式之差；
- 放缩后若首项不适配（如 $n=1$ 时分母出现 0 或不等号反向），就「保留前若干项不放缩」，从第 2 项或第 3 项起再放缩，单独验证头几项；
- 放缩尺度要恰当：既要保证裂项后能相消，又要剩余项（首尾项）便于计算。
**易错点**
- 放缩方向与要证结论相反是最常见错误；
- 忽略「保留头几项」，导致第 1 项无意义或不等式在 $n=1$ 处不成立。
**依据**：`题库/2027版 数学核心方法 高一 高二 高三/高三数学核心方法_351.pdf`（OCR 第134—136页）

### 数列 · 构造函数判定递推数列的单调与范围（更高更妙 第254—256页）
**核心思路**
- 递推式形如 x_n = x_{n+1} + ln(1+x_{n+1})：构造 f(x) = ln(1+x) − x，证其 ≤0，再代入递推式得 x_{n+1} 与 x_n 的大小关系与正负；
- 证 x_n > 0 用反证法：假设某项 ≤0，逐项向后递推得到 x_1 ≤0 与已知矛盾；
- 证「2x_{n+1}x_n ≤ 某式」：把目标式用递推式替换成只含 x_{n+1} 的表达式，再构造新函数用单调性证明它非负；
- 要放大得到 x_n ≥ 1/(2n−1) 型下界：先用 f(x) ≤ f(0) 得 x_{n+1} ≥ x_n − x_{n+1}，再由相邻项关系逐次递推；
- 求和不等式 S_n < 2 + 2ln n：先用放缩把和式化成含调和和的形式，再构造 g(x) = ln(1+x) − x/(1+x) 证明调和项 < ln 项，最后逐项相加。
**易错点**
- 用反证法必须有清晰的递推链条，不能只验证一项；
- 构造 g 时要注意 x 的定义区间（如 x > 0 或 n ≥ 2），在端点处的取值要单独处理。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第254—256页）

### 数列 · 凸数列（二阶差 ≥0）的两端点界与和式控制（更高更妙 第333—336页）
**核心思路**
- 见到「a_{k+1}+a_{k−1} ≥ 2a_k」，先写成一阶差 d_k=a_{k+1}−a_k 单调不减；于是对 m<n 有 a_n−a_m ≥ (n−m)(a_{m+1}−a_m)，即「后面的每一段增量都不小于第一段」；
- 把 a_n−a_m 改写成「首项、末项、中间项」的组合（如 (k−1)(a_{n₀}−a₁) ≥ (n₀−1)(a_k−a₁)），再用条件 Σa_k=1 或 Σa_k<1 把各项加起来夹出界；
- 要证 a_n 落在 [a₁−某式, 某式] 时：一端由「所有增量 ≤ 首段增量」累加，另一端由「所有增量 ≥ 首段增量」累加后再用总和条件；
- 这类题常以「凸数列」为背景，条件给的是不等式而非等式，不能求通项，只能估界；
**易错点**
- 二阶差条件不保证 a_n 单调，凡用到「差≥0」处都要单独说明；
- 累加时不等式个数（m 个、n−1 个）与系数要核对，系数算错是主要失分点；
- 严格不等号与「≥」在取等、极限处结论不同，题目给「>」时不能取等。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第333—336页）

### 数列 · 递推不等式型：反证 + 递推式自身单调定下界（更高更妙 第334—335页）
**核心思路**
- 递推式以不等式给出（无法求通项）而要证 a_n ≥ 常数时，先假设存在 k 使 a_k < 该常数，用递推式推出「此后所有项都 < 该常数」，再与已知条件（和、最小项、极限）矛盾；
- 若从递推式能整理出 a_{n+1} ≤ a_n（差为 −(a_n−1)²/a_n 一类非正），则在假设下 a_n 递减且保持 <常数，矛盾更直接；
- 若递推式可先取倒数化成 1/(a_{n+1}−1) = 1/(a_n−1)+1 型等差，先解出通项的一端，另一端再用反证补；
**易错点**
- 反证要假设「存在某一项」，不能假设「所有项」，否则推不出递推链；
- 取倒数前必须确认 a_n>0 且分母不为 0，不等号方向随之改变；
- 递推不等式链中每一步的不等号方向要一致，反向传递会得出错误矛盾。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第334—335页）

### 数列 · 点列问题三步：几何条件抽象递推再放缩（更高更妙 第336—342页）
**核心思路**
- 点列题固定三步：由几何条件（最短距离、切线平行、相切）建立 x_n 的递推式；由递推求通项或证等差/等比；最后求和、证不等式或求极限；
- 「点到曲线上点的距离最短」⇒ 距离函数在最近点导数为 0，或曲线在该点的切线与连线垂直（斜率积为 −1）；「切线与两点连线平行」⇒ 切线斜率等于两点连线斜率；
- 例如 y=x^k 上由 P_{n−1}(a_{n−1},0) 作切线得 a_n/a_{n−1}=k/(k−1) 等比；y=x³+x² 上切线平行于原点连线得 x_n²+x_n=3x_{n+1}²+2x_{n+1}，再令 y_n=x_n²+x_n 作等比；
- 证通项介于两个等比之间：把递推式一侧放大成 4x²+2x 型完全平方得下界，另一侧缩小得以 y_n 为公比的等比得上界，两边分别累乘；
**易错点**
- 由几何条件转递推时要同时用「切点在曲线上」和「斜率关系」两条信息，只用一条会漏解；
- 递推中系数（2x_{n+1} 与 x_{n+1}）容易抄错，换元前先把式子整理成同一变量；
- n=1 的通项要单独验证，累乘、累加的下标上限别多算一项。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第336—342页）

### 数列 · 调和平均数定义的新定义数列（更高更妙 第415—416页）
**核心思路**
- 新定义「每一项等于前后两项的调和平均数」：由 2/b_n = 1/b_{n−1}+1/b_{n+1} 知 {1/b_n} 成等差数列，先研究倒数数列；
- 若还要求新数列各项都取自已知递增等差集合（如正整数列）且不是常数列，就检验该集合中元素的倒数能否构成非平凡等差数列——通常只能全相等，从而判定不存在；
- 新定义数列通法四步：读懂定义 → 取 n=1,2,3 试算 → 在特殊情形找规律及与原等差/等比的关系 → 化归到熟悉模型；
- 「恰有 k 项落在某区间」型：列出首项、公差的两个边界不等式（第 k 项在内、第 k+1 项在外，首项前一项在外）；
**易错点**
- 调和平均数的位置是「中间项」，公式方向写反会把数列倒过来；
- 存在性题必须同时满足全部约束（非常数列、每项在原集合、递推关系），只验证其中一条不算；
- 试算只能用于发现规律，最终结论仍需由定义证明。
**依据**：`题库/43、更高更妙的高中数学思想与方法第16版.pdf`（OCR 第415—416页）

### 数列 · 三项递推的可因子化构造（培优讲义 第317—320页）
**核心思路**
- 形如 a(n+2)+p·a(n+1)+q·a(n)=0 的三项递推，找常数 k、h 使 a(n+2)−k·a(n+1)=h(a(n+1)−k·a(n))，条件为 h+k=−p、−hk=q；
- k、h 是一元二次方程的两个根，取实根（可相等）后即得等比数列，再解出通项；
- 当 k=h 时得到等差型（a(n+1)−k a(n) 为常数），再用错位或拆项求通项。
**易错点**
- 特征方程写错符号（应为 k²+pk+q=0 形式，检验方式是把构造式展开与原式对照）；
- 求出等比后求 a(n) 时忘记 n=1 的初始条件。
**依据**：`题库/2026重难点培优讲义/2026重难点培优讲义教师版.pdf`（OCR 第317—320页）

### 数列 · 前 n 项积与乘积型递推（培优讲义 第325—326页）
**核心思路**
- 题设给出 a1·a2·…·an = f(n)，仿照 S 与 a 的关系：a(n)=f(n)/f(n−1)（n≥2），a1=f(1)；
- 求前 n 项积 T(n) 时通项能写成比例式，直接连乘约分；
- 若递推式为 a(n+1)/a(n)=g(n) 型，即累乘法，取对数可化为累加。
**易错点**
- n=1 时没有单独用 a1=f(1) 验证；
- 约分后分母为 0 的情形未排除。

### 数列 · 公共项问题：列举观察加方程取整（培优讲义 第330—333页）
**核心思路**
- 两个数列的公共项：先按顺序列举前几项找出公共项构成的子数列，观察其公差（常为重排后的等差或等比）与首项；
- 若列举不易看出，就设公共项在第一个数列中的序号为 k、在第二个中为 m，联立两个通项相等，解出 k 与 m 的整数对应，得到公共项序号序列；
- 求第 n 个公共项或公共项个数：前者用序号序列的通项，后者解不等式并取整。
**易错点**
- 列举时只比较前两项就推公差，未验证第三项；
- 方程解出的序号必须是正整数且两数列下标均需满足。
**依据**：`题库/2026重难点培优讲义/2026重难点培优讲义教师版.pdf`（OCR 第330—333页）

### 数列 · 分段递推的逆向枚举（培优讲义 第337—339页）
**核心思路**
- 递推分段（奇偶不同规则，形如冰雹猜想）：先按规则把项写成两段；
- 正向求值用奇偶分组，逆向求某值的前一项时，按每段规则分别反解，得到两个可能的前驱，再继续逆推直到下标 1；
- 题目若问「是否可能」，逆推时每一步都要检查前驱是否为整数与下标范围。
**易错点**
- 逆推时漏掉某一支，导致「不可能」结论错误；
- 分段规则下正推与逆推的序号奇偶对应错位。
**依据**：`题库/2026重难点培优讲义/2026重难点培优讲义教师版.pdf`（OCR 第337—339页）

### 数列 · 隔项递推的分奇偶求通项与 S(2n)（培优讲义 第345—347页）
**核心思路**
- 奇偶项规则不同（隔项型 a(n+2)=a(n)+f(n)）：把偶数项、奇数项分别视为新数列，各自用累加或构造求通项，再按奇偶回写；
- 求 S(2n) 时按 (a1+a2)+(a3+a4)+… 两两分组，每组用同一公式求和，再套等差数列或裂项；
- 求 S(n) 最值：先由奇偶分组写出 S(2n)，再讨论奇数项多出的一项，分别找最值。
**易错点**
- 只求出偶数项通项，奇数项未写；
- S(n) 奇偶两种情形没有分别给出。

### 数列 · 相邻两项和/积为 f(n) 型的作差作商（培优讲义 第348—350页）
**核心思路**
- a(n)+a(n+1)=f(n)：写出下一式 a(n+1)+a(n+2)=f(n+1) 相减，得隔项为常差（等差），按奇偶分别写出；
- a(n)·a(n+1)=f(n)：相除得 a(n+2)/a(n)=f(n+1)/f(n)，隔两项成等比（或比例可化常量），按奇偶分段；
- 求前 n 项和时利用每个隔项结构，两两配对或分奇偶求和。
**易错点**
- 两式相除时默认 f(n)≠0，题设未保证时需讨论「某一项为 0 后全为 0」；
- 分段后漏掉首项归属。

### 数列 · 取整数列在区间内的项数统计（培优讲义 第350—353页）
**核心思路**
- 通项带取整符号（如 a(n)=[f(n)] 或含 n 的高斯函数）时，按区间分组：先找出取整值变化的临界 n（f(n) 为整数的位置）；
- 在每一段内取整值为常数，段内项数与下标范围用不等式解出；
- 求满足 a(n)<m 或 >m 的项数，转化为解关于 n 的不等式，再取整得到边界。
**易错点**
- 临界点处取整值归属（恰好为整数时属于下一段）判断错误；
- 段数统计时首尾端点重复计数。

### 数列 · 平均不等式放缩（优质解法 第47页）
**核心思路**
- 递推含 aₙ₊₁²−aₙ₊₁+3=0 这类二次关系，要证含 (aₙ+2) 的乘积或和的下界：把 aₙ₊₁²+3 拆成 (aₙ₊₁²+1)+2，用 a²+1≥2a 得 aₙ₊₁²+3≥2aₙ₊₁+2；
- 整理成 aₙ₊₁+2≥2(aₙ+2) 的等比型，逐级迭代得下界；
- 关键是把式子凑成与目标括号完全相同的整体，再用基本不等式。
**易错点**
- 等号成立条件（如 aₙ₊₁=1）未必能达到，只能作为放缩界；
- 不等式方向要与所证结论一致；
- 迭代后首项用 a₁ 而不是 a₀。
**依据**：`题库/《高考数学•优质解法》（405P）.pdf`（OCR 第1—200页）

### 数列压轴 · 错位相减的万能公式 Sn=(An+B)qⁿ+C（方法题型一本通 第169—175页）
**核心思路**
- 见到 cₙ=(an+b)·qⁿ⁻¹（q≠1，a、b 为待定）的求和，结果为 Sₙ=(An+B)qⁿ+C 的形式，先设出 A、B、C，用 n=1、2、3 三个特值确定系数；
- 也可以两边乘以 q 用两次错位相减；万能公式省去错位书写，选择题里可直接套；
- 求得的 A 与 a、q 的关系为固定形式，不用每次现推。
**易错点**
- q=1 时公式不适用（此时就是等差求和）；
- 三个特值中若 n 从 0 或 1 起算搞错，C 的取值随之出错；
- 求和结果要写成「(An+B)qⁿ+C」，不能把 C 并进前面指数。
**依据**：`题库/高中数学方法题型一本通/高中数学方法题型一本通.pdf`（OCR 第169—175页）

### 数列压轴 · 裂项六型的常用公式清单（方法题型一本通 第181—190页）
**核心思路**
- 等差型：分母两因子之差为常数者，裂成两分之一之差乘以系数；分母含 (2n−1)(2n+1)、n(n+1)(n+2) 时按固定裂项写；
- 根式型：含 1/(√n+√(n+k)) 的项先分母有理化，化为两相邻根式之差；根式与 n 的乘幂混合型按 (n+1)√n−n√(n+1) 结构整理；
- 指数型：分母含 (2ⁿ−1)(2ⁿ⁺¹−1) 或 n·2ⁿ 的项，按「差为指数式」裂成两项之差；
- 符号型：含 (−1)ⁿ 的项裂成两项后要核符号交替；
- 错位型（本块专指分母为 n(n+k)(n+2k) 的连乘型）：按三项连乘的「前项−后项」裂项；
- 放缩型：裂项后若要证明不等式，只保留可逐项相消的首尾项并判断丢项方向。
**易错点**
- 根式型没做有理化就硬拆，裂项系数算错；
- 三项连乘型拆成两项之差时系数漏乘；
- 放缩型只朝一个方向放缩，导致证明方向反了。
**依据**：`题库/高中数学方法题型一本通/高中数学方法题型一本通.pdf`（OCR 第181—190页）
