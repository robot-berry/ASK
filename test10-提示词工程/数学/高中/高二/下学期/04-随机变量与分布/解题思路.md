## 四、概率与统计（题型26—27）

### 13. 条件概率、全概率、贝叶斯（题型26 技法03—05）

**核心思路**
- 条件概率：$P(B|A)=\frac{P(AB)}{P(A)}$；
- 乘法公式：$P(AB)=P(A)P(B|A)$；
- 全概率：按互斥完备事件组分解 $P(B)=\sum P(A_i)P(B|A_i)$；
- 贝叶斯：$P(A_i|B)=\frac{P(A_i)P(B|A_i)}{\sum_j P(A_j)P(B|A_j)}$；
- 关键是**正确划分完备事件组**。

**易错点**
- 事件组不互斥或不完备；
- 条件概率方向写反。

### 14. 分布列与数字特征（题型27 技法01—02）

**核心思路**
1. 确定随机变量所有取值；
2. 逐一求概率，检验和为 1；
3. 求 $E(X)=\sum x_ip_i$，$D(X)=\sum(x_i-E(X))^2p_i$；
4. 判断分布类型：二项分布（独立重复、成功概率恒定）、超几何分布（不放回抽样）；
5. 正态分布用 $3\sigma$ 原则与对称性。

**易错点**
- 分布列概率和不为 1 未发现；
- 二项分布与超几何分布混淆（放回/不放回）；
- 期望线性性质误用。

### 14.1 二项分布与超几何分布的识别公式

**核心思路**

- 二项 $X\sim B(n,p)$：$P(X=k)=\binom nk p^k(1-p)^{n-k}$，$E(X)=np$，$D(X)=np(1-p)$；
- 超几何：$P(X=k)=\dfrac{\binom Mk\binom{N-M}{n-k}}{\binom Nn}$，$E(X)=\dfrac{nM}{N}$；
- 判定口诀：**有放回 / 独立重复 → 二项；不放回 / 有限总体 → 超几何**；
- 当总体 $N$ 远大于样本 $n$ 时，超几何可近似为二项（$p=\dfrac MN$）；
- 正态：$X\sim N(\mu,\sigma^2)$，$P(\mu-\sigma<X<\mu+\sigma)\approx0.6827$ 等。

**易错点**：超几何中组合数上下标写错；二项分布中 $n$ 与 $k$ 混淆。

### 14.2 分布列的检验与期望线性性质

**核心思路**

- 检验：$\sum p_i=1$（必查，能抓出多数计算错误）；
- $E(aX+b)=aE(X)+b$ 对**任何**分布成立；$D(aX+b)=a^2D(X)$；
- $E(X+Y)=E(X)+E(Y)$ 无需独立；$D(X+Y)=D(X)+D(Y)$ **需要**相互独立；
- 决策题：比较两种方案的 $E(X)$，若风险要求高再比 $D(X)$。

**易错点**：对方差用线性性质（$D(X+Y)=D(X)+D(Y)$）而不检查独立性；决策题只比期望不谈风险。

### 随机变量与分布 · E(XY)=E(X)E(Y) 需独立（浙大优辅22 第58—59页）
**核心思路**
- 期望的线性性 $E(X+Y)=E(X)+E(Y)$ 对任意随机变量成立，不需要独立；
- 乘积的期望 $E(XY)=E(X)E(Y)$ 必须附加"$X,Y$ 相互独立"，否则不成立，典型反例是 $X+Y=1$ 型（两者完全负相关）；
- 判断能否拆开乘积期望：先看题目是否明说独立，或能否由样本空间结构证明独立。
**易错点**
- 把 $E(XY)$ 无条件拆成 $E(X)E(Y)$；
- 只验证了 $E(X+Y)$ 的可加性就类推到乘积。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破22-概率.pdf`（OCR 第58—59页）

### 随机变量与分布 · 混检方案的期望比较（浙大优辅22 第64—65页）
**核心思路**
- 逐人检测需 $n$ 次；分组混检把 $n$ 人分成 $k$ 人一组共 $n/k$ 组，每组先混检 1 次，若该组有人患病再对该组 $k$ 人逐一检测，故一组期望检测次数为 $1+k\cdot P(\text{组阳性})$，总期望为组数乘之；
- 组阳性概率由单人阳性率 $p$ 得 $1-(1-p)^k$，代入后对 $k$ 求最小值得最优分组；
- 混检优于逐人检测的条件是 $p<1-k^{-1/k}$，且组内人数并非越大越好，需按 $p$ 具体优化（$p$ 很小时最优 $k$ 约为 $1/\sqrt{p}$ 量级）。
**易错点**
- 忘乘组数或把"组阳性后再检测"的次数写成 $k+1$；
- 默认组越大越省，未做期望比较。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破22-概率.pdf`（OCR 第64—65页）

### 随机变量与分布 · 几何分布的无记忆性（浙大优辅22 第52—53页）
**核心思路**
- 独立重复试验中首次成功所需次数 $X$ 服从几何分布，$P(X=k)=(1-p)^{k-1}p$；
- 无记忆性：已知前 $m$ 次都未成功，再等 $n$ 次的分布与从头开始相同，即 $P(X>m+n\mid X>m)=P(X>n)$；
- 条件概率计算时把 $P(X>m+n)$ 与 $P(X>m)$ 都用等比求和表示，再相除即可验证。
**易错点**
- 把"至少 $n$ 次"与"恰好第 $n$ 次"混淆；
- 事件 $\{X>m+n\}$ 是 $\{X>m\}$ 的子事件这一点没用上。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破22-概率.pdf`（OCR 第52—53页）

### 随机变量与分布 · 概率最大项用数列单调性求（浙大优辅22 第45—46页）
**核心思路**
- 求 $P(X=k)$ 最大时的参数或 $k$：比较相邻两项，作商 $\dfrac{P(X=k+1)}{P(X=k)}$ 或作差，令其大于 1 得到单调递增的区间，转折点即最大项；
- 参数未知时（如超几何分布中总体个数 $N$），把"某项概率最大"写成关于参数的不等式组，解出参数范围后取整数；
- 这类"使观测结果最可能"的思路即极大似然，答题时说明"相邻项比值由大于 1 变为小于 1"即可。
**易错点**
- 只比较一项而不写出比值随 $k$ 的变化；
- 解出的参数范围未取整数或未检验端点。
**依据**：`题库/浙大优辅-高中数学各个击破（全套23册）/高中数学各个击破22-概率.pdf`（OCR 第45—46页）

### 随机变量与分布 · 方差随参数变化时的增减判断（培优讲义 第399—403页）
**核心思路**
- 分布中的参数（如概率 p）变化时求方差最值：先写出 E(X) 与 E(X²) 关于参数的表达式，D(X)=E(X²)−E(X)² 是参数的函数；
- 若为二次函数，配方或求导找最值点，并注意参数的取值范围；
- 离散型与二项型结论对比：二项分布 D=np(1−p) 在 p=½ 最大。
**易错点**
- 忘记 D(X)=E(X²)−[E(X)]² 中的平方，写成 E(X²)−E(X)；
- 参数范围未与概率合法性（0≤p≤1）取交集。
**依据**：`题库/2026重难点培优讲义/2026重难点培优讲义教师版.pdf`（OCR 第399—403页）

### 随机变量与分布 · 二项分布与几何分布的期望取舍（培优讲义 第406—410页）
**核心思路**
- 在「做若干次试验最多取某值」类问题中，若目标是固定次数内成功的个数 → 二项分布；若目标是首次成功所需次数 → 几何分布；
- 几何分布 P(Y=k)=(1−p)^(k−1)·p，E(Y)=1/p，用于比较两组方案（如两种操作哪种期望次数更少）；
- 两方案比较时分别写出期望再比大小，结论依赖 p 的范围时要分段。
**易错点**
- 「最多试 n 次」不是几何分布（几何分布次数无上限），需截断并重新归一；
- 二项与几何的期望混用。
**依据**：`题库/2026重难点培优讲义/2026重难点培优讲义教师版.pdf`（OCR 第406—410页）

### 随机变量与分布 · 二项分布的棣莫弗—拉普拉斯正态近似（培优讲义 第410—413页）
**核心思路**
- n 较大、p 不极端时，二项分布近似服从 N(np, np(1−p))，求「X≤k」或「X 在区间内」的概率时把 k 标准化后查正态表；
- 近似前提：n 足够大使 np 与 n(1−p) 都不小（教材给出判别口径），否则改用精确求和；
- 涉及「至少」「至多」时用正态的对称性化简。
**易错点**
- np 或 n(1−p) 很小时仍用近似；
- 连续性修正（整数端点取 k±0.5）与题设精度不一致。
**依据**：`题库/2026重难点培优讲义/2026重难点培优讲义教师版.pdf`（OCR 第410—413页）

### 随机变量与分布 · 超几何分层的抽盒模型（培优讲义 第415—419页）
**核心思路**
- 不放回地从两类物品中抽取：先从总数中定各类个数，再按抽取个数列超几何分布 P(X=k)=C(M,k)C(N−M,n−k)/C(N,n)；
- 计算时先估出 k 的可能范围（max(0, n−(N−M)) ≤ k ≤ min(n,M)），只算这些项；
- 与二项分布的选择：有放回或总体极大视作独立抽 → 二项；无放回且总体有限 → 超几何。
**易错点**
- 分母用组合而非排列；
- 忽略 k 的可能范围导致概率和不为 1。
**依据**：`题库/2026重难点培优讲义/2026重难点培优讲义教师版.pdf`（OCR 第415—419页）

### 随机变量与分布 · 正态分布对称性与 σ 的含义（培优讲义 第419—423页）
**核心思路**
- 正态曲线关于 x=μ 对称：P(X≤μ−t)=P(X≥μ+t)=½−P(μ−t<X<μ+t)/2，用对称性把一个概率换到已知区间；
- σ 决定曲线胖瘦：σ 越大越扁平（数据越分散），σ 越小越集中；比较两组正态的分散程度只看 σ；
- 利用 3σ 原则（|X−μ|<σ、<2σ、<3σ 的百分比区间）做近似判断。
**易错点**
- 把 σ 当作取值范围端点而不是标准差；
- 对称换算时对「大于」与「大于等于」的连续性处理不一致。
**依据**：`题库/2026重难点培优讲义/2026重难点培优讲义教师版.pdf`（OCR 第419—423页）

### 随机变量与分布 · 二项分布概率最大项用左右邻不等式求 $k$（题型总结选修3 第101—102页）
**核心思路**
- 设 $X\sim B(n,p)$，要找 $P(X=k)$ 最大的 $k$：同时写出 $P(k)\ge P(k-1)$ 与 $P(k)\ge P(k+1)$ 两个不等式（左邻加右邻），两边约去相同的组合数与幂，得 $k$ 落在区间 $np+p-1\le k\le np+p$，$k$ 取整数；
- 只与一个邻项比较会得到 $k\le$ 或 $k\ge$ 的单边范围，必须左右两边都约束才能定位转折点；
- $n,p$ 已知时直接代入算区间，区间内可能有 1 或 2 个整数，取其一（或并列）；
- 若题目“使观测结果最可能”给出已知参数（如总体个数 $N$），同样先用不等式定位，再结合整数条件取值。
**易错点**
- 只写一个不等式，取到端点而非最大值点；
- 区间端点为整数时要说明两个值并列或按题意取舍。
**依据**：`题库/新高考高中数学《题型总结》+高一高二培优压轴专练/新高考高中数学题型总结-选修3解析册.pdf`（OCR 第101—102页）

### 随机变量与分布 · 二项分布参数 $p$ 用导数求最值（题型总结选修3 第103—104页）
**核心思路**
- 题目问“当 $p$ 取何值时恰有 $k$ 件不合格（成功）的概率最大”：把 $P=C(n,k)p^k(1-p)^{n-k}$ 看作关于 $p$ 的函数 $f(p)$，定义域 $p\in(0,1)$；
- 求导并用乘积法则提取公因式，导数中出现“$p$ 的一次式”，令导数为 0 得临界点 $p_0=k/n$；
- 判断临界点两侧导数符号（左正右负），确认最大值点；$k=0$ 或 $k=n$ 时临界点在边界，需单独说明；
- 代入后求期望时，若件数 $Y\sim B(m,p_0)$，则用 $E(Y)=mp_0$ 与线性性质合并常数项。
**易错点**
- 求导后没提取公因式导致解错临界点；
- 忘记 $p$ 的定义域只在 $(0,1)$，或边界情形未验证。
**依据**：`题库/新高考高中数学《题型总结》+高一高二培优压轴专练/新高考高中数学题型总结-选修3解析册.pdf`（OCR 第103—104页）

### 随机变量与分布 · 超几何最值反求总体参数（题型总结选修3 第105—106页）
**核心思路**
- 设 $X$ 服从超几何分布，已知“恰取 $k$ 个次品的概率最大”求次品总数 $M$：写出 $H(k;n,M,N)$ 的形式，比较 $M$ 与 $M\pm1$ 时的概率；
- 作比后约去相同因子，得到关于 $M$ 的两个线性不等式（分别来自与 $M+1$、$M-1$ 的比较），解出 $M$ 的整数区间；
- 得到的 $M$ 再代回求期望 $E(X)=nM/N$；
- 若样本量 $n$ 也待定，先固定 $n$ 解 $M$，或按题意先确定其中一个再对另一个用同一不等式组。
**易错点**
- 约分时漏掉阶乘比中随 $M$ 变化的因子，导致不等式写错；
- 解出的区间含两个整数时未按题意取舍。
**依据**：`题库/新高考高中数学《题型总结》+高一高二培优压轴专练/新高考高中数学题型总结-选修3解析册.pdf`（OCR 第105—106页）

### 随机变量与分布 · 状态转移构造等比数列求概率（题型总结选修3 第106—109页）
**核心思路**
- 概率题中每一步结果影响下一步（轮流投篮、从箱中取放球、亲子代花色、比赛积分），设“第 $i$ 步处于状态 A”的概率为 $p_i$；
- 按上一状态的两种可能写全概率：$p_i=p_{i-1}\cdot P(A\mid A)+(1-p_{i-1})\cdot P(A\mid B)$，整理成 $p_i=ap_{i-1}+b$；
- 用 $p_i+t=a(p_{i-1}+t)$，$t=b/(1-a)$ 求出 $t$，得 $\{p_i+t\}$ 为等比数列，写出 $p_i$ 的通项；
- 递推求通项后，若再用到期望或某一步的分布，把通项直接代入（如 $E(X)=\sum c_i p_i$），并说明单调性（如递减）以回答“哪一步期望最大”。
**易错点**
- 只写了“保持状态 A”的一项，漏掉来自 $B$ 的转移（$1-p_{i-1}$ 项）；
- 构造等比数列时用的是 $p_i$ 而非 $p_{i-1}$ 的系数，$t$ 算错；
- 初始条件 $p_1$ 未单独求就套通项公式。
**依据**：`题库/新高考高中数学《题型总结》+高一高二培优压轴专练/新高考高中数学题型总结-选修3解析册.pdf`（OCR 第106—109页）

### 随机变量与分布 · 相邻概率差为等比数列再叠加（题型总结选修3 第108页）
**核心思路**
- 题目要证“最终获胜的概率”，且状态为“累计得分 $i$”：设 $P(i)$ 表示处于状态 $i$ 时的胜率，按一步转移写出 $P(i)=p_1P(i+1)+p_2P(i-1)+p_3P(i)$；
- 整理后得到 $P(i+1)-P(i)$ 与 $P(i)-P(i-1)$ 成固定比例，即相邻差列构成等比数列；
- 分别写出各差项的公比与首项（首项用 $P(1)-P(0)$ 表示），对所有差项叠加得 $P(n)-P(0)$ 的表达式；
- 再借助两端边界条件 $P(0)=0$、$P(n)=1$（或题设条件）解出首项，回代得目标概率。
**易错点**
- 直接对 $P(i)$ 用等比而非对差值用等比；
- 叠加后忘记用边界条件定首项。

### 随机变量与分布 · 用二项分布最值反求试验总次数（题型总结选修3 第131—132页）
**核心思路**
- 题目给出“某事件发生某固定次数的概率最大”，但总次数 $N$ 未知：先由正态分布算单次概率 $p$（如 $\mu\pm3\sigma$ 落在区间内），得 $X\sim B(N,p)$；
- 把 $P(X=m)$ 写成含 $N$ 的表达式，用相邻比值 $f(N+1)/f(N)$ 与 1 比较，得 $N$ 的上界（通常为 $m/p$ 附近的整数）；
- 整数 $N$ 取满足“比值先大于 1 后小于 1”的那一个；
- 若两个相邻的 $N$ 都使比值接近 1，按题目要求取值并写出估计说明。
**易错点**
- 把 $p$ 与 $m$ 混淆，直接令 $N=m$；
- 比值不等式的方向写反，取到使概率最小的 $N$。

### 随机变量与分布 · 正态分布反求样本量或概率范围（题型总结选修3 第131—132页）
**核心思路**
- 样本均值 $\bar X\sim N(\mu,\sigma^2/n)$，标准差缩小为 $\sigma/\sqrt n$；题目要求“误差落在某区间内概率不小于 0.9545”时，用 $\mu\pm2\sigma/\sqrt n\subseteq$ 目标区间；
- 把不等式写成 $\sqrt n\ge$“$2\sigma$ 除以区间半宽”，解出最小整数 $n$；
- 要求“落在某区间外的次数期望大于某值”时，先由 $3\sigma$ 原则得单次概率，再令 $N\cdot P$ 大于该值，解 $N$ 的最小整数；
- 求“某区间内概率”时，先把区间平移为 $\mu$ 对称的形式，再用对称性拆成两侧。
**易错点**
- 把 $\sigma$ 当作 $\sigma^2$ 代入，或样本均值标准差仍用 $\sigma$；
- 解出 $n\ge$ 某数后向下取整（应向上取整）。

### 随机变量与分布 · 正态曲线参数识别与“高瘦矮胖”比较（题型总结选修3 第123—124页）
**核心思路**
- 由密度函数解析式直接读出 $\mu$ 与 $\sigma$：指数部分为 $-(x-\mu)^2/(2\sigma^2)$，前面的系数与 $\sigma$ 相关，令峰值为 $1/(\sqrt{2\pi}\sigma)$ 可校验 $\sigma$；
- 两正态曲线比较：曲线越“高瘦”，$\sigma$ 越小、数据越集中；峰值位置横坐标为 $\mu$；
- 比较概率大小转为比较“某条竖线左侧曲线下面积”：$\mu$ 相同而 $\sigma$ 不同，$\sigma$ 小者在 $\mu$ 附近集中、远离 $\mu$ 处概率更小；
- $\mu$ 不同而 $\sigma$ 相同时，用对称性与平移判断；要求某点概率相等，两 $\mu$ 关于该点对称。
**易错点**
- 把峰值 $1/(\sqrt{2\pi}\sigma)$ 当作 $\sigma$ 或 $\sigma^2$；
- 不同 $\mu$、不同 $\sigma$ 两曲线直接比大小，未做标准化。

### 随机变量与分布 · 平均分组中指定对象同组的概率（优质解法 第340—341页）

### 随机变量与分布 · 摸球的「浓度」法求期望（优质解法 第341页）
**核心思路**
- 从含红球m个、白球n个的盒中取t个：红球个数期望 E = t·m/(m+n)，不必求分布列；
- 把红球比例看成「浓度」，取球个数看成「溶液量」，期望=浓度×量；
- 多次转移（取出放入另一盒再取）：逐步更新红球浓度与总数，按每一步取球个数加权；
- 求最终取到红球的概率 = 最终红球数/最终总球数。
**易错点**
- 浓度法给的是期望不是概率；
- 不放回时每一步的浓度都要更新，转移后总数也变。

### 随机变量与分布 · 混合样本方差公式（优质解法 第341—343页）
**核心思路**
- 已知各组平均数x̄_i、方差s_i²、权重w_i，合并方差 S² = Σ w_i[(x̄_i−z̄)²+s_i²]；
- 先求总平均 z̄ = Σ w_i x̄_i（权重为人数比例）；
- 两组时 S² = w1[(x̄1−z̄)²+s1²] + w2[(x̄2−z̄)²+s2²]；
- 由总方差反求某组方差或人数时，代入公式解方程。
**易错点**
- 权重是人数占比，不是组数；
- 组内方差要加「组均值与总均值之差的平方」，不能直接加权平均各组方差；总均值必须先算。

### 随机变量与分布 · 正态曲线并排比较（方法题型一本通 第115—116页）

- 古典概型：从有限等可能结果中随机取，求某事件概率（如从 5 款中取 2 款，都是某类）。

### 随机变量与分布 · 超几何分布与二项分布的判别与三步解法（全基础题型 第470—474页）
**核心思路**
- 超几何（一次抽 n 个、不放回）：袋中两类共 N 个，其中某类 M 个，摸出 n 个中该类个数 X；取值 0 … min(M, n)，P(X=k) = C(M,k)·C(N−M,n−k)/C(N,n)，E(X) = nM/N。

- 二项分布 n 与 k 混淆；超几何中 X 的上限取 min(M,n) 而非 n。

### 随机变量与分布 · 正态分布：μ 定对称轴、σ 定高矮、面积即概率（全基础题型 第475—476页）
**核心思路**
- X ~ N(μ, σ²)：μ 是期望，决定图像对称轴（x = μ）；σ 是标准差，σ 越大图像越矮胖、越小越瘦高；曲线下面积 = 概率，总面积 = 1。
- 对称性应用：P(X > μ) = 0.5；P(X < μ−a) = P(X > μ+a)。
- 3σ 原则：P(μ−σ < X < μ+σ) ≈ 0.6826，P(μ−2σ < X < μ+2σ) ≈ 0.9544；落在 (a, b) 的概率可用对称区间拆分相减。
- 直方图拟合正态：用样本平均数近似 μ、样本方差近似 σ²，再按 3σ 区间求概率；「100 件中位于某区间的件数 X」服从二项，E(X) = 100×该概率。
**易错点**
- σ² 与 σ 混用（N(μ, σ²) 中的第二个参数是方差，比较图像高矮要看 σ 不是 σ²）。
- 区间不对称时（如 (3, 6)）直接用两倍对称区间概率，忘记减去中间部分。

### 随机变量与分布 · 期望与方差的「套娃算法」Y = aX + b（全基础题型 第469页）
**核心思路**
- 若 Y = aX + b，则 E(Y) = aE(X) + b，D(Y) = a²D(X)，直接由 X 的期望、方差算 Y 的，不必重新列表。
- 一组样本数据经过 10xᵢ 变换：方差变 100 倍；加上常数 c 时方差不变、均值加 c。
- 多选/计算题中出现「D(X) = (1−m)²」「E(X) = 1−m」这类由分布列得出参数的结论，用套娃算法与 E(X)、D(X) 定义式联立核对。
**易错点**
- 方差变换漏平方（写成 a·D(X)）。
- 平移常数对均值与方差的影响混淆（平移不影响方差）。
