## 使用入口

1. 阅读 [项目交接说明](00_请先读_项目交接说明.md)。
2. 按 [版本与调用说明](01_提示词/版本与调用说明.md) 使用候选提示词及附加 system 指令。
3. 在 `02_知识点与题库/` 查阅知识卡、分类索引和100题题面。
4. 在 `03_测试结果/` 查看复测分析，在 `07_100题完整运行记录_内部/` 查阅原始运行记录。
5. `04_代码与回归/` 保存核心代码和便携离线回归，运行方式见该目录说明。

## 与现有工程的关系

初中使用本目录的候选提示词与知识卡；高中继续使用 `../高中/` 的专题入口和输出契约。两套方案尚未统一调用协议，不应直接混用高中输出 schema。这里完成资料分类整合，不会自动更新服务或数据库。
