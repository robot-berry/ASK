# 代码与离线回归

本目录是为交接摘取的隔离版关键源代码，不含完整服务、OCR 模型、运行环境、服务启动配置、提示词数据库、接口凭据或完整调用依赖。`search_machine_pipeline.py` 用于了解集成位置，不能直接在此目录启动完整服务。文件为隔离副本的当前快照，不代表线上代码。

- `isolation_quality_checks.py`：少数动点、圆与二次函数题的有限数学及结果边界检查，也有定向语言修补。
- `isolation_answer_blanks.py`：对严格识别的少量题型进行答案留空或核查。
- `isolation_linear_answer_guard.py`：部分一元一次方程、单空算术与识别缺失的保护。
- `compact_guidance.py`、`streaming_images.py`：提示词输出格式、部分文本处理及相关依赖。
- `test_isolation_*.py`：原隔离项目的对应回归；其中含用于校验的内部样例结果，不是学生材料。

使用 Python 3，在本目录运行：

```powershell
python 运行离线回归.py
```
