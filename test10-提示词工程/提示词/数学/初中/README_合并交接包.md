1. `00_请先读_项目交接说明.md`：目标、答案边界、进度、限制与原工程位置。
2. `01_提示词/版本与调用说明.md`、`V11_数据库版本9_候选提示词.txt` 和 `请求附加_system提示词.txt`：提示词快照及实际调用组成。V11 是候选名称，9 是数据库版本编号；不是线上当前版本的证明。
3. `02_知识点与题库/`：四类知识卡、教辅原页对照、候选索引与 100 题题库。
4. `03_测试结果/`：100 题相关结果说明、18 题离线复核与实时复测、数学和语言问题。
5. `04_代码与回归/`：局部代码和离线回归；先阅读该目录说明。原交接记录为 56 项通过、3 项因缺少服务或 OCR 依赖跳过；这是原打包时的结果，本次合并未重新运行。
6. `07_100题完整运行记录_内部/100题运行记录_内部.md`：逐题索引、处理后的解析、原始模型回复和生成图片；仅供内部查看。
7. `05_接手任务与验收.md`：建议的接手任务；`06_补充交接说明.md`：另一份交接材料的补充背景。

原 100 题中，82 题取得完整模型回复、16 题被本地检查拦截、2 题接口兜底；之后 18 题实时复测为 8 题获得完整回复、3 题拦截、7 题兜底。生成完成不代表数学正确，拦截不一定等于数学错误，兜底不算模型答题成功。题图是文字生成并人工确认题面，不能说明真实拍照或几何图识别已通过。
