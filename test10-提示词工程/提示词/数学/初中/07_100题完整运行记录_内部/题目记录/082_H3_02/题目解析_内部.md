# 第 82 题｜较难｜圆的切线综合

**题目：** 初三数学：圆O的半径为10，弦AB长为16。过A、B分别作圆O的切线，交于点P；过O作OH⊥AB，垂足为H。（1）求OH的长；（2）求PA的长；（3）求四边形OAPB的面积。

## 学霸解析


小问 （1）

1. 要求OH的长，已知半径和弦AB，你能把弦的一半、半径和OH放在哪个图形里考虑？
2. 这个图形为什么是直角三角形？题中哪个条件保证了这一点？

小问 （2）

1. 要求PA的长，PA与圆O相切于A，这个相切关系能告诉你哪条线段与OA垂直？
2. 在包含PA的直角三角形中，除了OA，你还能利用哪个已知长度来建立关系？

小问 （3）

1. 四边形OAPB由哪两个三角形组成？这两个三角形全等吗？依据是什么？
2. 要求四边形面积，你需要先知道哪些线段的长度？这些长度是否已经能由前两问得到？

## 中上解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB中点，AH等于AB的一半。
- 勾股定理：在直角三角形OHA中，用半径OA和半弦AH可求OH。
- 切线性质：PA切圆于A，所以OA⊥PA，三角形OAP是直角三角形。
- 切线长定理：从P引两条切线PA、PB，所以PA=PB，且OP垂直平分AB。
- 面积分割：四边形OAPB可分成两个全等的直角三角形，面积是单个三角形面积的2倍。

## 中等解析


小问 （1）

1. 题中OH⊥AB且O是圆心，这提示H是弦AB的中点，所以AH等于AB的一半。
2. 在直角三角形OHA中，应把半径OA作为斜边，用勾股定理建立OH与AH的关系。

小问 （2）

1. PA是切线，切点为A，所以OA⊥PA，三角形OAP是直角三角形。
2. 要求PA，需要先确定OP与OA的关系；由切线长定理和垂直平分弦可找到OP与OH的联系。

小问 （3）

1. 四边形OAPB可沿OP分成两个直角三角形OAP和OBP，它们全等。
2. 四边形面积等于两个三角形面积之和，每个三角形面积用底OA和高PA计算。

## 中下解析


小问 （1）

1. 由OH⊥AB且O为圆心，根据垂径定理可知H是AB中点，因此AH=AB/2。
2. 在直角三角形OHA中，OA是半径，作为斜边；AH是半弦，作为一条直角边。
3. 由勾股定理得OH²=OA²-AH²，代入半径和半弦长即可建立OH的表达式。

小问 （2）

1. 由PA切圆于A，得OA⊥PA，所以三角形OAP是直角三角形，OA和PA是两条直角边。
2. 由切线长定理，PA=PB，且OP垂直平分AB，因此H在OP上，OH是OP的一部分。
3. 在直角三角形OAP中，用勾股定理得PA²=OP²-OA²，而OP=OH+HP，需先由相似或坐标关系确定HP。

小问 （3）

1. 四边形OAPB由三角形OAP和三角形OBP组成，由切线长定理和半径相等可证两三角形全等。
2. 每个三角形的面积是(1/2)×OA×PA，因为OA⊥PA，OA和PA分别是底和高。
3. 四边形面积等于2倍三角形OAP面积，即OA×PA，代入前两问得到的OA和PA即可。

## 学渣解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB中点，AH等于AB的一半。
- 勾股定理：在直角三角形OHA中，用半径OA和半弦AH可求OH。
- 切线性质：PA切圆于A，所以OA⊥PA，三角形OAP是直角三角形。
- 切线长定理：从P引两条切线PA、PB，所以PA=PB，且OP垂直平分AB。
- 面积分割：四边形OAPB可分成两个全等的直角三角形，面积是单个三角形面积的2倍。
- 公式：OH² + (AB/2)² = OA²；条件：在圆中，弦心距、半弦和半径构成直角三角形
- 公式：PA = PB；条件：从圆外一点引圆的两条切线，切线长相等
- 公式：OA ⊥ PA；条件：切线垂直于过切点的半径

小问 （1）

1. 已知圆O半径OA=10，弦AB=16，要求OH的长。
2. 因为OH⊥AB且O为圆心，由垂径定理得H是AB中点，所以AH=AB/2=8。
3. 在直角三角形OHA中，OA是斜边，AH是直角边，满足OH²+AH²=OA²。
4. 代入得OH²+8²=10²，即OH²=100-64=36，所以OH=√36。
5. 检查：OH是弦心距，应小于半径10，且所得参数小于半径，符合图形。
- 易错提示：误把OH当作半径或半弦，忽略垂径定理中H是AB中点。

小问 （2）

1. 已知PA切圆于A，要求PA的长，需利用直角三角形OAP。
2. 由切线性质得OA⊥PA，所以三角形OAP是直角三角形，OA=10。
3. 由切线长定理，PA=PB，且OP垂直平分AB，所以H在OP上，OH是OP的一部分。
4. 在直角三角形OHA和OAP中，∠HOA=∠AOP，且都有直角，所以△OHA∽△OAP，对应边成比例：OH/OA=AH/AP。
- 易错提示：请结合前面的关系，完成最后一步。

小问 （3）

1. 要求四边形OAPB的面积，可将其分成三角形OAP和三角形OBP。
2. 由切线长定理PA=PB，且OA=OB，OP公共，所以△OAP≌△OBP。
3. 每个三角形都是直角三角形，直角边为OA和PA，面积S△OAP=(1/2)×OA×PA。
4. 四边形面积S=2×S△OAP=OA×PA，代入OA=10和PA=80/6，得S=10×(80/6)。
5. 检查：四边形面积应大于单个三角形面积，且由两全等三角形组成，计算式正确。
- 易错提示：误将四边形面积算成一个三角形面积，忘记OAPB由两个全等三角形组成。
- 方法总结：遇圆的弦与切线，先由垂径定理得半弦和弦心距，再用切线性质构造直角三角形，通过勾股定理或相似比求切线长，最后分割图形求面积。
