# 第 88 题｜较难｜圆的切线综合

> 内部记录：模型内容未经逐题审核，可能包含数学错误或答案，不可直接用于学生。

**题目：** 初三数学：圆O的半径为40，弦AB长为64。过A、B分别作圆O的切线，交于点P；过O作OH⊥AB，垂足为H。（1）求OH的长；（2）求PA的长；（3）求四边形OAPB的面积。

**运行状态：** 已生成完整模型解析

## 学霸解析


小问 （1）

1. 要求OH的长，已知半径和弦AB的长，你能把半弦、半径和OH放在哪个直角三角形中？
2. 这个直角三角形中，哪条边是斜边？哪条边是直角边？它们与已知量如何对应？

小问 （2）

1. 要求PA的长，已知半径和OH，你能在哪个直角三角形中建立PA与已知量的联系？
2. 这个直角三角形与由半径、半弦、OH构成的直角三角形有什么关系？为什么？

小问 （3）

1. 四边形OAPB由哪两个三角形组成？它们的面积分别如何计算？
2. 这两个三角形全等吗？根据题设中的哪些条件可以判断？

## 中上解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB的中点，得到AH=AB/2。
- 勾股定理：在Rt△OAH中，OA为半径，AH为半弦，OH为弦心距，满足OH²+AH²=OA²。
- 切线性质：PA切圆于A，所以OA⊥PA，△OAP为直角三角形。
- 相似三角形：△OAH与△OAP有公共锐角，且均为直角三角形，因此相似，对应边成比例。
- 四边形面积：四边形OAPB可分割为两个全等直角三角形，面积等于其中一个三角形面积的2倍。

## 中等解析


小问 （1）

1. 题中OH⊥AB且O为圆心，这提示OH是弦心距，H是AB的中点。
2. 在Rt△OAH中，应把半径OA、半弦AH和OH用勾股定理联系起来。

小问 （2）

1. PA是切线，所以OA⊥PA，△OAP是直角三角形。
2. △OAH与△OAP有公共角∠AOH，且都是直角三角形，可建立相似关系。

小问 （3）

1. 四边形OAPB可沿OP分成△OAP和△OBP，两三角形全等。
2. 每个三角形的底和高分别是PA和OA，面积可用底乘高的一半表示。

## 中下解析


小问 （1）

1. 由OH⊥AB且O为圆心，根据垂径定理可知H是AB的中点，所以AH=AB/2。
2. 在Rt△OAH中，OA是半径，AH是半弦，OH是弦心距，三边满足勾股定理。
3. 将OA=40和AH=32代入OH²+AH²=OA²，可得到OH²的表达式，再开方求OH。

小问 （2）

1. 由PA切圆于A，根据切线性质得OA⊥PA，所以△OAP是直角三角形。
2. △OAH与△OAP均为直角三角形且共用锐角∠AOH，因此两三角形相似。
3. 相似比对应为OH/OA=AH/PA，代入OH、OA、AH的值可得到关于PA的方程。

小问 （3）

1. 由切线长定理，PA=PB，且OA=OB，OP为公共边，所以△OAP≌△OBP。
2. 四边形OAPB的面积等于△OAP面积的2倍，而△OAP是直角三角形。
3. △OAP的面积=OA×PA/2，代入OA和PA的值可表示四边形面积。

## 学渣解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB的中点，得到AH=AB/2。
- 勾股定理：在Rt△OAH中，OA为半径，AH为半弦，OH为弦心距，满足OH²+AH²=OA²。
- 切线性质：PA切圆于A，所以OA⊥PA，△OAP为直角三角形。
- 相似三角形：△OAH与△OAP有公共锐角，且均为直角三角形，因此相似，对应边成比例。
- 四边形面积：四边形OAPB可分割为两个全等直角三角形，面积等于其中一个三角形面积的2倍。
- 公式：OH² + (AB/2)² = OA²；条件：在圆中，弦心距、半弦和半径构成直角三角形
- 公式：PA = PB；条件：从圆外一点引圆的两条切线，切线长相等
- 公式：OA ⊥ PA；条件：切线垂直于过切点的半径

小问 （1）

1. 已知圆O的半径OA=40，弦AB=64，要求OH的长。
2. 因为OH⊥AB且O为圆心，由垂径定理得H是AB的中点，所以AH=AB/2=32。
3. 在Rt△OAH中，OA是斜边，AH和OH是直角边，满足OH²+AH²=OA²。
4. 代入得OH²+32²=40²，即OH²=40²-32²，可先算出差再开方。
5. 最后检查：OH是正数，开方后取正值，并确认OH小于半径40。
- 易错提示：注意OH是弦心距，不是半径；计算时不要误把OH当作40。

小问 （2）

1. 已知半径OA=40，由（1）可求出OH，要求切线长PA。
2. 因为PA切圆于A，所以OA⊥PA，△OAP是直角三角形。
3. △OAH与△OAP都是直角三角形，且共用锐角∠AOH，因此△OAH∽△OAP。
4. 由相似得OH/OA=AH/PA，代入OH、OA=40、AH=32，得到关于PA的方程。
5. 解方程后检查PA为正数，且PA大于AH，符合图形中切线段较长的特点。
- 易错提示：相似三角形对应边不要写错：OH对应OA，AH对应PA。

小问 （3）

1. 要求四边形OAPB的面积，可将其分成△OAP和△OBP。
2. 由切线长定理PA=PB，又OA=OB，OP为公共边，所以△OAP≌△OBP。
3. 因此四边形OAPB的面积等于△OAP面积的2倍。
4. △OAP是直角三角形，面积=OA×PA/2，代入OA=40和（2）中得到的PA表达式。
5. 最后检查：面积应为正数，且等于两个全等三角形面积之和。
- 易错提示：四边形面积是△OAP面积的2倍，不要漏乘2。
- 方法总结：遇圆的弦与切线，先由垂径定理得半弦，再用勾股定理求弦心距；切线问题常构造直角三角形，利用相似或面积公式求解。
