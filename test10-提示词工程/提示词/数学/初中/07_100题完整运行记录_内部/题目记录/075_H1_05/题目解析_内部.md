**题目：** 初三数学：抛物线y=x²+bx+c与x轴交于A(-6,0)、B(8,0)，与y轴交于点C。点P在A、B之间的抛物线上运动。（1）求抛物线解析式；（2）求三角形ABC的面积；（3）求三角形PAB面积的最大值及此时P的坐标。

小问 （3）

## 中上解析

- 二次函数在区间上的最值：点P的纵坐标决定三角形PAB的高，需结合P在A、B之间的范围分析。

## 学渣解析

- 待定系数法：利用抛物线与x轴的两个交点坐标，建立关于b、c的方程组来确定解析式。
- 二次函数与y轴交点：令x=0，可得到点C的纵坐标，它是三角形ABC的高。
- 三角形面积公式：底边AB在x轴上，高为点C到x轴的竖直距离，面积等于底乘高的一半。
- 二次函数在区间上的最值：点P的纵坐标决定三角形PAB的高，需结合P在A、B之间的范围分析。
- 公式：x₁+x₂=-b；条件：抛物线与x轴交于两点时，交点横坐标是方程 x²+bx+c=0 的根
- 公式：S=ah/2；条件：三角形面积公式，底为水平线段时高为竖直距离
- 公式：y=a(x-h)²+k；条件：二次函数配方后求最值，需检查顶点横坐标是否在取值范围内

小问 （1）

1. 题目要求抛物线y=x²+bx+c的解析式，已知它与x轴交于A(-6,0)和B(8,0)。
2. 因为A、B在x轴上，所以x=-6和x=8都是方程x²+bx+c=0的根。
3. 由根与系数的关系，两根之和-6+8=2等于-b，两根之积(-6)×8=-48等于c。
4. 由此可得b=-2，c=-48，抛物线解析式为y=x²-2x-48。
5. 最后把A、B坐标代入解析式检验，确认y值均为0，说明解析式正确。
- 易错提示：代入交点坐标时注意符号，尤其是x=-6代入后平方项为36，不要漏掉负号。

小问 （2）

1. 要求三角形ABC的面积，先确定底边AB的长度和点C到x轴的距离。
2. A(-6,0)、B(8,0)都在x轴上，所以AB=8-(-6)=14。
3. 点C是抛物线与y轴的交点，令x=0代入y=x²-2x-48，得C的纵坐标为-48。
4. 点C到x轴的距离是|-48|=48，这就是三角形ABC的高。
5. 三角形ABC的面积等于14×48÷2，最后一步请你自己算一算。
- 易错提示：点C的纵坐标是负数，计算面积时高应取绝对值，不能直接用负数当高。

小问 （3）

1. 要求三角形PAB面积的最大值及此时P的坐标，底边AB固定为14，面积只随点P到x轴的距离变化。
2. 设P的横坐标为x，则P的纵坐标为y=x²-2x-48，点P到x轴的距离为|y|。
3. 在A、B之间，即-6<x<8，抛物线开口向上，纵坐标y为负，所以高为-y=-(x²-2x-48)。
4. 三角形PAB的面积S=14×[-(x²-2x-48)]÷2=7(-x²+2x+48)，这是关于x的二次函数。
5. 配方得S=7[-(x-1)²+49]，顶点横坐标x=1在-6与8之间，最后一步请你自己算一算。
- 易错提示：点P在A、B之间时纵坐标可能为负，高应取纵坐标的绝对值，不能直接当作纵坐标。
- 方法总结：先由抛物线与x轴交点确定解析式，再求与y轴交点得到固定三角形的高，最后用动点纵坐标的绝对值表示面积并分析二次函数在给定区间上的最值。
