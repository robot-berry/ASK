# 第 83 题｜较难｜圆的切线综合

**题目：** 初三数学：圆O的半径为15，弦AB长为24。过A、B分别作圆O的切线，交于点P；过O作OH⊥AB，垂足为H。（1）求OH的长；（2）求PA的长；（3）求四边形OAPB的面积。

## 学霸解析


小问 （1）

1. 要求OH的长，已知半径和弦长，你能把OH、半弦和半径放在哪个三角形里？
2. 这个三角形是直角三角形吗？依据是什么？

小问 （2）

1. 要求PA的长，已知半径和OH，你能在图中找到与PA有关的直角三角形吗？
2. 这个直角三角形与由半径、半弦、OH组成的三角形有公共角吗？

小问 （3）

1. 四边形OAPB由哪两个三角形组成？它们的面积如何分别表示？
2. 这两个三角形全等吗？依据是什么？

## 中上解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB中点，AH=AB/2。
- 勾股定理：在Rt△OAH中，用半径OA和半弦AH求OH。
- 切线长定理：PA=PB，且OA⊥PA、OB⊥PB。
- 相似三角形：△OAH与△OAP有公共角且均为直角三角形，对应边成比例。
- 面积分割：四边形OAPB的面积等于△OAP与△OBP面积之和。

## 中等解析


小问 （1）

1. 因为OH⊥AB且O为圆心，所以H是弦AB的中点，这是求OH的突破口。
2. 在Rt△OAH中，OA为半径、AH为半弦，应利用勾股定理建立OH与已知量的关系。

小问 （2）

1. 切线PA与半径OA垂直，所以△OAP是直角三角形，这是求PA的关键。
2. △OAH与△OAP有公共角∠AOH，且都是直角三角形，应利用相似比建立PA与已知量的关系。

小问 （3）

1. 四边形OAPB可分割为△OAP和△OBP，分别求面积再相加。
2. 由切线长定理PA=PB，且OA=OB，可判断两个三角形全等，从而面积相等。

## 中下解析


小问 （1）

1. 由OH⊥AB且O为圆心，根据垂径定理可知H是AB的中点，所以AH=AB/2。
2. 在Rt△OAH中，OA是半径，AH是半弦，OH是弦心距，三者满足勾股定理。
3. 将OA=15、AH=12代入OH²+AH²=OA²，可建立关于OH的方程。

小问 （2）

1. 因为PA切圆于A，所以OA⊥PA，△OAP是直角三角形。
2. △OAH与△OAP均为直角三角形，且共用角∠AOH，因此两个三角形相似。
3. 由相似比OH/OA=AH/PA，代入已知的OH、OA、AH，可建立关于PA的方程。

小问 （3）

1. 四边形OAPB可沿OP分成△OAP和△OBP，其面积等于两个三角形面积之和。
2. 由切线长定理PA=PB，又OA=OB，OP为公共边，所以△OAP≌△OBP。
3. 因此四边形面积等于2倍的△OAP面积，而△OAP面积可用底OA和高PA表示。

## 学渣解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB中点，AH=AB/2。
- 勾股定理：在Rt△OAH中，用半径OA和半弦AH求OH。
- 切线长定理：PA=PB，且OA⊥PA、OB⊥PB。
- 相似三角形：△OAH与△OAP有公共角且均为直角三角形，对应边成比例。
- 面积分割：四边形OAPB的面积等于△OAP与△OBP面积之和。
- 公式：OH² + (AB/2)² = OA²；条件：在圆中，弦心距、半弦和半径构成直角三角形
- 公式：PA = PB；条件：从圆外一点引圆的两条切线，切线长相等
- 公式：OA ⊥ PA；条件：切线垂直于过切点的半径

小问 （1）

1. 已知圆O的半径OA=15，弦AB=24，要求OH的长。
2. 因为OH⊥AB且O为圆心，由垂径定理得H是AB的中点，所以AH=AB/2=12。
3. 在Rt△OAH中，OA是斜边，AH是直角边，OH是另一条直角边，满足OH²+AH²=OA²。
4. 代入OA=15、AH=12，得OH²+12²=15²，即OH²+144=225。
5. 所以OH²=81，OH=9（取正值），最后一步请你自己算一算。
- 易错提示：注意垂径定理中H是AB的中点，不要误认为AH等于AB。

小问 （2）

1. 已知半径OA=15，由（1）得OH=9，AH=12，要求切线PA的长。
2. 因为PA切圆于A，所以OA⊥PA，△OAP是直角三角形。
3. △OAH与△OAP都是直角三角形，且共用角∠AOH，所以△OAH∽△OAP。
4. 由相似比OH/OA=AH/PA，代入OH=9、OA=15、AH=12，得9/15=12/PA。
5. 交叉相乘得9·PA=15·12，所以PA=15·12/9，最后一步请你自己算一算。
- 易错提示：相似三角形对应边要找准，OH对应OA，AH对应PA，不要写反。

小问 （3）

1. 要求四边形OAPB的面积，可将其分成△OAP和△OBP。
2. 由切线长定理PA=PB，又OA=OB，OP为公共边，所以△OAP≌△OBP。
3. 因此四边形OAPB的面积等于2倍的△OAP面积。
4. △OAP是直角三角形，直角边OA=15，PA由（2）可得，所以S△OAP=1/2·OA·PA。
5. 代入得S四边形=2·(1/2·15·PA)=15·PA，将PA的表达式代入计算，最后一步请你自己算一算。
- 易错提示：四边形面积是△OAP面积的2倍，不要漏乘2。
- 方法总结：圆中弦长问题常构造弦心距、半弦、半径的直角三角形，再用勾股定理或相似三角形求解。
