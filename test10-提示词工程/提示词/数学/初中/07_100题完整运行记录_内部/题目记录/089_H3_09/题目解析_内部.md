# 第 89 题｜较难｜圆的切线综合

**题目：** 初三数学：圆O的半径为45，弦AB长为72。过A、B分别作圆O的切线，交于点P；过O作OH⊥AB，垂足为H。（1）求OH的长；（2）求PA的长；（3）求四边形OAPB的面积。

**运行状态：** 已生成完整模型解析

## 学霸解析


小问 （1）

1. 要求OH的长，已知半径和弦AB的长，你能把半弦、半径和OH放在哪个直角三角形中？
2. 这个直角三角形中，哪条边是斜边？哪条边是直角边？它们与已知量有什么关系？

小问 （2）

1. 要求PA的长，PA是圆的切线，你能利用切线的什么性质找到与PA有关的直角三角形？
2. 在这个直角三角形中，已知哪些边或角？PA与这些已知量如何联系？

小问 （3）

1. 四边形OAPB由哪两个三角形组成？这两个三角形有什么共同特点？
2. 要求四边形面积，需要先知道哪些三角形的面积？这些面积与已知量或已求量有什么关系？

## 中上解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB的中点，得到AH=AB/2。
- 勾股定理：在Rt△OAH中，OA为半径，AH为半弦，OH为弦心距，满足OH²+AH²=OA²。
- 切线性质：PA切圆于A，所以OA⊥PA，△OAP为直角三角形。
- 切线长定理：从P引圆的两条切线PA、PB，所以PA=PB。
- 面积分割：四边形OAPB可分成两个全等的直角三角形，面积等于2倍△OAP的面积。

## 中等解析


小问 （1）

1. 由OH⊥AB且O为圆心，根据垂径定理可知H是AB的中点，所以AH=AB/2。
2. 在Rt△OAH中，OA是半径，AH是半弦，用勾股定理可建立OH与已知量的关系。

小问 （2）

1. PA是切线，所以OA⊥PA，△OAP是直角三角形，斜边为OP。
2. 由切线长定理PA=PB，且OP垂直平分AB，可先求OH，再在△OAP中找PA与已知量的关系。

小问 （3）

1. 四边形OAPB由△OAP和△OBP组成，且PA=PB、OA=OB，两三角形全等。
2. 所以四边形面积等于2倍△OAP的面积，而△OAP的面积可由OA和PA计算。

## 中下解析


小问 （1）

1. 因为OH⊥AB且O为圆心，由垂径定理得H是AB的中点，所以AH=AB/2。
2. 在Rt△OAH中，OA是半径，AH是半弦，OH是弦心距，三边满足勾股定理。
3. 将OA=45和AH=36代入OH²+AH²=OA²，可得到OH²的表达式，再开方求OH。

小问 （2）

1. 因为PA切圆于A，所以OA⊥PA，△OAP是直角三角形，斜边为OP。
2. 由切线长定理PA=PB，且OP垂直平分AB，所以H在OP上，OH是OP的一部分。
3. 在Rt△OAP中，OA=45，OH已可求，OP=OH+HP，但HP需通过相似或勾股关系与PA联系。

小问 （3）

1. 四边形OAPB可分割为△OAP和△OBP，由PA=PB、OA=OB、OP公共得两三角形全等。
2. 因此四边形面积等于2倍△OAP的面积，而△OAP是直角三角形，直角边为OA和PA。
3. 所以面积=2×(1/2×OA×PA)=OA×PA，代入OA=45和PA的表达式即可。

## 学渣解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB的中点，得到AH=AB/2。
- 勾股定理：在Rt△OAH中，OA为半径，AH为半弦，OH为弦心距，满足OH²+AH²=OA²。
- 切线性质：PA切圆于A，所以OA⊥PA，△OAP为直角三角形。
- 切线长定理：从P引圆的两条切线PA、PB，所以PA=PB。
- 面积分割：四边形OAPB可分成两个全等的直角三角形，面积等于2倍△OAP的面积。
- 公式：OH² + (AB/2)² = OA²；条件：在圆中，弦心距、半弦和半径构成直角三角形
- 公式：PA = PB；条件：从圆外一点引圆的两条切线，切线长相等
- 公式：OA ⊥ PA；条件：切线垂直于过切点的半径

小问 （1）

1. 已知圆O半径OA=45，弦AB=72，要求OH的长。
2. 因为OH⊥AB且O为圆心，由垂径定理得H是AB的中点，所以AH=72÷2=36。
3. 在Rt△OAH中，OA是斜边，AH和OH是直角边，满足OH²+AH²=OA²。
4. 代入得OH²+36²=45²，即OH²=45²-36²，可先算出差再开方。
5. 最后检查：OH是正数，开方后取正值，并确认OH小于半径45。
- 易错提示：注意AH是AB的一半，不是AB；勾股定理中斜边是半径OA，不是OH。

小问 （2）

1. 已知PA是圆O的切线，切点为A，要求PA的长。
2. 由切线性质得OA⊥PA，所以△OAP是直角三角形，斜边为OP。
3. 由切线长定理PA=PB，且OP垂直平分AB，所以H在OP上，OH是OP的一部分。
4. 在Rt△OAP中，OA=45，OH已可求，设PA=x，则OP=OH+HP，而HP可由△OHA∽△OAP的比例关系得到。
5. 检查：相似比对应边为OH/OA=AH/AP，代入OH、OA、AH的数值可解出PA，注意PA为正且大于AH。
- 易错提示：不要误以为OH等于OP；H在OP上，OP=OH+HP，需通过相似或勾股关系求PA。

小问 （3）

1. 要求四边形OAPB的面积，已知OA=45，PA可求。
2. 由PA=PB、OA=OB、OP公共，得△OAP≌△OBP，所以四边形面积等于2倍△OAP的面积。
3. △OAP是直角三角形，直角边为OA和PA，所以△OAP面积=1/2×OA×PA。
4. 因此四边形面积=2×(1/2×OA×PA)=OA×PA，代入OA=45和PA的表达式即可。
5. 检查：面积应为正数，且等于两个全等直角三角形面积之和。
- 易错提示：四边形面积不是△OAP面积的2倍吗？注意△OAP和△OBP全等，所以面积是2倍，不要漏乘2。
- 方法总结：遇圆的弦与切线，先由垂径定理得半弦和弦心距，再用勾股定理求弦心距；切线问题利用切线垂直于半径构造直角三角形，结合切线长定理和相似比求切线长；四边形面积可分割为两个全等直角三角形计算。
