# 第 85 题｜较难｜圆的切线综合

**题目：** 初三数学：圆O的半径为25，弦AB长为40。过A、B分别作圆O的切线，交于点P；过O作OH⊥AB，垂足为H。（1）求OH的长；（2）求PA的长；（3）求四边形OAPB的面积。

## 学霸解析


小问 （1）

1. 要求OH的长，已知半径和弦AB，你能把OH、半弦和半径放在哪个直角三角形中？
2. 这个直角三角形中，哪条边是斜边？哪条边是直角边？它们与已知量有什么关系？

小问 （2）

1. 要求PA的长，已知半径和OH，你能在图中找到与PA有关的直角三角形吗？
2. 这个直角三角形与由半径、半弦、弦心距构成的直角三角形有什么共同点？如何利用它建立比例关系？

小问 （3）

1. 四边形OAPB由哪两个三角形组成？它们的面积分别如何计算？
2. 这两个三角形有什么共同特征？能否用已知的半径和切线长表示它们的面积？

## 中上解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB的中点，得到AH=AB/2。
- 勾股定理：在Rt△OAH中，半径OA、半弦AH、弦心距OH满足OH²+AH²=OA²。
- 切线性质：PA切圆于A，所以OA⊥PA，△OAP是直角三角形。
- 相似三角形：△OAH与△OAP有公共锐角，且均为直角三角形，因此相似。
- 四边形面积：四边形OAPB可分割为两个全等的直角三角形，面积等于二者之和。

## 中等解析


小问 （1）

1. 由OH⊥AB且O为圆心，根据垂径定理可知H是AB的中点，所以AH=AB/2。
2. 在Rt△OAH中，OA为半径，AH为半弦，用勾股定理可建立OH与已知量的关系。

小问 （2）

1. 由PA切圆于A，得OA⊥PA，所以△OAP是直角三角形。
2. △OAH与△OAP均为直角三角形且有一个公共锐角，可判定相似，进而用对应边成比例求PA。

小问 （3）

1. 四边形OAPB可分成△OAP和△OBP，由切线长定理知PA=PB，且OA=OB，所以两三角形全等。
2. 每个三角形的面积可用底OA和高PA计算，四边形面积等于两个三角形面积之和。

## 中下解析


小问 （1）

1. 因为OH⊥AB且O为圆心，由垂径定理得H是AB的中点，所以AH=AB/2=20。
2. 在Rt△OAH中，OA=25为斜边，AH=20为直角边，OH为另一直角边。
3. 由勾股定理得OH²=OA²-AH²，代入数值可求出OH。

小问 （2）

1. 因为PA切圆于A，所以OA⊥PA，△OAP为直角三角形，其中OA=25，OP为斜边。
2. △OAH与△OAP均为直角三角形，且∠AOH=∠AOP，所以△OAH∽△OAP。
3. 由相似比OH/OA=AH/PA，代入OH、OA、AH的值可建立关于PA的方程。

小问 （3）

1. 由切线长定理知PA=PB，又OA=OB，OP为公共边，所以△OAP≌△OBP。
2. △OAP的面积等于(1/2)×OA×PA，其中OA=25，PA已在第（2）问中表示。
3. 四边形OAPB的面积等于△OAP与△OBP面积之和，即2×(1/2)×OA×PA=OA×PA。

## 学渣解析

- 垂径定理：OH⊥AB且过圆心，所以H是AB的中点，得到AH=AB/2。
- 勾股定理：在Rt△OAH中，半径OA、半弦AH、弦心距OH满足OH²+AH²=OA²。
- 切线性质：PA切圆于A，所以OA⊥PA，△OAP是直角三角形。
- 相似三角形：△OAH与△OAP有公共锐角，且均为直角三角形，因此相似。
- 四边形面积：四边形OAPB可分割为两个全等的直角三角形，面积等于二者之和。
- 公式：OH² + (AB/2)² = OA²；条件：在圆中，弦心距、半弦和半径构成直角三角形
- 公式：PA = PB；条件：从圆外一点引圆的两条切线，切线长相等
- 公式：OA ⊥ PA；条件：切线垂直于过切点的半径

小问 （1）

1. 已知圆O的半径OA=25，弦AB=40，要求OH的长。
2. 因为OH⊥AB且O为圆心，根据垂径定理，H是AB的中点，所以AH=AB/2=20。
3. 在Rt△OAH中，OA是斜边，AH和OH是直角边，满足OH²+AH²=OA²。
4. 代入OA=25，AH=20，得OH²=25²-20²=625-400=225。
5. 所以OH=√225，最后一步请你自己算一算。
- 易错提示：注意垂径定理中H是AB的中点，不要误认为OH等于半径或半弦。

小问 （2）

1. 已知半径OA=25，由第（1）问得OH=15，要求切线长PA。
2. 因为PA切圆于A，所以OA⊥PA，△OAP是直角三角形。
3. △OAH与△OAP均为直角三角形，且∠AOH=∠AOP，所以△OAH∽△OAP。
4. 由相似比OH/OA=AH/PA，代入OH=15，OA=25，AH=20，得15/25=20/PA。
5. 解这个比例式得PA=20×25/15，最后一步请你自己算一算。
- 易错提示：相似三角形对应边要找准：OH对应OA，AH对应PA，不要写反。

小问 （3）

1. 要求四边形OAPB的面积，已知OA=25，PA=100/3（由第（2）问表示）。
2. 由切线长定理知PA=PB，又OA=OB，OP为公共边，所以△OAP≌△OBP。
3. △OAP的面积等于(1/2)×OA×PA，因为OA⊥PA。
4. 四边形OAPB的面积等于△OAP与△OBP面积之和，即2×(1/2)×OA×PA=OA×PA。
5. 代入OA=25，PA=100/3，得四边形面积=25×100/3，最后一步请你自己算一算。
- 易错提示：四边形面积是两三角形面积之和，不要漏乘1/2或重复计算。
- 方法总结：遇圆的弦与切线，先由垂径定理得半弦和弦心距，再用勾股定理求弦心距；利用切线垂直半径构造直角三角形，通过相似比求切线长；四边形面积可分割为两个全等直角三角形计算。
