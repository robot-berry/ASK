## 三、方法卡

### M01 · 古典概型与枚举计数
**触发**：摸球、抽签、掷骰子、选人等等可能结果，求概率。
**步骤**：
1. 定型：样本点有限且等可能，否则不能套 $P(A)=\frac mn$。
2. 有序／无序、放回／不放回，分子分母须同一口径。
3. 列举、表格（甲为行乙为列，总数为行列积）、树状图；对角线即「结果相同」。
4. 「至少／至多」分类多时用对立事件 $1-P(\bar A)$。
**易错**：有序与无序混用；列举标准不一而重复遗漏。

### M02 · 事件关系与公式选择
**触发**：判互斥、对立、独立，选用加法或乘法公式。
**步骤**：
1. 互斥 $AB=\varnothing$；对立为互斥且 $A\cup B=\Omega$；独立为 $P(AB)=P(A)P(B)$。
2. 非互斥求并集用容斥：$P(A\cup B)=P(A)+P(B)-P(AB)$。
3. 独立事件同时发生用乘法，可推广到 $n$ 个，对立事件间仍独立。
4. 「互斥而不对立」看能否同时不发生。
**易错**：$P(A)+P(B)=1$ 是对立条件；交集为空不等于独立。

### M03 · 条件概率三法
**触发**：题干有「已知」，或已知事件影响所求概率（不放回）。
**步骤**：
1. 定义法 $P(B\mid A)=\dfrac{P(AB)}{P(A)}$，须 $P(A)>0$。
2. 样本点法：分子分母取自同一缩小后的样本空间。
3. 缩样法（仅古典概型）：直接在小样本空间内计数。
4. 可加性：$A$ 下互斥事件之并的概率为各条件概率之和。
**易错**：$P(B\mid A)$ 与 $P(A\mid B)$ 写反；未缩小样本空间。

### M04 · 全概率公式
**触发**：结果由多来源或多阶段产生，求结果的概率。
**步骤**：
1. 划分 $A_1,\dots,A_n$：两两互斥、并为 $\Omega$、各概率为正。
2. $P(B)=\sum P(A_i)P(B\mid A_i)$。
3. 第一阶段未知求第二阶段用全概率；第二阶段已知反推原因用贝叶斯。
4. 随机化回答：把「是」的比例按两条路径加权，反解真实比例。
**易错**：划分不互斥或不完备仍套公式；两公式混用。

### M05 · 贝叶斯公式
**触发**：已知结果 $B$，反推它来自哪一类原因。
**步骤**：
1. 分母用全概率 $P(B)=\sum P(A_i)P(B\mid A_i)$。
2. $P(A_k\mid B)=\dfrac{P(A_k)P(B\mid A_k)}{P(B)}$，所得为后验概率。
3. 结论写明「来自第 $k$ 类」，再据此写分布列与期望。
4. 由三个概率反求 $P(A)$：按 $B,\bar B$ 两路径展开得一次方程。
**易错**：分母误用条件事件概率；解须按 $0\le P\le1$ 取舍。

### M06 · 独立性判定
**触发**：判断事件独立，或求独立事件同时发生的概率。
**步骤**：
1. $P(AB)=P(A)P(B)$；$P(A)>0$ 时等价于 $P(B\mid A)=P(B)$。
2. 有放回、不同对象互不影响时直接判定独立。
3. 独立之积可推广到 $n$ 个；对立事件之间仍独立。
4. 独立重复三条件：同条件、各次独立、每次两种结果。
**易错**：有放回分堆抽取仍独立，不可判为超几何；独立与互斥混同。

### M07 · 分布列四步与数字特征
**触发**：求离散型随机变量的分布列、期望、方差。
**步骤**：
1. 穷举全部取值，核对不重不漏。
2. 逐值求概率，列表并验证 $\sum p_i=1$。
3. $E(X)=\sum x_ip_i$，$D(X)=E(X^2)-E(X)^2$；$E(aX+b)=aE(X)+b$，$D(aX+b)=a^2D(X)$。
4. 随机变量为独立小事件之和时用期望线性性拆分。
**易错**：取值遗漏；方差忘减 $E(X)^2$；方差单位是原变量单位的平方。

### M08 · 二项分布
**触发**：$n$ 次独立重复试验的成功次数，有放回或频率视为概率。
**步骤**：
1. 各次独立、成功概率同为 $p$、只有两种结果，则 $X\sim B(n,p)$。
2. $P(X=k)=C_n^k p^k(1-p)^{n-k}$，$E(X)=np$，$D(X)=np(1-p)$。
3. 范围概率化为互斥事件之和或用对立事件；「至少一次」为 $1-(1-p)^n$。
4. 两点分布是 $n=1$ 的二项。
**易错**：$n,k$ 弄错；不满足三条件仍套公式。

### M09 · 超几何分布
**触发**：有限总体、分两类、不放回抽取，求抽到某类的件数。
**步骤**：
1. 不放回抽取 $n$ 次且总体容量已知。
2. $P(X=k)=\dfrac{C_M^kC_{N-M}^{n-k}}{C_N^n}$，$E(X)=\dfrac{nM}{N}$。
3. 与分层抽样结合：先按比例定各层人数再抽取。
4. 已知抽出件数反求总体个数：列方程或比较组合数。
**易错**：总体未知仍用超几何；多个同类组各抽若干应逐组计数相乘。

### M10 · 二项与超几何的判据
**触发**：不确定用哪种分布，或出现「将频率视为概率」。
**步骤**：
1. 总体数未给或很大、单次概率不变 → 二项。
2. 有放回必二项；不放回且总体已知为超几何；样本量远小于总体可按二项近似。
3. 第一次抽样结果影响第二次 → 超几何。
4. 频率视为概率：$p=\dfrac{\text{频数}}{\text{总数}}$ 后再按 $B(n,p)$。
**易错**：把直方图纵坐标当 $p$；总体很小仍用二项。

### M11 · 正态分布对称与 3σ
**触发**：$X\sim N(\mu,\sigma^2)$，求区间概率、比较曲线、判异常。
**步骤**：
1. 定 $\mu,\sigma$（方差是 $\sigma^2$）。
2. $P(X\le\mu)=P(X\ge\mu)=0.5$，$P(X\le\mu-t)=P(X\ge\mu+t)$；$P(X\le a)=P(X\ge b)$ 得 $a+b=2\mu$。
3. 区间化为 $\mu\pm k\sigma$ 的组合，用 $3\sigma$ 的 $0.9974$ 与总面积 1 作差。
4. 相邻对称区间概率之差除以 2，即两分界带一侧的概率。
**易错**：$\sigma$ 与 $\sigma^2$ 混用；只有标准正态关于 $y$ 轴对称；超出 $\mu\pm3\sigma$ 应说明异常。

### M12 · 正态标准化与反查
**触发**：给占比、排名反求分数或人数；样本均值问题。
**步骤**：
1. 标准化 $Z=\dfrac{X-\mu}{\sigma}$，$\Phi(-a)=1-\Phi(a)$。
2. 由占比查表得标准分 $a$，按 $x=a\sigma+\mu$ 还原。
3. 样本均值 $\bar X\sim N(\mu,\sigma^2/n)$，标准差为 $\sigma/\sqrt n$。
4. 偏离超若干倍标准差且概率小于 $0.05$，可怀疑原假设。
**易错**：均值的标准差仍用 $\sigma$；$3\sigma$ 外概率约 $0.0026$。

### M13 · 离散概率最值（相邻比较）
**触发**：求 $P(X=k)$ 最大（小）的 $k$。
**步骤**：
1. 列 $P(X=k)\ge P(X=k-1)$ 与 $P(X=k)\ge P(X=k+1)$。
2. 二项相邻比 $\dfrac{P(X=k+1)}{P(X=k)}=\dfrac{(n-k)p}{(k+1)(1-p)}$，最可能次数取 $(n+1)p$ 的整数部分。
3. 超几何用组合数之比的单调性。
4. 解出区间后与取值范围取交集并检验两端。
**易错**：约分后不等号方向错；漏乘组合数；只取一端整数。

### M14 · 二项参数 $p$ 的双解筛选
**触发**：给 $B(n,p)$ 与 $D(X)$ 求 $p$，或给 $E(aX+b)$ 型条件。
**步骤**：
1. 由 $np(1-p)=D(X)$ 解出互补的两解 $p$ 与 $1-p$。
2. 由 $P(X=k_1)<P(X=k_2)$ 判别：$k$ 较大侧概率更大则 $p$ 取较大值。
3. 给 $E(aX+b)$ 先用线性性质求 $E(X)$ 再反求 $p$。
**易错**：只取一个解；概率大小与 $p$ 方向判反。

### M15 · 几何分布与第 $k$ 次首次成功
**触发**：独立重复试验中首次成功时的试验次数。
**步骤**：
1. $P(K=k)=(1-p)^{k-1}p$（无上限），$E(K)=\dfrac1p$。
2. 无记忆性：$P(K>m+n\mid K>m)=P(K>n)$。
3. 限定最多 $n$ 次时须逐项列，并把「$n$ 次都没抽到」单列。
4. 不放回版：分步按剩余数量连乘，或定位法用排列数之比。
**易错**：截断后仍套几何分布；不放回却每步除总数。

### M16 · 马尔科夫链与状态转移
**触发**：下一状态只依赖当前状态，求第 $n$ 次处于某状态的概率。
**步骤**：
1. 设 $P_n$ 为第 $n$ 步处于目标状态的概率，按全概率得 $P_{n+1}=aP_n+b$。
2. 构造等比 $P_{n+1}+t=a(P_n+t)$ 求通项，初始值由题给。
3. 期望用可加性：单步概率乘步数。
4. 「第 $n$ 次处于某状态」求概率；「前 $n$ 次中的次数」求期望。
**易错**：前一状态不止两类仍用一阶递推；漏初始状态。

### M17 · 随机游走与吸收壁
**触发**：位置每次只移 $\pm1$，两端吸收，求到某端概率。
**步骤**：
1. $P(i)=\alpha P(i-1)+\beta P(i+1)$。
2. 边界 $P(0)=0$、$P(m)=1$ 单独写出代入。
3. 左右概率相等时中间状态成等差数列，由两端值定公差。
4. 含原地不动概率时递推多一项，仍按全概率。
**易错**：边界值写反；解递推不验边界。

### M18 · 几何概型
**触发**：随机取点、随机时刻、随机投点求概率。
**步骤**：
1. 定测度维数（长度、面积、体积），概率 = 条件测度 / 总测度。
2. 会面：设 $(x,y)$，条件化为 $|x-y|\le t$，在矩形内算面积比。
3. 无法计算时用随机数模拟的比例。
**易错**：两时段长度不同仍按正方形；维数选错。

### M19 · 决策：期望比较
**触发**：方案选择、进货量、检测方案比较。
**步骤**：
1. 各方案收益（损失）设为随机变量，写分布列算期望，取最大（最小）者。
2. 先比均值，相同或相近再比方差。
3. 进货量：按需求档位把 $n$ 分段，每段 $E(Y)$ 为一次函数，最值在端点。
4. 混检每组 $k$ 人：期望 $=(k+1)-k(1-p)^k$，乘组数后比较。
**易错**：均值相同只凭均值结论；未售部分仍按售价计入。

### M20 · 比赛赛制与局数分布
**触发**：$n$ 局 $m$ 胜、领先即胜、两赛制比较。
**步骤**：
1. 「$n$ 局结束」：最后一局胜者拿下，前 $n-1$ 局胜者恰赢 $n-1$ 局，乘组合数。
2. 胜率为各类比分概率之和；两赛制作差因式分解判符号，$p=\frac12$ 时相同可验算。
3. 求最优单局胜率对 $p$ 求导或比较。
4. 比赛中断分赌注：按继续比赛各自获胜概率之比分配。
**易错**：漏 3 局、4 局结束的分支；局数分布漏乘组合数。

### M21 · 统计图表与数字特征
**触发**：直方图、茎叶图、百分位数、平均数与方差。
**步骤**：
1. 纵轴是频率/组距，面积即频率；频数 = 面积 × 样本容量。
2. 众数取最高矩形中点横坐标；中位数令左右面积各 0.5；平均数 = 中点 × 频率之和。
3. 百分位数：排序后算 $i=n\times p\%$；非整数取大于 $i$ 的最小整数项，整数取第 $i$ 与 $i+1$ 项均值。
4. 方差用「平方的平均数减均值的平方」；经 $ax+b$ 变换后方差 $a^2s^2$。
**易错**：纵坐标当频率；百分位数不插值。

### M22 · 分层抽样与合并方差
**触发**：分层抽样求各层数量或反求总体；求总方差。
**步骤**：
1. 抽样比 = 该层个体数 / 总体个体数；反推用「抽取量 ÷ 抽样比」。
2. 总平均数按层权重加权。
3. 总方差 $=\sum\dfrac{n_i}{n}\left[s_i^2+(\bar x_i-\bar x)^2\right]$。
4. 删去一项：均值不变说明删去值等于原均值，由偏差平方和两式联立求 $n$。
**易错**：抽样比写反；合并方差漏偏差修正项。

### M23 · 回归方程与非线性化
**触发**：求经验回归方程、预测、非线性模型。
**步骤**：
1. 算样本中心 $(\bar x,\bar y)$，回归直线必过该点，按最小二乘得 $\hat b,\hat a$。
2. 换元：指数型取 $\ln y$；$y=a+\frac bx$ 令 $t=\frac1x$；对数、根式型令 $t=\ln x,\sqrt x$。
3. 求系数后还原，预测须代回原变量。
4. 残差 = 观测值 − 预测值；已知残差反推参数时与过样本中心联立。
**易错**：用 $y$ 均值当新变量均值；还原时系数与常数项写反。

### M24 · 拟合效果比较
**触发**：多模型比较、残差图、$R^2$、相关系数。
**步骤**：
1. $Q=\sum(y-\hat y)^2$ 越小越好；$R^2=1-\dfrac{Q}{\sum(y-\bar y)^2}$ 越接近 1 越好。
2. 两模型共用分母，可由一个模型的 $R^2$ 与 $Q$ 换算另一个。
3. 残差均匀分布在水平窄带内为好；喇叭形、弯曲说明模型不当。
4. $|r|$ 越接近 1 相关性越强，符号定正负；$|r|>0.75$ 为较高。
**易错**：$R^2$ 与 $r$ 混用；残差符号做反。

### M25 · 独立性检验
**触发**：$2\times2$ 列联表、判两类变量是否有关。
**步骤**：
1. 设零假设「无关」，整理完整列联表，缺项由行列合计补齐。

4. 比较关系强弱看 $\chi^2$ 大小；样本量扩大 $k$ 倍时 $\chi^2$ 约放大 $k$ 倍。
**易错**：写「证明有关」；只看单一比例判强弱。
