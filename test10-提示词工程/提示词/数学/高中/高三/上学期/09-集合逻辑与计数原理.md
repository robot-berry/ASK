## 三、方法卡

### M01 · 集合关系求参数与元素互异性
**触发**：$A\subseteq B$、$A\cap B=A$、两集合相等，含参数求参数。
**步骤**：
1. 辨类型：列举、不等式解集、点集。
2. 运算关系译成包含：$A\cap B=A\iff A\subseteq B$，$A\cup B=A\iff B\subseteq A$。
3. 含参集合先讨论空集，再在数轴上按端点大小列不等式组，注意开闭。
4. 解出参数后代回检验互异性，元素重复或关系不成立者舍去。
**易错**：漏空集；不回代；端点大小与开闭写反。

### M02 · 集合运算、德摩根与 Venn 图
**触发**：交并补混合运算、补集的组合、三元集合关系。
**步骤**：
1. 各集合化简为区间或列举，先确认全集 $U$。
2. 德摩根：$\complement_U(A\cap B)=\complement_UA\cup\complement_UB$，并之补同理（交并互换）。
3. 补集组合先用定律合并为 $A\cap B$ 或 $A\cup B$ 的补。
4. 三元关系用 Venn 图逐块标数：先三者交集，再两两交，最后单属一块。
**易错**：两公式记混；「同时参加两项」与「只参加两项」混同。

### M03 · 充要条件与小充大必要
**触发**：判断「$p$ 是 $q$ 的什么条件」，或由条件求参数范围。
**步骤**：
1. 写成 $A=\{x\mid p(x)\}$、$B=\{x\mid q(x)\}$，$p\Rightarrow q$ 即 $A\subseteq B$。
2. 小范围充分、大范围必要：真包含为充分不必要或必要不充分，相等为充要。
3. 口诀：定义是充要，判定定理是充分，性质定理是必要。
4. 否定某方向举一反例；条件复杂时改判逆否 $\neg q\Rightarrow\neg p$，链式条件用传递性合并。
**易错**：「$p$ 是 $q$ 的充分条件」与「$q$ 的充分条件是 $p$」看反；单向推出当等价。

### M04 · 容斥、补集与交集法
**触发**：集合计数、$A\cap B\ne\varnothing$、正面情况太多、两条件同时满足。
**步骤**：
1. 二元 $|A\cup B|=|A|+|B|-|A\cap B|$；三元再加回 $|A\cap B\cap C|$。
2. 补集法：正面太繁时求反面（如「四点共面」），用全集结果相减。
3. 交集法：解由 $\alpha,\beta$ 决定时解集为 $A\cap B$；计数型先圈候选再逐次淘汰。
4. 淘汰优先用末位取值、整除性等强条件。
**易错**：三元忘加回三交集；「至少一个不满足」与「全部不满足」混淆。

### M05 · 分类加法与分步乘法
**触发**：计数总体框架，或「不同种类的组合」。
**步骤**：
1. 一步到位、各类互斥 → 分类相加；须分几步、各步独立 → 分步相乘。
2. 复杂问题先分类、类内再分步，逐层查不重不漏。
3. 「不同种类各选若干」以种类搭配分类，类内分步相乘后相加。
4. 数字题按最高位等关键位分类，其余位分步；「至少／至多」取反面。
**易错**：某步不能独立完成整件事仍相乘；同一组合因次序被重复计数。

### M06 · 特殊优先与间接法
**触发**：特殊元素或特殊位置、「不能排某位」。
**步骤**：
1. 以元素为主或以位置为主，先安排受限者。
2. 受限者位置影响其他位置可选数时按其位置分类。
3. 限制多、反面少时用间接法：总数减不符合者，并用容斥加回重复减去的部分。
4. 多面手问题按其被选人数分类。
**易错**：分类标准不一而重复；间接法漏加回交集部分。

### M07 · 捆绑法
**触发**：相邻、「甲与乙必须在一起」、链条先后。
**步骤**：
1. 相邻元素捆成整体，与其余元素全排列，再乘内部排列数。
3. 块不能站两端时先给块选非两端位置。
4. 「甲—中间人—乙」型把中间人一并捆入，块内甲乙可互换。
**易错**：只捆不乘内部排列；块被放到禁位。

### M08 · 插空法
**触发**：互不相邻、相隔几人、关灯不相邻。
**步骤**：
1. 先排无限制元素，形成 $n+1$ 个空（含两端）。
2. 把不相邻元素插入空位；两端不可插时只用中间空。
3. 「恰隔两人」：先排甲乙（可交换），选两人插其间并排列，整体再与其余全排。
4. 两组相互间隔：先排一组，按交替模式插另一组，检查两种起头。
**易错**：漏两端空位或漏乘甲、乙交换；「都不与某元素相邻」误当两两不相邻。

### M09 · 定序倍缩与分裂法
**触发**：元素相对顺序固定（甲在乙前、由高到矮）。
**步骤**：
1. 全部元素全排列，再除以定序元素的全排列数；或只排其余元素占位。
3. 叠加位置限制时按受限者位置分类，类内再用倍缩或填空。
**易错**：把顺序固定当相同元素多除；只除不分类而漏位置限制。

### M10 · 分组分配（均分除序、指定对象、球箱）
**触发**：分成几堆、分给几人、每处至少一人。
**步骤**：
1. 分堆用组合连乘；个数相等的堆除以相等堆数的阶乘，局部均分只除均分部分。
2. 「分成几份」不排序；分给不同对象乘对象数全排列；已指定谁得哪份则不乘。
3. 指定某人恰好去某处：按其所在堆的大小分类，再把该堆放到指定去处。
4. 容量已定的球箱依次取人。
**易错**：局部均分除以全部堆数阶乘；堆无区别却多乘排列。

### M11 · 隔板法
**触发**：相同元素分给不同对象、名额分配、方程正整数解。
**步骤**：
1. $n$ 个相同元素分 $m$ 组、每组至少 1 个：$\binom{n-1}{m-1}$。
2. 允许空组：先借 $m$ 个，隔板分配后每组取走一个。
3. 下限不为 1：先按最低要求预分，剩余再隔板。
4. 方程正整数解个数与隔板位置一一对应。
**易错**：元素不同仍用隔板；下限大于 1 未预分。

### M12 · 环排与多排
**触发**：围成一圈、圆桌、前后两排。
**步骤**：
1. 环排固定一人后其余全排列，为 $(n-1)!$；可翻转时再除以 2。
2. 圆桌指定座位：先固定一人，相邻者可互换，余者再排。
3. 环排中插入元素：先排一组圆排列，再把另一组填入间隔。
4. 多排按直排：先从前排选人排列，其余站后排。
**易错**：环排未固定起点致重复；环形漏首尾相邻。

### M13 · 错位排列
**触发**：信封错装、编号全不同、恰有 $k$ 个对应。
**步骤**：
1. $D(1)=0$，$D(2)=1$，$D(n)=(n-1)[D(n-1)+D(n-2)]$。
2. 恰有 $k$ 个位置正确：选出 $k$ 个放原位，其余全错位，相乘。
**易错**：分不清「恰有」与「至少」；只算一种错位数。

### M14 · 数字排列
**触发**：组成偶数、被 3 整除、大于某数、介于两数之间。
**步骤**：
1. 含 0 时按「0 是否被用」分支，首位不为 0。
2. 偶数先定末位；被 3 整除按各位数字模 3 的余数分类。
3. 大于某数：从最高位逐位比较，该位取更大数字时其余位任意，相等则进下一位。
4. 介于两数之间：小于上限个数减不大于下限个数。
**易错**：首位排 0；逐位比较在相等处直接当全排列。

### M15 · 涂色问题
**触发**：区域涂色、相邻不同色、环形或立方体。
**步骤**：
1. 先标出全部相邻边，对角线不算相邻。
2. 选关键区域，按「与前面某块同色／不同色」分支，分别计数后相加。
3. 环形先定相邻两块，按第三块是否与第一块同色分支。
4. 也可按实际用色种数分类（立方体 3 色为三对对面同色）。
**易错**：只按相邻步进相乘，忽略后续可用色数；环形漏首尾相邻。

### M16 · 路径计数与递推标注
**触发**：网格最短路径、禁行路段、三维网格、非标准方向。
**步骤**：
1. 标准网格路径数 $=\binom{m+n}{m}$，即总步数中选横向步数。
2. 有禁行段：总数减「经过该段的路径数」，后者 = 起点到段一端 × 另一端到终点。
3. 路口标注：每点为上游各点标注之和，封闭记 0。
4. 三维网格分别选横、纵、竖步数位置，三组合数相乘；方向不对称时逐点标注。
**易错**：封闭点重复扣减；非对称方向硬套组合数。

### M17 · 填空法、走楼梯与生成函数
**触发**：相同元素混排、每步 1 级或 2 级、按类取件。
**步骤**：
1. 相同元素先选位置（组合），其余元素再选剩余位置；同类内部不同则乘全排列。
2. 走楼梯：设两级 $x$ 步、一级 $y$ 步，$2x+y=N$，枚举非负整数解，各组按 $\dfrac{(x+y)!}{x!y!}$ 求和。
3. 生成函数：无区别取 $0\sim k$ 个用 $1+x+\cdots+x^k$，有区别用 $(1+x)^m$，整取用 $1+x^k$；$x^r$ 系数即取 $r$ 个的取法数。
**易错**：相同元素位置用排列；只取一组解；两类因子混用。

### M18 · 折线模型与反射法
**触发**：每步 $+1$ 或 $-1$、全程不低于某水平线、找零问题。
**步骤**：
1. 画折线，方案数等于格点路径数 $\binom{\text{总步数}}{\text{上升步数}}$。
2. 有下界限制时用反射法：首次触界后的部分关于该界线反射，总数减对应路径数。
3. 找零问题（$n$ 人持 5 元、$n$ 人持 10 元）概率为 $\dfrac1{n+1}$。
**易错**：反射轴选错；起点或终点落在界线上未单列。

### M19 · 二项式通项
**触发**：求指定项、常数项、有理项、幂指数含参数。
**步骤**：
1. $T_{k+1}=\binom nk a^{n-k}b^k$，把指数合成关于 $k$ 的式子，令其等于目标次数解出 $k$。
2. 常数项令指数为 0；有理项要求指数为整数（可为负），由整除性定 $k$。
3. 两个变元联立两个指数方程；分式、根式先化为整体幂。
4. 「存在常数项」$\iff$ 指数方程有 $k\in[0,n]$ 的整数解。
**易错**：$(a-b)^n$ 漏符号 $(-1)^k$；只求 $k$ 不检验范围。

### M20 · 三项式与乘积展开系数
**触发**：$(a+b+c)^n$、两个二项式相乘、多因式相乘求某次幂。
**步骤**：
1. 三项式按 $[(a+b)+c]^n$ 再展开内层；或写多重组合系数，三指数和为 $n$。
2. 两式相乘：每项与另一式通项配对，列「指数和 = 目标次数」逐项求和。
3. 多因式相乘按「每个因式各选一项」计数。
4. 有公因式先因式分解再配对。
**易错**：整体展开后忘乘回内层系数；多组指数解只取一组。

### M21 · 系数最值项
**触发**：系数最大（小）项、二项式系数最大项、第 $k$ 项最大。
**步骤**：
1. 二项式系数最大：$n$ 偶取中间一项，奇取中间两项。
2. 系数最大：设第 $r+1$ 项系数 $f(r)$，列 $f(r)\ge f(r+1)$ 且 $f(r)\ge f(r-1)$，解出 $r$ 取整。
3. 含负号或参数先定符号，再比绝对值。
4. 两类同时出现时分别计算。
**易错**：把二项式系数与系数当同一量；只用一个不等式只能定单调性。

### M22 · 赋值法与系数和
**触发**：各项系数和、奇偶项系数和、系数绝对值之和。
**步骤**：
1. 令 $x=1$ 得系数和；令 $x=-1$ 得交错和；两式加减后除以 2 得偶次项、奇次项和。
2. 系数绝对值之和令 $x=-1$（变号时），或对两式取平均。
3. 二项式系数和恒为 $2^n$，奇数项与偶数项各为 $2^{n-1}$。
4. 「除某项外系数和」用总和减该项系数。
**易错**：二项式系数和与系数和混用；只赋 $x=1$ 求奇偶项和。

### M23 · 整除与余数
**触发**：$a^n$ 除以 $m$ 的余数、被某数整除求参数、星期问题。
**步骤**：
1. 把底数写成「$m$ 的倍数 $\pm1$」，展开后只留低次项，余数由末项符号定。
2. 底数较大时先用 $a\bmod m$ 替换底数，再交替「化底数、降指数」。
3. 被 $m$ 整除求参数：令常数项与参数之和为 $m$ 的倍数，区间内取值。
4. 余数须落在 $[0,m)$，负余数加 $m$ 调整。
**易错**：$(-1)^k$ 符号丢失；只化底数不降指数。

### M24 · 组合恒等式与杨辉三角
**触发**：证明 $\sum\binom nk=2^n$、平方和恒等式、含 $k$ 加权求和。
**步骤**：
1. 算两次：比较 $(1+x)^{m+n}$ 与 $(1+x)^m(1+x)^n$ 同次幂系数。
2. 平方和型比较 $(1+x)^n(1+x)^n$ 与 $(1+x)^{2n}$ 的展开。
3. 含 $k$、$k^2$ 加权：对 $(1+x)^n$ 求导，必要时乘 $x$ 再求导，最后令 $x=1$。
4. 倒序求和拆成相邻组合数之差裂项；杨辉三角第 $n$ 行第 $i$ 个数为 $\binom{n}{i-1}$，行和为 $2^n$。
**易错**：比较的不是同一幂次；求导次数与权不对应。

### M25 · 推理与证明
**触发**：归纳猜想、存在性／唯一性／否定式命题、与正整数 $n$ 有关的命题。
**步骤**：
1. 归纳：列表比较随 $n$ 变化的量，猜出通项，代前几项验证后写结论。
2. 反证法：反设 → 由假设与已知推出矛盾 → 结论成立。
3. 数学归纳法：验证初始值 → 假设 $n=k$ 推 $n=k+1$ → 结论。
4. 图形类先数每个图新增元素，找增量与 $n$ 的关系。
**易错**：归纳结论不验证前几项；归纳第二步未用归纳假设。
