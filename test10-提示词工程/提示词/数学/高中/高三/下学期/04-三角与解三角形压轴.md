## 一、识别特征

**属于本主题的信号**
- 三角形内出现**分角线、中线、高线**（$AD$ 平分 $\angle A$、$AD$ 为中线、$AD\perp BC$），且问其中一条线段的长度或与它相关的最值
- 已知一边及其对角，问**周长、面积、$b+c$、$|b-c|$、$\dfrac bc$ 的范围或最值**
- 多个三角形**拼接**：四边形连对角线、两个三角形共用一边或共用一个角，需「算两次」
- 等式呈**齐次结构**（全是边或全是 $\sin$），需在「边化角 / 角化边」之间取舍；出现 $a\cos B+b\cos A$、$\sin^2A+\sin^2B-\sin^2C$
- 选填给 $f(x)=A\sin(\omega x+\varphi)$ 的单调区间、对称轴、零点个数，反求 $\boldsymbol{\omega}$ 的范围
- 条件里出现「$\tan$ 恒等式」「和差化积 / 积化和差」「万能公式」

## 三、方法卡

### M01 · 解三角形结论群（张角、角平分线、中线、射影）
**触发**：三角形内出现分角线、中线、高线，求其长度或由它建立关系。
**步骤**：
1. 角平分线 $AD$ 分 $\angle A$：用张角定理 $\dfrac{\sin\angle BAD}{AC}+\dfrac{\sin\angle CAD}{AB}=\dfrac{\sin A}{AD}$；先用角平分线定理定 $BD:DC=AB:AC$。
2. 中线 $AD$：用中线定理 $4AD^2=2AB^2+2AC^2-BC^2$。
3. 见到 $a\cos B+b\cos A$ 型用射影定理 $=c$；正切恒等式、和差化积/积化和差、万能公式与对偶式用于化简含角条件。
**易错**：定理适用条件先核对——点是否在三角形边上或内部；角的范围（如 $\angle BAD<\dfrac\pi2$）会限制张角公式的使用。

### M02 · 边角互化：选正弦还是余弦
**触发**：等式全是边或全是 $\sin$，需统一后求解；出现平方型结构或 $a\cos B+b\cos A$。
**步骤**：
1. 见到 $a^2+b^2-c^2$ 型 → 余弦定理；见到 $\sin^2A+\sin^2B-\sin^2C$ 型 → 先用正弦定理统一成边，再用余弦定理。
2. 见到 $a\cos B+b\cos A$ → 射影定理 $=c$，或化边后用余弦定理展开。
3. 先检查等式是否**齐次**：关于边或正弦齐次时才能边化角/角化边。
4. 双正弦、双余弦结构（$\dfrac{\sin A}{\sin B}=\dfrac ab$、$2\cos A\cos B$）先统一角度，再用和差化积。
**易错**：非齐次等式不能直接边角互化；角化边后要检查是否引入增根。

### M03 · 周长、面积与边长和差的最值
**触发**：已知一角及对边（如已知 $A$ 与 $a$），求面积、周长、$b+c$、$|b-c|$、$\dfrac bc$ 的范围。
**步骤**：
1. 已知 $A,a$：由 $a^2=b^2+c^2-2bc\cos A$ 得 $bc$ 的上界（基本不等式），进而面积 $S=\dfrac12bc\sin A$ 与周长 $a+b+c$ 的上界。
2. 求 $b+c$ 范围：正弦定理化 $b+c=2R(\sin B+\sin C)$，用 $B+C=\pi-A$ 化为单一角的三角函数求值域。
3. 求 $|b-c|$ 或 $\dfrac bc$：同样化角，注意角的取值范围。
4. 题设「锐角三角形」：转化为对 $B,C\in\left(0,\dfrac\pi2\right)$ 的不等式，先界定角的范围再求最值。
**易错**：基本不等式取等条件与「锐角三角形」等附加条件可能冲突，须回代检验；只在把角范围写好之后才能取最值。

### M04 · 图形类解三角形（多三角形拼接）
**触发**：多个三角形拼接（四边形连对角线、两三角形共边或共角）。
**步骤**：
1. 先在可解的三角形中求出公共边 / 公共角，再进入相邻三角形。
2. 公共边用两次余弦定理建立方程（「算两次」）。
3. 出现角平分线、中线、高线时优先用对应定理（M01）。
4. 四边形问题连对角线，拆成两个三角形分别处理。
**易错**：图形中角的和差关系（如 $\angle BAD+\angle CAD=A$）容易写错；公共边要对齐同一顶点。

### M05 · 三角函数选填：$\omega$ 的取值范围
**触发**：给 $f(x)=A\sin(\omega x+\varphi)$ 的单调区间、对称轴/中心、零点个数，求 $\omega$ 的范围或最值。
**步骤**：
1. 把单调区间 / 对称轴 / 零点条件写成关于 $\omega$ 的不等式组。
2. 已知区间长度时，用「区间长度 $\le$ 半周期 / 整周期」限定 $\omega$。
3. 求 $\omega$ 的最大值或最小值：先写出通解，再取满足条件的整数 $k$。
**易错**：$\omega>0$ 的前提；对称中心与对称轴的通解相差 $\dfrac T4$，不要混用。
