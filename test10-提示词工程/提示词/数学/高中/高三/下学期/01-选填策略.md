## 一、识别特征

**属于本主题的信号**
- 题干为单选、多选或填空，答案是一个值、一组范围或一个选项，不要求写推理过程
- 结论是「定值 / 最值 / 范围 / 恒成立」，而条件里含不确定量（某点任意、$n$ 任意、三角形形状未定）
- 出现年份数或「求第 $n$ 项相关量」，选项本身也写成含 $n$ 的形式，需比较通式
- 给出解析式后问「对应图象是」，需判断 $x\to0$、$x\to\pm\infty$ 的行为或渐近线
- 出现取整符号 $[x]$、$\max/\min$、$|x-a|$ 型折线、两条平行夹线夹住一段曲线
- 参数在曲线族中变化，问参数范围或「最小值中的最大值 / 最大值中的最小值」
- 计数型设问「至少 / 至多 / 与某集合有公共元素」，正面分类繁而反面情形单一

**容易误投的信号（改去对应主题）**
- 明确要求写出完整证明、有过程分（如「求证」「讨论并证明」）→ 按背景改去 02-函数与导数压轴 / 06-数列压轴 / 08-圆锥曲线压轴
- 主体是联立直线与圆锥曲线、韦达、定点定值 → 08-圆锥曲线压轴
- 主体是通项构造、数列求和与放缩 → 06-数列压轴
- 主体是线面角、二面角、体积、外接球 → 05-向量与立体几何
- 主体是分布列、条件概率、回归与独立性检验 → 07-概率统计

## 三、方法卡

### M01 · 特殊值/特殊位置/特殊函数
**触发**：结论对任意满足条件的对象都应成立的选填题。
**步骤**：
1. 取最简单对象：数列令 $a_n=x$ 或只取 $n=1,2$；一般三角形换正三角形；任一点换顶点或中点。
2. 代入算出一个具体值，与选项比对；两个特殊值仍区分不开时换第三个。
**易错**：只适用于选择、填空；解答题不能用（原文标注「具有风险性」）；特殊值只能排除，不能当作最终证明。

### M02 · 选项分析与年份题
**触发**：求前 $n$ 项相关量的通式；题面含年份数；选项写成含 $n$ 的表达式。
**步骤**：
1. 令 $n=$ 题中年份，把四个选项也改写成 $n$ 的形式后比较。
2. 数列选填先用 $a_1,a_2$ 检验选项，两项定不了再加 $S_2$。
3. 定值型可把选项逐个代回原条件检验。
**易错**：只代一个年份可能撞上巧合；代回时要用原题的完整条件，不能只验一半。

### M03 · 函数图象判断（四步排除）
**触发**：给出解析式，问「大致图象是」。
**步骤**：
1. 奇偶性：不对称于 $y$ 轴/原点的图象直接排除。
2. 特值：算 $x=0$、$x=1$、$x\to0^{+}$ 处的函数值符号与大小。
3. 极限：$x\to\pm\infty$ 时的增长阶（指数 > 多项式 > 对数）与 $x\to0$ 时的发散方向。
4. 渐近线、零点个数、单调性，逐项排除到只剩一个。
**易错**：只凭一个特征就选；忘记定义域（如 $\ln x$ 只在 $x>0$ 有图）。

### M04 · 高斯函数（取整函数）的性质与分段列举
**触发**：题面出现 $[x]$、「不超过 $x$ 的最大整数」。
**步骤**：
1. 套基本性质：$[n+x]=n+[x]$；$[x]\le x<[x]+1$；$[x]+[y]\le[x+y]\le[x]+[y]+1$；$[nx]\ge n[x]$。
2. 求和型：把每项写成「常数 − 正小数」，用上下界把每项夹成同一个常数，项数 × 常数即和。
3. 方程组型：令两个取整值相等解出一个范围，再由另一式确定目标范围。
4. 方程型：设取整部分为整数 $m$，用 $[m,m+1)$ 夹出候选整数，再逐个回代检验。
5. 含根号与取整：把整条根式设为新变量 $t$（平方还原），化为一元二次方程再解。
6. 求 $[x]+[y]+\cdots$ 的值域：按自变量分段，逐段列出取整值取并集。
**易错**：取整与乘除不能交换，$[nx]\ge n[x]$ 只是单侧不等式；夹出的整数候选必须逐一代回原方程。

### M05 · 最值函数基本定理
**触发**：题面出现 $\max\{a,b\}$、$\min\{a,b\}$、$\max|f(x)-b|$ 型最值。
**步骤**：
1. 两数比较：$\dfrac{a+b}{2}\le\max\{a,b\}$，$\min\{a,b\}\le\sqrt{ab}\le\max\{a,b\}$（$a,b$ 同号时 $\min,\max$ 分别是差、和的一半）。
2. $\max\{|x-a|,|x-b|\}$ 的最小值：$\max\ge$ 两者之和的一半，再用三角不等式得差为常数，最小值为 $\dfrac{|b-a|}{2}$。
3. 两向量和的模、差的模的平方取 max：$\max\ge$ 两者之和的一半 $=|\vec a|^2+|\vec b|^2$。
4. 多分量取 max（如 $\max\{b-a,c-b,1-c\}$）：用加权和 $\le M\times$ 权重和得下界，再由条件补第二个下界，取较大者并给出等号配置。
5. 对任意 $b$ 求 $\max|f(x)-b|$ 的最小值 $=\dfrac{\max f-\min f}{2}$，在区间中点取得。
**易错**：$\min\{a,b\}\le\sqrt{ab}$ 只在 $a,b\ge0$ 时成立；由加权平均得下界后要回到「$M$ 是各分量最大值」这一前提。

### M06 · 临界状态法
**触发**：含参求范围或最值，疑有相切、重合、端点相碰的临界。
**步骤**：
1. 先自问「有没有临界状态」：几何中为端点重合、两点重合、相切；代数中为曲线族随参数单调升降的两端。
2. 把参数 $a$ 提出后若剩余部分符号确定，即可判定曲线族随 $a$ 升降，最值只在参数区间两端取得。
3. 求「最小值中的最大值 / 最大值中的最小值」：先求内层 $m(a)$，再对 $m(a)$ 求最值。
**易错**：判定不了升降方向时回归求导；端点值要单独验证能否取到，区间开闭先看清。

### M07 · 绝对值折线与曲线相切的临界
**触发**：含 $|2x-a|$ 一类的不等式恒成立，求参数范围。
**步骤**：
1. 把绝对值看成顶点在 $\left(\dfrac a2,0\right)$ 的 V 形折线，另一侧画曲线。
2. 参数变化时折线平移，临界只有三种：左支射线与曲线相切、右支射线相切、折线顶点落在曲线的端点或分段点。
3. 每个临界列「函数值相等 + 导数相等」求参数，由这些临界值夹出范围。
**易错**：只算一支相切会漏另一支；顶点落在分段点常是第三个临界；相切解出的参数须回代检查切点在对应区间内。

### M08 · 平移不等式的零点距离判据
**触发**：$\forall x,\ f(x-m)\le f(x)$，求参数。
**步骤**：
1. 画 $f(x)$，把平移量 $m$ 理解为「图象上任意点与其左移 $m$ 后点的函数值比较」。
2. 多零点时只需最远的两个零点 $x_1,x_2$ 满足 $|x_1-x_2|\le m$，即平移量不小于最大零点间距。
3. 参数藏在零点里：先解出零点间距关于参数的表达式，再解不等式。
4. 奇函数或轴对称函数可先化为「到对称轴的距离」比较，再套同一判据。
**易错**：$m$ 须为正才可理解为右移量，符号反了会得到相反范围；最远零点对不一定在区间端点。

### M09 · 平口单峰的待定系数构造
**触发**：求 $|f(x)-kx-b|$ 在区间上最大值的最小值；或 $|f(x)-b|$ 型。
**步骤**：
1. 先把 $f$ 化成平口单峰函数（两端值相等、区间内唯一极值点），此时最小值等于两条平行夹线铅锤距离的一半。
2. 不是平口时待定系数构造：设 $g(x)=f(x)+px$，令 $f(m)+pm=f(n)+pn$ 解出 $p$，再检验区间内是否唯一极值点。
3. 客观题直接用「两平行线夹曲线，距离一半」；解答题取夹线与曲线的关键点代入 $g(x)\le M$，用绝对值不等式推 $M$ 的下界。
4. $|f(x)-b|$ 型（无斜率项）：最小值为 $\dfrac{\max f-\min f}{2}$。
**易错**：构造出的函数不一定平口单峰，必须检验「唯一极值点」；定理只适用于客观题，解答题须写出关键点控制的不等式推导。

### M10 · 选择题常用策略
**触发**：选择题，四种方法都未立即见效时。
**步骤**：
1. 规则题直接算；求定值/范围且含不确定量 → 特殊值、特殊函数、特殊数列、特殊位置、特殊模型。
2. 选项代回原条件验证（线性规划最优解、含参不等式尤其快）。
3. 有几何背景先画图判形（两圆公切线条数看两圆位置关系）。
4. 捕捉隐含信息（定点、过定点的直线、特殊数据）少算；按量级估算缩小选项；由选项特征反推（只有一项含分数/特殊值常是提示）。
**易错**：把「过点 $A$ 的切线」当「在 $A$ 处的切线」；定义域/值域混淆；两直线垂直未讨论斜率不存在。

### M11 · 填空题解法与七种检验
**触发**：填空题，尤其填性质、填范围。
**步骤**：
1. 定量型按定义/公式直接算；定性型在多选项中取特殊模型验证。
2. 含不确定量而结论为定值 → 特殊角、特殊数列、特殊模型；几何背景画图直读；不等式解集转两图象关系。
3. 构造辅助对象（正方体、长方体、圆）把问题放进规则模型。
4. 七种检验：回顾（约束区间、集合形式）、赋值（无限结论代 $n=1$）、逆代（有限答案代回）、估算、作图、变法（换法重算）、极端（端点验证）。
**易错**：由 $S_n$ 求 $a_n$ 时 $n=1$ 要单独验证；二次不等式解集为空集时漏掉二次项系数为 $0$ 的情形。

### M12 · 验证法：必要条件筛选项再代入确认
**触发**：选项由整除性、位数、图形位置、勾股数等条件能大面积排除。
**步骤**：
1. 从题设找出答案必须满足的必要条件，排除明显不符的选项。
2. 对剩下少数选项逐个代入原题验证，通过者即为答案。
3. 几何/数列题可先画草图估计（如面积平分线的位置），再对估计值做精确检验；也可先猜想（如直角三角形）后用另一组数据验证。
**易错**：把必要条件当充分条件，未验证就选；只验证一个选项成立就停，未确认其他选项确实不成立。

### M13 · 排除法：从全集扣掉不合条件的情形
**触发**：「至少 / 至多 / 与某集合有公共元素」的计数或图象选择。
**步骤**：
1. 计数型：先算满足主要限制的总数，再减去只违反次要限制的数目。
2. 集合型：求「$A\cup B$ 中取若干元素且与 $A$ 有公共元素」的个数，用总数减「与 $A$ 无公共元素」的个数。
3. 图象型：由解析式定出必过点、开口方向、系数同号等特征，逐项排除。
**易错**：扣除的情形有交叉重叠（减多了）；扣除的情形有遗漏（减少了）。只在「不合情形单一易数」时用排除法，否则仍用分类。
