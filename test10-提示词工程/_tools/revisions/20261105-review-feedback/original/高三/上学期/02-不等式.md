## 一、识别特征

**属于本主题的信号**
- $a+b$、$ab$、$a^2+b^2$ 中两者互求最值；$\frac1x+\frac1y$、$\frac{a^2}{x}+\frac{b^2}{y}$ 型分式和
- 条件带 $x>0$、$a,b>0$；问「最小值为」「取值范围」；出现 $ax+by=k$、$ab+2a-2=0$、$ax+by+cxy=d$ 约束
- 「恒成立」「有解」「对任意 $x\in D$」；参数在系数、指数底数或常数位置
- 含参一元二次不等式、解集为区间、根分布在某区间；求 $|x-a|+|x-b|$ 最小值
- 线性约束下求 $z=ax+by$；证明 $\sum\frac{a^2}{b}\ge\sum a$ 一类不等式

**容易误投的信号（改去对应主题）**
- 只考零点、单调性、极值，无不等式约束 → 01-函数与导数
- $e^x$、$\ln x$ 切线放缩、同构构造 → 01-函数与导数
- 以「充分不必要」「量词否定」「$A\subseteq B$」为主 → 09-集合逻辑与计数原理
- 三角恒等变形、解三角形边角 → 03-三角函数与解三角形
- $\vec a\cdot\vec b$、$|\vec a+\vec b|$ 模最值 → 04-平面向量与复数

## 三、方法卡

### M01 · 基本不等式链与和积平方和互化
**触发**：和定求积、积定求和，或 $a+b$、$ab$、$a^2+b^2$ 互求。
**步骤**：
1. 先验「一正二定三相等」。
2. 按所求方向用 $a^2+b^2\ge\frac{(a+b)^2}{2}$、$ab\le\frac{(a+b)^2}{4}$、$a+b\ge2\sqrt{ab}$。
3. $m(a+b)+nab=c$：求 $ab$ 用 $a+b\ge2\sqrt{ab}$；求 $a+b$ 用 $ab\le\frac{(a+b)^2}{4}$，化为单变量二次不等式。
4. 求 $ma+nb$：因式分解为 $(a+x)(b+y)=z$，再对两因子用和积关系。
5. 条件含 $ax+by$ 与 $xy$：用 $ax+by\ge2\sqrt{ab\cdot xy}$ 搭桥，整体换元后解二次不等式。
**易错**：代换方向写反得反向不等式；变量为负不能直接用。

### M02 · 配凑法（配项、配系数、分离常数）
**触发**：无现成和定/积定，结构接近公式。
**步骤**：
1. 配项：$x+\frac1{x+1}=(x+1)+\frac1{x+1}-1$。
2. 配系数：$x(a-bx)=\frac1b\cdot bx(a-bx)$。
3. 分子分母都含自变量：先多项式除法，化成「常数 + 真分式」。
4. 变量为负先取相反数或换元。
5. 分子可因式分解的复杂分式先分解，再对两项放缩。
**易错**：配系数改变式值却不补乘除；分离常数时符号或余数算错。

### M03 · 乘「1」法
**触发**：已知 $ax+by=k$ 求分式和，或目标可拆成两分母之和。
**步骤**：
1. 用条件构造 $1=\frac{ax+by}{k}$，乘到目标式展开，得两正项放缩。
2. $ax+by=cxy$：两边同除 $xy$，化成倒数和为常数再乘 1。
3. 条件已含 1（如 $\frac1{a+1}+\frac1{b+1}=1$）：乘 1 并把 $a+b$ 写成 $(a+1)+(b+1)-2$。
4. 构造不明时待定系数：$x+y=a(3x+y)+b(x+2y)$ 比较系数。
**易错**：「1」不由条件整体构造则无法约简；待定出负系数不满足一正。

### M04 · 消元法与整体换元（因式分解）
**触发**：$ax+by+cxy=d$ 或 $ax^2+by^2+cxy=d$，求一次式或乘积。
**步骤**：
1. 一次型解出 $y=\frac{d-ax}{b+cx}$ 代入，分离常数后配项。
2. 或分解为 $(px+q)(sy+t)=r$，让目标恰为两因子之和。
3. 二次型十字分解为 $(mx+ny)(px+qy)=d$，令 $w,z$ 为该两因子，$wz=d$。
4. 反解 $x,y$ 代入目标，用 $w,z$ 的和积结构放缩。
5. 求 $xy$：由 $d\ge2\sqrt{ab\cdot xy}+cxy$，令 $t=\sqrt{xy}$ 解二次不等式。
**易错**：条件含一次项不能套二次型分解；解出的 $x,y$ 须回原约束检验。

### M05 · 分式型最值的标准模型
**触发**：目标为分式求最值。
**步骤**：
1. 分母一次且分子为其一次式加常数：令分母为 $t$。
2. 分母含 $x-a$：令 $t=x-a$，化为 $mt+\frac nt$，按 $t$ 符号选基本不等式或对勾单调性。
3. $\frac{x}{ax^2+bx+c}$（$a,c>0$）：同除 $x$，先求分母最小再取倒数。
4. 两分式之和、分母为不同一次式：双换元。
5. 分子分母同次：齐次化后化为单变量。
**易错**：取倒数前确认分母恒正；$x(n-mx)$ 型须 $0<x<\frac nm$。

### M06 · 双换元（分母整体换元）
**触发**：分子、分母由同一组线性组合构成。
**步骤**：
1. 两个线性组合整体设为 $a,b$，不展开。
2. 反解 $x,y$ 代入目标。
3. 出现互反项 $\frac ab+\frac ba$，用基本不等式得下界。
4. 新变量符号由原范围导出；取等 $a=b$ 反解回 $x,y$ 验证。
**易错**：新变量范围未导出使取等点落在可行域外；反解系数漏写使结构不对。

### M07 · 齐次化与比值换元
**触发**：分子分母同次，或条件 $a+b=1$ 等定值。
**步骤**：
1. 分子分母同除某一量，化为只含 $t=\frac ab$ 的式子。
2. 或先齐次化目标再整体换元。
3. 由条件写出 $t$ 的范围。
4. 化为 $t+\frac kt$ 后判断区间上的单调性，取端点而非盲目用 $2\sqrt k$。
**易错**：非同次除后不是单变量；漏写 $t$ 的范围。

### M08 · 权方和不等式
**触发**：分式和最值，分母相加为定值。
**步骤**：
1. 「分子先和再方，分母直接相加」：$\frac{a^2}{x}+\frac{b^2}{y}\ge\frac{(a+b)^2}{x+y}$，取等 $\frac ax=\frac by$。
2. 系数不一致时先乘除系数配平。
3. 分子比分母多一次幂：用 $\sum\frac{x_i^{m+1}}{y_i^m}\ge\frac{(\sum x_i)^{m+1}}{(\sum y_i)^m}$。
4. 三角版：用 $\sin^2\theta+\cos^2\theta=1$ 作定值分母和。
**易错**：幂次差不等于 1 不能直接套；分母和不是定值则失效。

### M09 · 柯西不等式配凑
**触发**：给平方和求一次式；分式和、根式和需配成和定因式。
**步骤**：
1. 把两项配成和等于定值的因式，对两组因式用柯西。
2. 根式和用 $\sqrt{xz}+\sqrt{yw}\le\sqrt{(x+y)(z+w)}$，配对使因式之和为定值。
3. 给 $(x-a)^2+(y-b)^2=r^2$ 求线性式：写成两向量内积直接套柯西。
4. 取等为对应项成比例，解出后代回原条件验证。
**易错**：配出的因式之和不是定值无法化简；取等无解时所得界不是最值。

### M10 · 待定系数法配凑系数
**触发**：结构与均值或柯西接近，系数对不上。
**步骤**：
1. 引入待定正参数改写目标。
2. 用取等条件（各项相等或成比例）列方程。
3. 解参数，用「各项为正」筛增根。
4. 要求放缩结果为定值，可再列一方程。
**易错**：设参后不验证取等；放缩后仍含变量却当成定值。

### M11 · 糖水不等式
**触发**：比较 $\frac ba$ 与 $\frac{b+m}{a+m}$，或分数大小快速判定。
**步骤**：
1. $0<b<a$、$m>0$ 时 $\frac ba<\frac{b+m}{a+m}$。
2. 可多次迭代；比较 $\frac{a+m}{b+m}$ 型分数同样适用。
3. 与作差法互检方向。
**易错**：只对真分数成立；迭代每步须同向。

### M12 · 排序不等式
**触发**：两组数搭配求和、对称或轮换对称不等式。
**步骤**：
1. 先定两组数各自的大小顺序。
2. 反序和 ≤ 乱序和 ≤ 顺序和。
3. 完全对称可设全部顺序；轮换对称只设最大者或最小者。
4. 非对称时先把一组重排再比较。
5. 取等：至少一组数全相等。
**易错**：未定序就套用；顺序和与反序和认反。

### M13 · 绝对值不等式（距离和最小）
**触发**：$\sum|x-a_i|$ 最小值、$|a|\pm|b|$ 放缩。
**步骤**：
1. $||a|-|b||\le|a\pm b|\le|a|+|b|$；$|x-a|+|x-b|\ge|a-b|$，等号在 $x$ 介于 $a,b$。
2. 多项按「最小配最大」首尾配对，逐对放缩后相加。
3. 找各对取等区间的公共部分；奇数点取中位数，偶数点在中间两点区间任取。
4. 系数可拆成重复项再配对；系数非正改用折线顶点比较。
**易错**：取等区间无公共部分仍相加；解答题不能只写中位数结论。

### M14 · 比较法（作差 / 作商）
**触发**：比较两式大小；数列最大项、分布列最大概率。
**步骤**：
1. 作差：作差 → 通分/因式分解/配方 → 判断符号。
2. 作商：限于同号两式，作商 → 变形 → 与 1 比较。
3. 数列单调：算相邻项之差定增减区间，转折处为最大项。
4. 组合数比值：相邻项作商约分后只比简单分式与 1。
**易错**：作商只能用于同号两式；变形须等价且彻底。

### M15 · 连续使用基本不等式
**触发**：多元目标，各变量独立无约束。
**步骤**：
1. 对每项单独放缩。
2. 每步写出取等条件。
3. 联立检查能否同时成立。
4. 一致才可下最值结论；矛盾则改用他法。
**易错**：只看单步取等；变量间有约束仍当独立处理。

### M16 · 对称换元与和积换元
**触发**：条件与目标均关于两变量对称。
**步骤**：
1. 设 $a=P+t$、$b=P-t$，或设 $s=a+b$、$p=ab$，用条件消元。
2. 化为只含 $p$（或 $t^2$）的一元函数。
3. 由 $(a-b)^2\ge0$ 与 $a,b>0$ 定 $p$ 的上下界。
4. $p+\frac kp$ 型在受限区间按单调性取端点。
**易错**：$p$ 只写 $p>0$，漏掉上界。

### M17 · 局部固定法（逐步调整）
**触发**：一组变量受约束，另一变量独立受约束。
**步骤**：
1. 固定独立变量，对受约束组求局部最小值。
2. 通分化简为互反项放缩。
3. 释放被固定变量（如 $t=c-k>0$），再次求值。
4. 联立两次取等解出各变量并验证。
**易错**：两次取等互不相容；固定错变量致无法化为单变量。

### M18 · 恒成立与存在性的转化
**触发**：「恒成立」「有解」求参数。
**步骤**：
1. $\forall x,f(x)\ge a\iff a\le f_{\min}$；$\exists x,f(x)\ge a\iff a\le f_{\max}$。
2. 双区间：$f(x_1)\ge g(x_2)$ 对任意成立 $\iff f_{\min}\ge g_{\max}$。
3. 能分离优先分离，注意除数符号。
4. 不可分离则构造 $f(x)-a$ 求最值。
5. 参数为一次式时以参数为主元，只验两端点值。
6. 二次型在 $\mathbb R$ 上恒正需 $a>0,\Delta<0$，$a=0$ 单验。
**易错**：恒成立与有解的最值端记反；给定区间不能用判别式；漏 $x$ 范围与端点开闭。

### M19 · 含参一元二次不等式与根的分布
**触发**：含参二次不等式、解集为区间、根在某区间。
**步骤**：
1. 不含参：求根标数轴，结合开口写解集。
2. 含参按系数正负、判别式、两根大小分层讨论。
3. 已知解集端点用韦达；解集为 $\{x\mid x\ne d\}$ 时 $\Delta=0$，$a^2=4b$。
4. 根分布同时看开口、判别式、对称轴、端点函数值符号。
5. 倒序不等式 $cx^2+bx+a$：根为原端点的倒数。
**易错**：看清谁是参数；给定区间恒成立不能用 $\Delta$。

### M20 · 无理不等式四法
**触发**：含 $\sqrt{\cdot}$ 的不等式或最值。
**步骤**：
1. 按右边 $<0$ 与 $\ge0$ 分两类，后者平方，条件取并。
2. 或设整个根式为 $y$，先解 $y$ 范围。
3. 或画根式函数与一次函数求交点分界。
4. 以端点和交点分段，逐段试值定符号。
**易错**：平方前不讨论右边符号产生增解；换元后须翻译回 $x$ 范围。

### M21 · 二元一次不等式组与线性规划
**触发**：线性约束求 $z=ax+by$。
**步骤**：
1. 画可行域：边界不过原点用原点判侧，否则取特殊点；$\ge,\le$ 实线，$>,<$ 虚线。
2. 求顶点坐标。
3. $y=-\frac abx+\frac zb$，把 $z$ 转为截距。
4. 平移直线，最优解在顶点或边界线段。
**易错**：$b<0$ 时截距最大对应 $z$ 最小；不封闭区域的解可能在边界。

### M22 · 等高线法
**触发**：目标为曲线族，与约束相切取最值。
**步骤**：
1. 画不同参数下的等高线。
2. 单独画约束条件。
3. 最值在相切处或边界顶点。
4. 切点由联立后 $\Delta=0$ 或圆心距 = 半径求得。
**易错**：忽略约束范围使切点落在之外；线性目标还须比较顶点值。

### M23 · 多变量范围用待定系数整体表示
**触发**：给若干组合式范围求另一组合式范围。
**步骤**：
1. 不分别求各变量范围再拼接。
2. 设目标式 = 已知组合式的线性组合，比较系数。
3. 同向相加；系数为负先取反向。
4. 积或商范围先取对数再用待定系数。
**易错**：拆分条件扩大范围；相加不同向。

### M24 · 不等式证明：逐项放缩与化归
**触发**：证明轮换式、分式和、结构复杂的不等式。
**步骤**：
1. 分式轮换：每项用 $\frac{a^2}{b}+b\ge2a$，逐项相加相消。
2. 三项取等为 $a=b=c$；「不全相等」时只能写严格不等号。
3. 次数不齐：两端配项，每三项凑积定值用三元均值。
4. 底数为正整数时可把幂拆成连加。
5. 复杂式子用变更问题法逐步等价化归到显然不等式。
**易错**：非整数底数不能拆幂；平方、去分母须补条件。
