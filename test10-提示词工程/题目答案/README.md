# 题目答案库 · 说明

与 `提示词/` 同级，目录结构镜像提示词库，只放从题库原始资料中抽出的题目与答案。

## 一、目录结构

```
题目答案/数学/初中/<年级>/<学期>/NN-主题/
    题目.md
    答案.md
题目答案/数学/高中/<年级>/<学期>/NN-主题/
    题目.md
    答案.md
```

- 主题目录名与 `数学/` 下的解题思路目录一致。
- 每个主题固定一对文件；不按题拆文件，避免文件数量失控。
- `题目.md` 只有题干；`答案.md` 只有答案、解析与出处，题号一一对应。

## 二、题号

同一主题内从 `Q01` 连续编号；`题目.md` 与 `答案.md` 使用同一编号。原书题号（例 3、变式 2-1）写在题干前的括注里，便于回查。

## 三、题目.md 格式

```markdown
# <主题> · 题目

> 年级/学期：<年级>/<学期>
> 题量：N
> 答案：同目录 `答案.md`

## 一、<分组名>

### Q01
（原题 例1）题干文字……

### Q02
……
```

- 按原书章节或题型分组，组名用原文标题。
- 题干保留选项；多小问保留 (1)(2)。
- 图形无法转写时写「（图见出处）」并在答案文件给出出处页段，不凭想象补图。
- OCR 明显错字可按题意校正；公式拿不准时保留 OCR 原文并标「OCR 原文」。

## 四、答案.md 格式

```markdown
# <主题> · 答案

> 与同目录 `题目.md` 一一对应。

## 一、<分组名>

### Q01
**答案**：……
**解析**：……
**出处**：`题库/……`（OCR 第 a—b 页）
```

- `答案` 只给最终结果；多小问逐问列出。
- `解析` 写关键步骤与依据，不写与本题无关的方法。
- `出处` 必须是题库中真实存在的文件，统一写成 `` `题库/<…>.<pdf|docx>`（OCR 第 N 页） `` 或 `` （OCR 第 a—b 页） ``，「第」与页号之间留一个空格；docx 无页段时写「（docx 文字层）」。
- 学生版 / 教师版成对时：题目出处写学生版，答案出处写教师版，可写两行「题目 `…（学生版）.docx`（docx 文字层）；答案 `…（教师版）.docx`（docx 文字层）」。
- 无法确认答案的题不收录。

## 五、质量底线

- 只收能从原始资料核对到答案的题；OCR 残缺且无法还原的不收。
- 不补造条件、图形、数值；缺条件时在题干标「（OCR 不清）」。
- 同一主题内不重复收录同一道题。
- 题目与答案数量必须相等，编号必须一一对应。
