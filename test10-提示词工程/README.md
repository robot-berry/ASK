# 学科解题提示词工程

按「学科 → 学段 → 年级 → 学期」组织的解题提示词（Prompt）库。
同一目录下也存放该阶段对应的题库、知识点与教材参考资料，用于编写和验证提示词。

## 目录结构

```
test10-提示词工程/
├── 题库/                 # 原始题库资料（目前为数学资料，后续补充物理）
├── 数学/
│   ├── 初中/
│   │   ├── 八年级/
│   │   │   ├── 上学期/
│   │   │   └── 下学期/
│   │   └── 九年级/
│   │       ├── 上学期/
│   │       └── 下学期/
│   └── 高中/
│       ├── 高一/  (上学期 / 下学期)
│       ├── 高二/  (上学期 / 下学期)
│       ├── 高三/  (上学期 / 下学期)
│       ├── 来源索引.md      # 每学期内容对应题库中的哪些文件
│       └── 提取进度.md / .html  # 题库提取进度面板（HTML 可视化）
├── _tools/               # 提取脚本（docx 解析、切分、OCR、进度统计）
└── 物理/
    └── 结构同数学/
```

每个「学期」目录下按**知识主题**分文件夹，而不是把整学期的内容堆在一个文件里：

```
高一/上学期/
├── 01-集合与逻辑/
│   ├── 第1章 集合与常用逻辑用语.md   # 知识点
│   └── 解题思路.md                   # 该主题的解法，顶部列出题库出处
├── 02-一元二次函数方程与不等式/
├── ...
└── _学期总览/                        # 整学期合并版，便于通读
    ├── 知识点清单（全）.md
    └── 解题思路（全）.md
```

> 初中从八年级开始：人教版物理八年级上册才开设，物理从八年级起编，数学也为保持两科结构一致从八年级开始。
> 七年级数学如需要，可自行在 `数学/初中/` 下新增 `七年级/`。

## 学期目录内的文件约定

每个「年级/学期」目录建议包含：

| 位置 | 说明 |
| --- | --- |
| `<主题>/知识点清单或章节名>.md` | 该主题覆盖的知识点 / 章节范围 |
| `<主题>/解题思路.md` | 该主题的解题方法与套路，首行起为「依据（题库出处）」 |
| `提示词.md` | （待编写）该学期的主解题提示词（System Prompt 正文） |
| `题型索引.md` | （待编写）常见题型与对应解题方法的索引 |
| `示例.md`（可选） | 输入输出示例、Few-shot 样例 |
| `_学期总览/` | 整个学期的合并版知识点与思路 |

## 题库出处与公式说明

- 每个 `解题思路.md` 顶部列出所依据的 `题库/` 文件（相对路径精确到文件）。找不到可对应的题库文件时，条目只在 `_学期总览/` 中保留，不强行挂靠。
- docx 中的公式多为 MathType OLE 对象（`Equation.KSEE3`），纯文本提取时会丢失；OCR 对印刷体公式也不可靠。因此 [知识点清单] / [解题思路] 中的公式按课程标准补全，方法名称、适用条件与易错点保留原文表述。
- 提取进度见 [数学/高中/提取进度.html](数学/高中/提取进度.html)（浏览器打开），进度数据由 `_tools/progress_scan.py` → `_tools/build_progress.py` 生成。

## 提取工具

| 脚本 | 作用 |
| --- | --- |
| `_tools/progress_scan.py` | 盘点 `题库/`，判断每个文件是否有可用文本层，写出 `数学/高中/提取进度.json` |
| `_tools/build_progress.py` | 由 json + OCR 结果生成 `提取进度.md` / `提取进度.html` |
| `_tools/split_by_topic.py` | 把学期合并稿切分为知识主题文件夹 |
| `_tools/fix_citations.py` | 统一改写各主题的「依据（题库出处）」；**会覆盖手工修改的依据行，仅在批量重建时使用** |
| `_tools/ocr_pdf.py` | 对高中无文本层的 PDF 做 OCR，输出 `题库/_ocr/<路径>.txt`；支持 `--shards N --shard i` 分片并行，`--cap` 秒数/份，`--threads` 每进程 ONNX 线程数（默认 2），**下次运行从 PARTIAL 断点处续扫** |
| `_tools/ocr_rounds.py` | 多轮调用 `ocr_pdf.py` 直到所有 PDF 扫完（每轮每份约 `--cap` 秒，自动续扫未完成页；`--shards × --threads` 不要超过 CPU 线程数的一半，否则相互抢核反而更慢） |
| `_tools/ocr_docx.py` | 对纯图片排版（无文字层）的 docx，OCR 其内嵌图片 |
| `_tools/extract_outline.py` / `build_digests.py` | docx 提纲与【点睛】快速浏览 |

OCR 环境在 `_tools/ocr-env/`（Python 3.12 + PyMuPDF + RapidOCR），不污染系统 Python：

```bash
python -I _tools/progress_scan.py            # 重新盘点（较慢，分钟级）
python -I _tools/ocr_pdf.py --sem "高三/下"    # 单个学期 OCR，已完成/已扫完的会跳过
python -I _tools/ocr_rounds.py --shards 8 --threads 2 --cap 180   # 全量：8 片并行，多轮续扫直到扫完
python -I _tools/ocr_docx.py                 # 图片版 docx 的图片 OCR
python -I _tools/build_progress.py           # 刷新进度面板
```

OCR 采用页级进度：`提取进度.md/html` 中的「阶段 3」按**已识别页 / 总页数**显示；单份 PDF 未扫完时末尾写 `=== PARTIAL: stopped at page k/N ===`，下一轮从第 k+1 页继续，扫完即去掉该标记。

## 提示词编写规范（建议）

1. **年级锚定**：明确出现「八年级上学期」「高二下学期」等字样，并限定使用的知识范围，避免超纲（例如初中禁用高中方法，高一禁用圆锥曲线）。
2. **教材版本**：默认人教版，如使用北师大/苏科/沪科等版本在 `知识点清单.md` 中注明。
3. **输出格式**：统一为「题目理解 → 解题思路 → 分步推导 → 最终答案 → 易错点提醒」。
4. **符号表示**：明确公式使用 LaTeX（行内 `$...$`、块级 `$$...$$`）。
5. **不超纲原则**：只使用该学期及之前已学的方法；必须使用后续知识时需在输出中显式说明。

## 各学期知识范围速查

### 数学（人教版）

| 学期 | 主要内容 |
| --- | --- |
| 八年级上 | 三角形、全等三角形、轴对称、整式的乘法与因式分解、分式 |
| 八年级下 | 二次根式、勾股定理、平行四边形、一次函数、数据的分析 |
| 九年级上 | 一元二次方程、二次函数、旋转、圆、概率初步 |
| 九年级下 | 反比例函数、相似、锐角三角函数、投影与视图 |
| 高一上 | 集合与常用逻辑用语、一元二次函数/方程/不等式、函数概念与性质、指数函数与对数函数、三角函数 |
| 高一下 | 平面向量、解三角形、复数、立体几何初步、统计、概率 |
| 高二上 | 空间向量与立体几何、直线和圆的方程、圆锥曲线的方程 |
| 高二下 | 数列、导数及其应用、计数原理、随机变量及其分布、成对数据的统计分析 |
| 高三上 | 一轮复习：函数与导数、不等式、三角函数与解三角形、向量与立体几何、数列、概率统计、解析几何、集合逻辑与计数原理 |
| 高三下 | 二轮冲刺：选填策略、导数压轴、圆锥曲线压轴、概率与数列、向量与立体几何、新题型与应试 |

> 高中部分的主题文件夹与上表一一对应，命名前缀（`01-`、`02-`…）即为建议的讲解顺序。

### 物理（人教版）

| 学期 | 主要内容 |
| --- | --- |
| 八年级上 | 机械运动、声现象、物态变化、光现象、透镜及其应用、质量与密度 |
| 八年级下 | 力、运动和力、压强、浮力、功和机械能、简单机械 |
| 九年级上 | 内能、内能的利用、电流和电路、电压电阻、欧姆定律 |
| 九年级下 | 电功率、生活用电、电与磁、信息的传递、能源与可持续发展 |
| 高一上 | 运动的描述、匀变速直线运动、相互作用—力、运动和力的关系 |
| 高一下 | 抛体运动、圆周运动、万有引力与宇宙航行、机械能守恒定律 |
| 高二上 | 动量守恒定律、机械振动、机械波、光、电磁感应初步 |
| 高二下 | 静电场、恒定电流、磁场、电磁感应、交变电流 |
| 高三上 | 一轮复习：力与运动、功和能、动量、电场与磁场、电磁感应、热学、光学、近代物理 |
| 高三下 | 二轮专题、实验专题（力学/电学）、综合训练、考前冲刺 |

> 注：各地教学进度略有差异（如部分地区高二上学期已进入静电场），以此为参考，可按实际教学计划调整。
