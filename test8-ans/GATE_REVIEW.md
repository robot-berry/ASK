# 出图门禁审查与优化结论

更新时间：2026-09-07

## 结论

优化前，工作流把“模型质量评测”和“能否生成图片”绑在了一起。50 题都成功返回，且 50 题都通过了轻量相关性筛查，但只有 23 题生成了完整五层图。

优化后采用两套独立判定：

- 出图判定只保留最小必要条件；
- 严格结构、相关性、脱敏置信度和 20 秒继续记录，但只作人工审核和模型晋级指标。

使用原先保存的 50 份 Qwen-Max 回复本地重放，没有再次调用模型，完整五层图已从 23/50 提高到 50/50。

## 现在哪些会阻止出图

| 检查 | 处理 | 原因 |
|---|---|---|
| 模型回复完全无法解析 | 阻止 | 无法找到五层内容 |
| `l1`～`l5` 某一整层没有任何可展示文字 | 阻止 | 无法产生完整的五层产物 |
| 脱敏后仍检测到明确最终答案嫌疑片段 | 阻止 | 避免对外图片泄漏最终答案 |
| PNG 生成本身异常 | 阻止当题 | 图片文件实际未完成 |

## 哪些只作告警

| 检查 | 现在用途 | 为什么不再阻止出图 |
|---|---|---|
| 每层恰好 1/1/2/4 句 | 结构质量 | 少一句或多一句仍然可以正常阅读和排版 |
| 单句 8～60 字、建议 15～35 字 | 紧凑度 | 字数偏差不等于内容不可用 |
| `pit`、公式数量、精确字段集合 | 提示词遵循度 | 字符串/数组等小差异可以在本地宽容读取 |
| 第一层是否以问号结尾 | 引导形式 | 不影响图片生成 |
| 本地词面相关性 | 跑题筛查 | 它只是启发式筛查，不能代表正确性，也可能误报 |
| 无法从题干推断所求量 | 脱敏置信度 | 已做确定性脱敏时，只需提醒人工复核，不应让整套图消失 |
| 含 PNG 总时延超过 20 秒 | 性能和模型选型 | 超时不代表图片不能产生 |

## 50 题中的严格告警

- 17 题有严格 Schema 偏差：10 题涉及单句长度，4 题涉及固定句数，3 题涉及字段或类型，1 题涉及问句形式，1 题涉及公式数量；同一题可同时命中多类。
- 7 题的题干所求量推断置信度不足，已保留人工复核提示。
- 0 题本地相关性告警。
- 17 题超过 20 秒，且这 17 题在模型返回时就已经超时；本地处理没有使任何题从 20 秒内跨到 20 秒外。

## 已作为全局规则修复的审核问题

- 公开解析图不显示模型内部 `n` 字段，因此 A/B/C/D、数字序号和 demo 编号都不会作为独立标签露出。
- 公开图片中的 LaTeX 控制符先转为 Unicode/可读文本，`$`、反斜杠命令、`^{}` 和 `_{}` 不再原样泄漏。
- 所有公开文字统一为黑色，去除了“基础解析”前的竖线和上方横线，不对外显示 `l5` 或 demo 标识。
- 第五层对外名称为“基础解析”。
- 严格 Schema 失败不再触发第二次模型调用；只有完全无法构造五层展示内容时，显式开启的 repair 才可尝试第二次调用。
