# 网页提示词管理

入口：搜题主页的“提示词管理”，或 `/prompt-settings`。

使用现有 `TEST6_ACCESS_TOKEN`（兼容 `TEST4_ACCESS_TOKEN`）对应的主管理令牌登录。
设备专用令牌不能读取或修改提示词。不要把模型 API 密钥填入登录框。

选择数学或物理，直接编辑正文，也可导入 `.md` / `.txt`。完整原有 Markdown
文件将自动提取“二、发给模型的系统提示词”到“三、设备端排版约束”之间的正文。
点击“保存并启用”后，新开始处理的任务读取新版本，无需重启。
正在处理的任务保留启动时的提示词快照。任务内部审计记录 `prompt_version`
和 `prompt_revision`，不对设备公开提示词内容。

历史版本保留在数据库中；网页列出最近 30 个版本。选择并载入历史版本后，
需要点击“保存并启用”才生效。“载入工程默认版本”也是先填入编辑框。
默认版本来自工程自带的学科 Markdown 文件，不覆盖源文件。
若另一页面已保存不同内容，当前旧页面保存返回冲突，需重新加载。

此页面管理学科提示词正文。共用系统指令、JSON Schema、课程边界和输出校验
继续由工程控制。保存检查基本长度及五档标识，不代表内容质量已经验证。

## 部署与数据

Linux 默认数据库：`/var/lib/solver-test4/portal/prompts.sqlite3`。
Windows 默认数据库：工程下 `.local/prompts.sqlite3`。
可用 `TEST6_PROMPT_DB` 指定路径，门户、数学、物理三个服务必须配置同一路径。
门户服务需要数据库目录写权限，两学科服务只需读取权限。
数据库位于发布目录外，升级工程不会覆盖已保存的提示词。备份时保留此数据库。

首次安装功能需要更新 `prompt_store.py`、`prompt_admin.py`、门户入口及页面、
两学科 `search_machine_pipeline.py`，再重启三个服务。后续编辑提示词无需重启。
与项目现有 systemd 默认路径、运行用户和目录权限兼容。

验证命令：`python -m unittest discover -s tests -p 'test_p*.py' -v`。
