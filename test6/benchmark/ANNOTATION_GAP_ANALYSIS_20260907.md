## 结论

本轮以 `manual_annotations.json` 中保存的错误类型和备注为需求源。自动“语义结构通过”只表示检测到题号、选项等表面结构，不再用作正确率结论。

## 逐类差距与处理状态

| 批注方向 | 找到的实现原因 | 本轮处理 |
|---|---|---|
| 不自然换行、大块空白 | OCR 物理行曾直接影响段落；公式和填空槽在行尾又可能作为错误的断行单位 | 逻辑段落先合并再按画布宽度排版；选项统一网格；新增“填空槽+单位”原子，禁止 `____` 与 `cm` 分行。全部批注题仍需按新代码重跑核验 |
| 分段函数表示错误 | 代码曾主动把左花括号分段式改写为“当……时……”两句，改变了原公式结构 | 已改为本地绘制 `f(x)=`、一枚跨行左花括号和对齐的两段公式；不粘贴公式截图、不泄漏 TeX |
| 分式、根号、上下标、集合/向量/角度符号 | 结构公式识别是局部替换；旧结果中有些题未使用最新归一化与渲染规则 | 保留可靠正文，只替换定位明确的公式；已统一分式、根号、上下标、集合花括号、向量粗体和角度符号渲染。必须用最新代码重新生成批注题，旧图不作为完成证据 |
| 图注混入正文 | 图注曾在正文清理时被删除，但没有稳定绑定到相应裁图 | 识别到的图注现在从正文层剥离，绑定到对应插图，并在图下重新排版 |
| 插图缺失/裁剪不完整 | 只取模型框或最大连通块会丢坐标点、顶点和多图中的子图 | 以图注锚点、版面区域和邻近墨迹共同扩展边界；多图逐图保留；空白候选过滤。现有样例 T01-Q07、T03-Q06、T03-Q12、PHYS-T08-Q12 已出现完整图，但仍要按批注逐题复核 |
| 表格 | 表格既被 OCR 拉平成正文，又被重复作为图片裁剪 | 能确定行列时只生成对齐文字表格；不再重复同一表格图片；不能可靠重建时保留完整原表格裁图 |
| 正文漏字/多识别 | 题目边界与选项闭合判断不足；图注、相邻题和手写结果可能进入正文 | 题号到最后选项/小问作为边界；填空槽恢复；图注从正文剥离；手写解答尾部过滤。批注中无备注但勾选 `text_error/text_missing` 的题仍需依赖新旧图人工复核 |
| 手写字迹 | 文本层过滤与图片像素擦除是两个问题；保守擦除为保护科学图标签，仍可能留下覆盖在图内的手写线条 | 文本层不再输出手写答案；独立页边手写图可过滤。覆盖科学插图关键线条的黑色手写仍不能自动宣称清除，需保留为待确认，避免误删印刷标签或图线 |
