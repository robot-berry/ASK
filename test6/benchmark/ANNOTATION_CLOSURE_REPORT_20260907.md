## 2. 对应批注完成的工程级修改

### 2.1 自然换行和对齐

- 不再把 OCR 返回的每个物理文本框当作一行；先合并为语义段落，再按最终画布宽度自动换行。
- 题干、`（1）（2）` 小问、A/B/C/D 选项分别排版；同一选项不会因为源图框位置而产生无意义缩进。
- 行首标点、超短尾行和跨行黏连被统一修正。
- 两列或四列短选项继续横向对齐；长选项自动改为两列或单列，避免文字挤压。

### 2.2 数学公式

- 分式、嵌套分式、根式、上下标改用二维公式结构绘制，不再显示原始 LaTeX 文本。
- 向量基底使用粗体数学字母；带箭头向量保留箭头及系数分式。
- 小写直线 `l/l₁/l₂` 规范为 `ℓ/ℓ₁/ℓ₂`，避免看成数字 1。
- 空集保持 `∅`；包含、平行、垂直等关系保留数学符号。
- 填空横线与公式分离绘制，不被误当作分数线或答案内容。
- 定义式后的普通公式不再被误判为填空横线；例如 `第 i 行第 j 个数为 a(i,j)`。

### 2.3 插图和图注

- 插图框扩展到完整前景边界，保留图中坐标轴点、几何顶点和印刷标签。
- 多图按源图阅读顺序全部保留；同一行的两图保持并排，四图题全部输出。
- `甲、乙、丙、丁` 和“第 N 题图”等图注从题干文字中分离，只显示在对应插图下方。
- 表格已重建为文字表格时不再重复裁表格图；几何图、实验图、函数图仍按图片保留。

### 2.4 表格

- `TZIP-MATH-T04-Q12` 的列联表和概率参考表已经重建为规则网格。
- 表头保留“期末统考数学成绩：及格/不及格”，参考表保留 `P(χ²≥k)` 和 `k` 的原始语义。

### 2.5 文本和手写

- OCR 正文只保留印刷题目；答案勾选、演算、页码、校对字样和图注不会并入题干。
- 手写与印刷内容能空间分离时，公开结果只保留印刷区域。
- 手写线条与印刷图线真正重叠时不做破坏性强抹除，避免把滑轮、绳线或几何边一起删掉；这类题保留人工确认状态。
