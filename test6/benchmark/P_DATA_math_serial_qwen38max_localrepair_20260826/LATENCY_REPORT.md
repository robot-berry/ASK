## 新修复策略

```text
模型主响应
  → 本地修复循环（最多 3 次，直到稳定）
      → 公式/编号规范化
      → 答案字段删除、答案步骤截断
      → 坏 bbox 修正或同图复用
      → 步骤数量本地补齐/截断
      → 未完成推理草稿删除
  → 可安全发布：直接渲染，不调用修复模型
  → 仍有正确性错误：只把报错域交给模型修 1 次
      → 冻结题干、识别结果和 source contract
      → 只合并 guidance / base_formulas / knowledge_points / visual_evidence 中的报错域
      → 再跑本地修复；失败即停止，不发起第二次修复
```

识别源字段错误不会通过整份模型重写“修复”；定向响应缺少报错域时也不会回退为整份替换。这避免模型在修复格式问题时悄悄改题。
