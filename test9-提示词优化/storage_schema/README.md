# Test6题目分类存储结构

`question_record.schema.json` 是正式结构约束，`question_record.example.json` 是一条不含真实设备信息的示例记录。

一条记录对应“一道题目 × 一个解析等级”。同一道题具有五种解析时，应分别保存五条记录，五条记录的原题文字、图片上传时间和设备SN码保持一致，解析等级、解析文字内容和建议文字内容分别保存对应档位的数据。

字段规则：

- 学科类型：只能是“数学”或“物理”。
- 题目类型：只能是“原题”或“变式题”。
- 原题文字内容：保存OCR得到的完整原题文字，不混入解析和答案。
- 解析等级：只能是“学霸”“中上”“中等”“中下”“学渣”。
- 解析文字内容：保存对应等级的模型自然语言解析。
- 建议文字内容：保存对应等级给学生的建议。
- 图片上传时间：固定使用 `yyyy-MM-dd HH:mm:ss`，例如 `2026-09-08 17:40:00`。
- 涉及知识点：使用字符串数组，每个知识点单独一项并去重。
- 设备SN码：只允许英文字母、数字、点、下划线、冒号和短横线，最长128个字符。

JSON文件统一使用UTF-8编码。正式数据不要保存API密钥、手机令牌、服务器内部路径或原始图片二进制内容。
