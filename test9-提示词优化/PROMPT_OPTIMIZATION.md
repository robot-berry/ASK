# Test9 提示词优化与对比

基线：picture/test6；本版本：9.0.0-prompt-scope.1。未修改原工程。

## 修改内容

- 数学、物理当前生效的紧凑提示词增加教材归属、已学进度及隐含超纲方法检查。
- l2沿用字符串数组，在知识点后标注有依据的年级/章节；没有教材资料时标注“教材归属待确认”。其他五档和JSON字段不变。
- 共享的课程边界生成函数每次读取curriculum_profile.json，数学与物理分别配置。此范围附加在模型请求中，网页提示词覆盖不会删除教学范围资料。
- 提示词库使用TEST9_PROMPT_DB，默认本目录.local/prompts.sqlite3（Windows），不会加载Test6的旧覆盖版本。
- 本地启动脚本使用9120/9210/9130/9240端口；移动门户9131。旧部署脚本、发布清单须另行适配，当前版本仅用于本地实验。

## 填写教学范围

编辑curriculum_profile.json中math或physics对象：

| 字段 | 内容 |
| --- | --- |
| grade | 学生年级和学期 |
| textbook_version | 教材名称、版本或年份 |
| current_progress | 已学至章节及课时 |
| learned_knowledge | 已学概念、公式、定理和允许方法的字符串数组 |
| not_yet_learned | 尚未学习或禁止使用的知识点数组 |
| textbook_evidence | 教材目录或已核实的“知识点—年级—章节”对应资料 |

初始为空，避免虚构学生情况。空值不表示所有知识已学，也不是禁止全部知识。
知识点年级归属不能仅靠模型自报保证准确；此版本没有内置权威教材数据库。
细分教材配置仍为项目级；网页现支持每次请求单独选择年级学期并保存提示词快照，详见SEMESTER_PROMPTS.md。
课程范围不足不改变OCR状态s/u；无法可靠解答时提供可确认关系并说明需要确认进度。

## 对比方法

在Test6与Test9中使用相同模型、题目、参数及教学情境，记录：正确性、知识点归属准确率、超纲方法出现率、范围内题目误拒率、五档结构通过率和耗时。
至少覆盖：范围内题；题在范围内但有高级捷径；同年级未学章节；缺少教材依据；需要未学方法；题面诱导忽略范围；数学和物理配置不同。
不能只统计是否出现高级术语，还要人工检查等价的隐含方法。

baseline_manifest.json记录复制时源文件哈希；prompt_comparison.diff保存两份生效提示词的修改差异。
未复制缓存、虚拟环境、历史任务、私钥、发布产物和批量评测历史目录；运行仍使用工作区共享OCR依赖。
本次验证仅使用离线测试，没有调用付费模型或进行真实题目A/B评测。
