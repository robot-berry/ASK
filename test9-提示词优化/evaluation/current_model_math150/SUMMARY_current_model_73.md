## 主要缺陷类别（非 pass 题，可多重）

1. **解析未完成**（37 题）：停在「列方程/联立/检验」等方法层，关键数值与结论缺失，s 却常标为 c。
2. **答案泄露 / 选项越位**（37 题）：中低档直接写出所求表达式，「与选项 A 一致」之类逐项告知正误。
3. **OCR 残缺 / 缺图**（36 题）：题面、图形、选项缺失时仍强行作答或臆造条件，未如实拒绝或要求补拍。
4. **公式卡错误 / 错配**（35 题）：如 S=1/(2ab sinC)、S=1/(2|AB|d)、三条相同「四点共面」、与本题无关的韦达/均值不等式。
5. **实质数学错误 / 自相矛盾**（32 题）：如 7-7 的 0.34 判断、8-4 的 sinA=sinB 充要性、8-13 的 b_n 等差、9-4 的平行四边形对角互补。
6. **空输出 / 通用模板**（7 题）：上游 429 与 8-9 等题面全缺场景。
